Glossary

Every key word from the three tutorials in a sentence or two, with a link back to the lesson that explains it.

Accuracy ML
The fraction of predictions that are right. Misleading when one class is rare: always guessing the common class can score high. Lesson ›
Activation function ML
The nonlinear squash inside a neuron, such as tanh, the sigmoid or ReLU. Without it, stacked layers stay linear. Lesson ›
Ad hoc dataset QML
Havlíček and coauthors' dataset whose labels are made with the ZZ feature map itself, so a matching quantum kernel learns it from few examples. Lesson ›
Adam ML
A gradient-descent optimizer that adapts the step for every weight from running averages of its gradients. PyTorch's usual default. Lesson ›
Agent ML
In reinforcement learning, the learner that observes a state, takes an action and receives a reward. Lesson ›
Amplitude QC
One of the complex numbers describing a quantum state. Its squared size is the probability of that outcome. Lesson ›
Amplitude damping QML
Noise in which ∣1⟩|1\rangle∣1⟩ relaxes to ∣0⟩|0\rangle∣0⟩. It pulls ⟨Z⟩\langle Z\rangle⟨Z⟩ toward +1+1+1, shifting a classifier's boundary. Lesson ›
Amplitude encoding QML
Storing 2n2^n2n numbers, normalized, as the amplitudes of nnn qubits. Compact, but costly to prepare and to read back. Lesson ›
Angle encoding QML
Turning each feature into a rotation angle, such as RY(xj)R_Y(x_j)RY​(xj​) on its own qubit. One qubit per feature. Lesson ›
Autoencoder ML
A neural network trained to copy its input through a narrow bottleneck, learning a compressed code. Lesson ›
Autograd ML
PyTorch's automatic differentiation: it records a computation and runs the chain rule backwards to get every gradient. Lesson ›
Backpropagation ML
The chain rule applied backwards through a network, layer by layer, to get the gradient of the loss for every weight. Lesson ›
Balanced accuracy ML
The average of the recall of each class. Honest when one class is rare. Lesson ›
Barren plateau QC
A cost landscape that is flat almost everywhere, so gradients are too small to estimate. Common in big, expressive circuits. Lesson ›
Baseline QML
The classical model a new method must beat, ideally strong and tuned with the same effort, on the same data and splits. Lesson ›
Basis QC
A set of reference states to measure in. Measuring in another basis means rotating first, then measuring Z. Lesson ›
Bell state QC
One of four maximally entangled two-qubit states, such as 12(∣00⟩+∣11⟩)\frac{1}{\sqrt 2}(|00\rangle + |11\rangle)2​1​(∣00⟩+∣11⟩), made with H and a CNOT. Lesson ›
Bellman equation ML
A state's value equals its reward plus the discounted value of where you go next. The idea behind value iteration and Q-learning. Lesson ›
Bias and variance ML
Two ways to be wrong: too simple a model (bias) or one that changes too much with the data (variance). Lesson ›
Bloch sphere QC
A picture of every one-qubit state as a point on a sphere: the angle from the top sets the odds, the angle around sets the phase. Lesson ›
Born rule QC
The probability of an outcome is the squared size of its amplitude: P(0)=∣α∣2P(0) = |\alpha|^2P(0)=∣α∣2. Lesson ›
Circuit QC
A recipe of gates applied to qubits, read left to right, usually ending in measurements. Lesson ›
Class weights ML
Making mistakes on a rare class cost more during training, so the model doesn't ignore it. Lesson ›
Classical surrogate QML
A classical model built to imitate a quantum one, for example logistic regression on the Fourier features a circuit can make. Lesson ›
CNOT QC
The controlled-NOT: flips the target qubit when the control is 1. With a Hadamard, it creates entanglement. Lesson ›
Concentration (exponential) QML
In large feature spaces, kernel values of different points crowd around 2−n2^{-n}2−n, too small for shots to tell apart. Lesson ›
Confusion matrix ML
A table counting predictions against true classes: true and false positives and negatives. Lesson ›
Cost landscape QC
The cost of a parameterized circuit as a function of its angles: sine waves along every knob. Lesson ›
Cross-entropy ML
The loss for probabilities: −log⁡-\log−log of the probability given to the true class. Confident mistakes cost the most. Lesson ›
Cross-validation ML
Splitting the training data into folds, training on all but one and validating on it in turn, to tune settings without touching the test set. Lesson ›
Data re-uploading QML
Feeding the input into a circuit several times. Each upload adds a frequency to the Fourier series the circuit computes. Lesson ›
Decision tree ML
A model that classifies by asking a sequence of yes/no questions about the features. Lesson ›
Density matrix QC
A matrix ρ\rhoρ that describes any quantum state, including mixed states that a single vector of amplitudes can't. Lesson ›
Depolarizing noise QC
Noise that replaces the state by a fully random one with some probability ppp. It shrinks every expectation value toward 0. Lesson ›
Deutsch–Jozsa algorithm QC
Decides with one query whether a function is constant or balanced, using phase kickback and interference. Lesson ›
Encoding QML
How classical data is loaded into a quantum state: basis, angle or amplitude encoding, or a feature map. Lesson ›
Entanglement QC
A joint state of several qubits that can't be described qubit by qubit. Measuring one tells you about the others. Lesson ›
Epoch ML
One pass of training through the whole training set. Lesson ›
Error mitigation QC
Reducing the effect of noise on results without full error correction, for example by fixing readout errors or extrapolating to zero noise. Lesson ›
Expectation value QC
The average outcome of a measurement over many shots, such as ⟨Z⟩=P(0)−P(1)\langle Z\rangle = P(0) - P(1)⟨Z⟩=P(0)−P(1). The output of most quantum models. Lesson ›
Exploration and exploitation ML
The trade-off between trying actions to learn about them and using the best action found so far. Lesson ›
Feature ML
One measured property of a data point, one column of the data table. Lesson ›
Feature map ML
A function that lifts data into a bigger space, where a linear model can draw curved boundaries. Quantum feature maps lift data into quantum states. Lesson ›
Fidelity QC
How alike two quantum states are: ∣⟨ψ∣φ⟩∣2|\langle\psi|\varphi\rangle|^2∣⟨ψ∣φ⟩∣2 for pure states, 1 for identical, 0 for orthogonal. Lesson ›
Fourier series (of a circuit) QML
A circuit that uploads xxx through LLL rotation gates computes a sum of cos⁡(ωx)\cos(\omega x)cos(ωx) and sin⁡(ωx)\sin(\omega x)sin(ωx) with frequencies up to LLL. Lesson ›
Gaussian mixture ML
A model of the data as a blend of bell-shaped clusters, each with its own center, shape and weight. Lesson ›
Gradient ML
The direction of steepest increase of a function. Its components are the partial derivatives. Lesson ›
Gradient descent ML
Training by repeated small steps against the gradient of the loss, w←w−η ∇Lw \leftarrow w - \eta\,\nabla Lw←w−η∇L. Lesson ›
Grover's search QC
Finds a marked item among NNN in about π4N\frac{\pi}{4}\sqrt N4π​N​ steps by repeatedly flipping its sign and reflecting about the mean. Lesson ›
Hadamard gate QC
The gate H that turns ∣0⟩|0\rangle∣0⟩ into ∣+⟩|+\rangle∣+⟩, an equal superposition, and back again. Lesson ›
Helstrom bound QC
The best possible chance of telling two states apart from one copy: 12(1+D)\frac{1}{2}(1 + D)21​(1+D), with DDD their trace distance. Lesson ›
Hidden layer ML
A layer of neurons between the input and the output of a network. Hidden layers let boundaries bend. Lesson ›
Hybrid model QML
A model mixing classical layers and circuits, trained together, with gradients passing through both. Lesson ›
Hyperparameter ML
A setting chosen before training, such as kkk in kNN or a learning rate, tuned on validation data. Lesson ›
Interference QC
Amplitudes add before they are squared, so paths can reinforce or cancel. The engine of quantum algorithms. Lesson ›
Inversion test QML
Measuring the overlap of U(x)∣0⟩U(x)|0\rangleU(x)∣0⟩ and U(x′)∣0⟩U(x')|0\rangleU(x′)∣0⟩ by running U(x′)†U(x)U(x')^\dagger U(x)U(x′)†U(x): P(00…0)P(00\ldots0)P(00…0) is the fidelity. Lesson ›
k-means ML
Clustering by repeating two steps: join each point to its nearest center, move each center to the mean of its points. Lesson ›
k-nearest neighbors ML
Classifying a point by a vote of the kkk closest training points. Lesson ›
Kernel ML
A similarity k(x,x′)k(x, x')k(x,x′) that equals an inner product of feature vectors, so a model can work in a big feature space without building it. Lesson ›
Kernel matrix ML
The table of kernel values between all pairs of points. A valid one has no negative eigenvalues. Lesson ›
Label ML
The answer attached to a training example, such as its class. Lesson ›
Lasso and ridge ML
Penalties that keep weights small: ridge shrinks all of them, lasso pushes some to exactly zero. Lesson ›
Learning rate ML
The size of each gradient-descent step. Too small is slow; too big overshoots. Lesson ›
Logistic regression ML
A line or plane plus a sigmoid: a linear model that outputs class probabilities, trained with cross-entropy. Lesson ›
Loss ML
A number that measures how wrong a model is on the training data. Training lowers it. Lesson ›
Margin ML
In an SVM, the width of the street between the classes. The SVM picks the widest one. Lesson ›
Measurement QC
Reading a qubit: it gives 0 or 1 at random, by the Born rule, and the state collapses to what was seen. Lesson ›
Mini-batch ML
A small random group of training examples used for one gradient step. Lesson ›
Mixed state QC
A state that is uncertain in the classical sense too, such as a qubit that is ∣0⟩|0\rangle∣0⟩ or ∣1⟩|1\rangle∣1⟩ at random. Inside the Bloch sphere. Lesson ›
Neuron ML
A weighted sum of inputs plus a bias, passed through an activation function. Lesson ›
No-cloning QC
An unknown quantum state can't be copied. You get one shot at reading each copy. Lesson ›
Noise-induced barren plateau QML
Noise shrinks gradients a little in every layer, so in deep noisy circuits they fade exponentially, even on few qubits. Lesson ›
Observable QC
A quantity you can measure, such as ZZZ or Z⊗ZZ \otimes ZZ⊗Z. Its expectation value is a model's typical output. Lesson ›
Overfitting ML
Fitting the training data so closely, noise included, that the model does worse on new data. Lesson ›
Parameter-shift rule QC
The exact gradient of a circuit: run it with one angle shifted by ±π2\pm\frac{\pi}{2}±2π​ and take half the difference. Lesson ›
Parameterized circuit QC
A circuit with adjustable gate angles that act as trainable weights. Lesson ›
Pauli gates QC
X, Y and Z: half-turns of the Bloch sphere about its three axes. X is the quantum NOT. Lesson ›
Phase QC
The angle of an amplitude. Invisible to a single Z measurement, but it decides how amplitudes interfere. Lesson ›
Phase kickback QC
A controlled gate can write its effect into the phase of the control qubit, turning answers into signs. Lesson ›
Policy ML
An agent's rule for choosing actions. Policy gradient methods train it directly from rewards. Lesson ›
Precision and recall ML
Of the points flagged positive, the fraction truly positive (precision); of the truly positive, the fraction flagged (recall). Lesson ›
Principal component analysis (PCA) ML
Finding the directions in which the data vary most, to shrink many features to a few. Lesson ›
PyTorch ML
A Python library for building and training networks: tensors, autograd and optimizers. Lesson ›
Q-learning ML
Learning the value of every action in every state from experience, then acting greedily on those values. Lesson ›
QSVM QML
A support vector machine whose kernel values come from a quantum circuit. Lesson ›
Quantum data QML
Data that are quantum states themselves, from a sensor, a memory or another quantum computer: the QQ corner of QML. Lesson ›
Quantum kernel QML
A kernel computed by a circuit: the fidelity ∣⟨φ(x)∣φ(x′)⟩∣2|\langle\varphi(x)|\varphi(x')\rangle|^2∣⟨φ(x)∣φ(x′)⟩∣2 of two encoded states. Lesson ›
Qubit QC
The quantum bit: a state α∣0⟩+β∣1⟩\alpha|0\rangle + \beta|1\rangleα∣0⟩+β∣1⟩ with ∣α∣2+∣β∣2=1|\alpha|^2 + |\beta|^2 = 1∣α∣2+∣β∣2=1. Lesson ›
Random forest ML
Many decision trees, each trained on a random resample of the data, voting together. Lesson ›
RBF kernel ML
The Gaussian similarity e−γ∥x−x′∥2e^{-\gamma\|x - x'\|^2}e−γ∥x−x′∥2, the standard kernel for small datasets and the usual classical baseline. Lesson ›
Readout error QC
A measurement that reports the wrong bit. It shrinks and shifts expectation values, and can be partly corrected. Lesson ›
Regularization ML
Anything that keeps a model simpler than its data would allow, such as a penalty on large weights. Lesson ›
Reinforcement learning ML
Learning to act from rewards and penalties, by trial and error. Lesson ›
Reward ML
The number an environment hands an agent after an action: the signal reinforcement learning maximizes. Lesson ›
Rotation gates QC
RXR_XRX​, RYR_YRY​ and RZR_ZRZ​: turns of the Bloch sphere by any angle about an axis. Their angles are the knobs of trainable circuits. Lesson ›
Semi-supervised learning ML
Learning from a few labeled points and many unlabeled ones, letting the labels spread along the data's shape. Lesson ›
Shot QC
One run of a circuit ending in a measurement. Probabilities and expectation values are estimated from many shots. Lesson ›
Shot noise QML
The wobble of an estimate from SSS shots: about (1−⟨Z⟩2)/S\sqrt{(1 - \langle Z\rangle^2)/S}(1−⟨Z⟩2)/S​ for ⟨Z⟩\langle Z\rangle⟨Z⟩. Halving it costs four times the shots. Lesson ›
Sigmoid ML
The S-shaped function σ(z)=1/(1+e−z)\sigma(z) = 1/(1 + e^{-z})σ(z)=1/(1+e−z) that turns any number into a probability. Lesson ›
Softmax ML
Turns a list of scores into probabilities that add up to 1. Logistic regression for many classes. Lesson ›
Spread QML
How much a result varies across random splits or repeats, reported as ±\pm± one standard deviation. Differences smaller than it are ties. Lesson ›
Superposition QC
A qubit state with amplitude on both ∣0⟩|0\rangle∣0⟩ and ∣1⟩|1\rangle∣1⟩. Not 'both at once', but a state whose amplitudes can interfere. Lesson ›
Supervised learning ML
Learning from examples that come with the right answers. Lesson ›
Support vector machine (SVM) ML
A classifier that draws the widest street between two classes. Only the points on its edges, the support vectors, matter. Lesson ›
Swap test QML
A circuit with one extra qubit whose P(0)=1+F2P(0) = \frac{1 + F}{2}P(0)=21+F​ reveals the fidelity FFF of any two states. Lesson ›
Teleportation QC
Moving an unknown qubit state using a shared Bell pair and two classical bits. The original is destroyed on the way. Lesson ›
Tensor product QC
How qubits combine: two qubits have 2×2=42 \times 2 = 42×2=4 amplitudes, nnn qubits have 2n2^n2n. Lesson ›
Test set ML
Data kept locked away until the very end and used once, to measure how the final model does on new data. Lesson ›
Tomography QC
Reconstructing a quantum state by measuring many copies in several bases. Lesson ›
Trace distance QC
How distinguishable two states are, from 0 (identical) to 1 (perfectly distinguishable). For a qubit, half the distance between the Bloch vectors. Lesson ›
Training set ML
The data a model learns from. Lesson ›
Transpilation QC
Rewriting a circuit into the gates and connections a real device has, which usually makes it longer. Lesson ›
Unitary QC
A matrix that preserves total probability; every quantum gate is one, and every gate can be undone. Lesson ›
Unsupervised learning ML
Finding structure, such as clusters or directions, in data that has no labels. Lesson ›
Validation set ML
Held-out training data used to choose settings, so the test set stays untouched. Lesson ›
Value function ML
In reinforcement learning, how much total discounted reward an agent can expect from a state. Lesson ›
Variational quantum classifier (VQC) QML
A trainable circuit used as a classifier: encode, process with trainable gates, measure, and train with parameter-shift gradients. Lesson ›
VQE QC
The variational quantum eigensolver: a trainable circuit whose energy a classical optimizer minimizes, to find a ground state. Lesson ›
Winner's curse QML
The best-looking result out of many tries is partly luck, so it usually shrinks when retested on fresh data. Lesson ›
ZZ feature map QML
A quantum feature map with phases that depend on pairs of features, 2(π−xi)(π−xj)2(\pi - x_i)(\pi - x_j)2(π−xi​)(π−xj​), adding interactions and entanglement. Lesson ›
