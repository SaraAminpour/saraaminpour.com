Warm-up

Learning without an answer key

1 min

Nobody hands a toddler a labeled dataset of "correct steps". They try, wobble, fall, and slowly learn what works. Supervised learning needs the right answers; reinforcement learning (RL) only needs a signal of how well things went. This week a cat learns to find a fish, and you'll see every idea that game-playing and robot-controlling agents are built on.

Big idea

The loop, and the MDP

4 min

At each time step ttt, the agent sees the state sts_tst​, picks an action ata_tat​, and the environment answers with a reward rt+1r_{t+1}rt+1​ and a new state st+1s_{t+1}st+1​. A run from start to finish is an episode. The agent's rule for choosing actions is its policy π\piπ.

A Markov decision process (MDP) writes the environment down:

  • the states SSS (in the cat world: the 30 free squares) and the actions AAA (up, right, down, left);
  • the transitions P(s′∣s,a)P(s' \mid s, a)P(s′∣s,a): where each action can lead, with what probability (on a slippery floor, 80% where you meant, 10% to each side);
  • the rewards: here −0.04 per step, −1 for the puddle, +1 for the fish, which ends the episode;
  • a discount γ\gammaγ between 0 and 1.

"Markov" means the next state depends only on the current state and action, not on how you got there. The agent's goal is the biggest return, the discounted sum of future rewards:

Gt=rt+1+γ rt+2+γ2 rt+3+…G_t = r_{t+1} + \gamma\, r_{t+2} + \gamma^2\, r_{t+3} + \dotsGt​=rt+1​+γrt+2​+γ2rt+3​+…

A reward kkk steps away counts γk\gamma^kγk times as much: with γ\gammaγ near 0 the agent is short-sighted, near 1 it plans ahead. (Discounting also keeps endless episodes from summing to infinity.) Because transitions can be random, the same policy gives different returns each time; its value Vπ(s)V^\pi(s)Vπ(s) is the average return when starting from sss.

An MDP is the rulebook, a policy is the strategy, and the return is the score: RL looks for the policy with the best average score.

cell 1 · the MDP's rules
import numpy as np

maze = ["S...#.", ".##.#.", "...P..", ".#.##.", ".#....", "...#.F"]
rows, cols = len(maze), len(maze[0])
moves = [(-1, 0), (0, 1), (1, 0), (0, -1)]          # the actions: up, right, down, left
names = ["up", "right", "down", "left"]

def outcomes(state, action, slip=0.0):
    """The MDP's rules: every possible (probability, next state, reward, episode over?)."""
    results = []
    for direction, p in [(action, 1 - slip), ((action + 1) % 4, slip / 2), ((action + 3) % 4, slip / 2)]:
        if p == 0:
            continue
        r, c = state
        nr, nc = r + moves[direction][0], c + moves[direction][1]
        if not (0 <= nr < rows and 0 <= nc < cols) or maze[nr][nc] == "#":
            nr, nc = r, c                             # bumped into a wall: stay put
        cell = maze[nr][nc]
        reward = 1.0 if cell == "F" else -1.0 if cell == "P" else -0.04
        results.append((p, (nr, nc), reward, cell == "F"))
    return results

def step(state, action, rng, slip=0.0):
    """Sample one move: returns (next state, reward, episode over?)."""
    results = outcomes(state, action, slip)
    i = rng.choice(len(results), p=[p for p, *_ in results])
    return results[i][1:]

print("\n".join(maze))
print("\nFrom the start, trying to go right on a slippery floor:")
for p, s2, r, done in outcomes((0, 0), 1, slip=0.2):
    print(f"   with probability {p:.1f}: land on {s2}, reward {r:+.2f}")

cell 2 · one episode, one return
def run_episode(policy, rng, gamma=0.9, slip=0.0, max_steps=100):
    state, G, rewards = (0, 0), 0.0, []
    for t in range(max_steps):
        action = policy(state, rng)
        state, reward, done = step(state, action, rng, slip)
        G += gamma ** t * reward
        rewards.append(reward)
        if done:
            break
    return G, rewards

random_policy = lambda state, rng: int(rng.integers(4))
rng = np.random.default_rng(3)
G, rewards = run_episode(random_policy, rng)
print(f"random policy: {len(rewards)} steps, {rewards.count(-1.0)} puddle visits, "
      f"{'reached the fish' if rewards[-1] == 1.0 else 'no fish within 100 steps'}")
print(f"return with gamma = 0.9: {G:.3f}")

cell 3 · the value of two policies
arrows = ["DLLL#D",
          "D##U#D",
          "RRDRRD",
          "U#D##D",
          "U#RRRD",
          "URU#RF"]
act = {"U": 0, "R": 1, "D": 2, "L": 3}
hand_policy = lambda state, rng: act[arrows[state[0]][state[1]]]

for slip in [0.0, 0.2]:
    for name, policy in [("random", random_policy), ("hand-made", hand_policy)]:
        rng = np.random.default_rng(0)
        returns = [run_episode(policy, rng, slip=slip)[0] for _ in range(500)]

one solution
def discounted_return(rewards, gamma):
    return sum(gamma ** k * r for k, r in enumerate(rewards))

quick = [-0.04, -0.04, 0.5]
patient = [-0.04] * 11 + [1.0]
for gamma in [0.5, 0.8, 0.9, 0.95, 0.99]:
    q, p = discounted_return(quick, gamma), discounted_return(patient, gamma)
    print(f"gamma = {gamma:.2f}: quick {q:+.3f}, patient {p:+.3f} -> prefers the {'quick' if q > p else 'patient'} fish")
print("A small gamma makes the agent short-sighted; only a gamma close to 1 makes the long wait worth it.")

Wrap-up

Today in one sentence

1 min
In reinforcement learning an agent acts, gets rewards and new states; an MDP lists the states, actions, transition probabilities, rewards and discount; the return discounts future rewards by γ\gammaγ; and a policy's value is its average return.
Quantum link

Physicists use RL to control quantum systems: the state is what the lab knows about the qubits, the actions are pulses or gates, and the reward is how close the result comes to a target state. Agents have learned to prepare states and to correct errors this way.
