Warm-up

Ten classes, 64 pixels

1 min

Reading handwritten digits is the classic first job for a neural network: in the 1990s, networks like this one read the numbers on bank checks and envelopes. Today you'll train one, then hand it a pen.

Big idea

Pixels in, ten scores out

3 min

Each image is 8×88 \times 88×8 pixels, with values from 0 (blank) to 16 (full ink). Flatten it into a vector of 64 numbers, and it's just a data point in 64 dimensions, like the iris flowers in week 1 had 4.

The network:

x∈R64  →  ReLU(W1x+b1)⏟64 hidden neurons  →  W2h+b2⏟10 scores  →  softmax  →  10 probabilitiesx \in \mathbb{R}^{64} \;\to\; \underbrace{\text{ReLU}(W_1x + b_1)}_{64 \text{ hidden neurons}} \;\to\; \underbrace{W_2h + b_2}_{10 \text{ scores}} \;\to\; \text{softmax} \;\to\; 10 \text{ probabilities}x∈R64→64 hidden neuronsReLU(W1​x+b1​)​​→10 scoresW2​h+b2​​​→softmax→10 probabilities

The softmax and cross-entropy from week 3 handle the ten classes. The training loop uses all of this week's habits: mini-batches of 32, Adam, and early stopping on a validation set. The test set stays closed until the very end.

One honest warning: the images were made in a particular way. Each digit was scanned, fitted into a 32×3232 \times 3232×32 box (filling its full height, centered), and each 4×44 \times 44×4 block was counted, giving the 8×88 \times 88×8 grid. The widget shrinks your drawing the same way, but a finger on a screen is not a pen on paper. When test data comes from a different source than the training data, it's called distribution shift, and it makes every model less accurate.

A model is only as good as the match between its training data and the data it meets later.

X = digits.data / 16.0                     # pixel values from 0 to 1
y = digits.target
X_rest, X_test, y_rest, y_test = train_test_split(X, y, test_size=0.2, random_state=0, stratify=y)

Project: train, test, shrink

step 1 · train with every habit
def make_model(hidden=64, seed=0):
    torch.manual_seed(seed)
    return torch.nn.Sequential(torch.nn.Linear(64, hidden), torch.nn.ReLU(), torch.nn.Linear(hidden, 10))

loss_fn = torch.nn.CrossEntropyLoss()

def accuracy(model, X, y):
    with torch.no_grad():
        return (model(X).argmax(dim=1) == y).float().mean().item()

def fit(model, patience=10, max_epochs=300, verbose=False):
    opt = torch.optim.Adam(model.parameters(), lr=1e-3)
    loader = DataLoader(TensorDataset(Xtr, ytr), batch_size=32, shuffle=True, generator=torch.Generator().manual_seed(0))
    best_loss, best_state, best_epoch, waited = float("inf"), None, 0, 0
    for epoch in range(max_epochs):
        for xb, yb in loader:                      # mini-batches
            opt.zero_grad()
            loss_fn(model(xb), yb).backward()      # backpropagation
            opt.step()                             # Adam
        with torch.no_grad():
            val_loss = loss_fn(model(Xva), yva).item()
        if val_loss < best_loss:                   # early stopping
            best_loss, best_state, best_epoch, waited = val_loss, copy.deepcopy(model.state_dict()), epoch, 0
        else:
            waited += 1
            if waited >= patience:
                break
        if verbose and epoch % 20 == 0:
            print(f"epoch {epoch:3d}: validation loss {val_loss:.3f}, validation accuracy {accuracy(model, Xva, yva):.3f}")
    model.load_state_dict(best_state)
    if verbose:
        print(f"stopped after epoch {epoch}; kept the weights from epoch {best_epoch}")
    return model

model = fit(make_model(), verbose=True)

Need a hint?

Inside the loop: m = fit(make_model(hidden)) and results[hidden] = accuracy(m, Xva, yva). Then best = max(results.values()) and pick the smallest hidden with results[hidden] >= best - 0.01.

Show a solution
one solution
results = {}
for hidden in [2, 4, 8, 16, 32, 64]:
    m = fit(make_model(hidden))
    results[hidden] = accuracy(m, Xva, yva)
    n_weights = sum(p.numel() for p in m.parameters())
    print(f"{hidden:2d} hidden neurons ({n_weights:5,d} weights): validation accuracy {results[hidden]:.3f}")

best = max(results.values())
choice = min(h for h, acc in results.items() if acc >= best - 0.01)
final = fit(make_model(choice))
print(f"smallest size within 1% of the best: {choice} neurons; its test accuracy (opened once): {accuracy(final, Xte, yte):.3f}")

Wrap-up

This week in one sentence

1 min
A neural network stacks layers of weighted sums and nonlinear bends, learns all its weights at once with backpropagation, and trains well with mini-batches, Adam and early stopping; on clean digits it reaches 97%, and new kinds of data remind us that every model depends on what it was trained on.
Quantum link

An 8×88 \times 88×8 digit has 64 numbers. Amplitude encoding (Quantum ML, week 1) can store all 64 in the amplitudes of just 6 qubits, because 26=642^6 = 6426=64. Many quantum classifier papers test on exactly this dataset, often shrunk to two classes such as 0 versus 1. Now you know what a strong classical baseline looks like.

Go deeper (optional)

ISLP section 10.3 (convolutional neural networks): networks that look at small patches of an image, and the main reason computers now read images so well. For the history, look up LeCun and coauthors, "Backpropagation applied to handwritten zip code recognition" (Neural Computation, 1989).
