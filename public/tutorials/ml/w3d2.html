Warm-up

How surprised should a model be?

1 min

Yesterday the cross-entropy loss appeared in one line. It deserves more: it's the loss behind almost every classifier you'll ever train, from logistic regression to giant language models to quantum classifiers. Today you'll see what it means, why it beats squared error, and how it handles more than two classes.

Big idea

Surprise, its push, and softmax

4 min

Cross-entropy is surprise. If the model gave the correct class probability ppp, its loss on that example is

L=−log⁡pL = -\log pL=−logp

p=1p = 1p=1: no surprise, loss 0. p=0.5p = 0.5p=0.5: loss 0.69. p=0.01p = 0.01p=0.01: loss 4.6, a big surprise. Averaged over the data, it rewards models that put high probability on the truth.

Why not squared error? The gradient decides how hard each training step pushes. With a sigmoid output and cross-entropy, the push on the score zzz is beautifully simple:

∂L∂z=p−y\frac{\partial L}{\partial z} = p - y∂z∂L​=p−y

Confidently wrong (p≈0p \approx 0p≈0, y=1y = 1y=1)? A full push of almost 1. With squared error, the sigmoid's flat tail multiplies the gradient by almost zero, so a confidently wrong model barely moves. Cross-entropy never stalls on its worst mistakes.

More than two classes: softmax. Give each class kkk a score zkz_kzk​ (the logits), then

pk=ezk∑jezjp_k = \frac{e^{z_k}}{\sum_j e^{z_j}}pk​=∑j​ezj​ezk​​

Every pkp_kpk​ is positive, they add up to 1, and the biggest score gets the biggest probability. Dividing the scores by a temperature TTT first makes the model more confident (T<1T < 1T<1) or more cautious (T>1T > 1T>1). With two classes, softmax is exactly the sigmoid of the difference of the scores.

A classifier outputs scores; softmax turns them into probabilities; cross-entropy measures the surprise at the truth. In PyTorch that's nn.Linear(d, K) plus nn.CrossEntropyLoss().

cell 2 · the push on a confident mistake
for name in ["squared error", "cross-entropy"]:
    z = torch.tensor(-4.0, requires_grad=True)
    p = torch.sigmoid(z)
    loss = (p - 1) ** 2 if name == "squared error" else -torch.log(p)
    loss.backward()
    print(f"{name:>14}: loss {loss.item():.3f}, gradient dL/dz = {z.grad.item():+.4f}")
print("Cross-entropy's gradient is simply p - y = 0.018 - 1. Squared error's is tiny: learning would crawl.")

cell 3 · softmax and temperature
z = torch.tensor([2.0, 1.0, 0.1])
for T in [0.5, 1.0, 3.0]:
    p = torch.softmax(z / T, dim=0)

cell 4 · three iris species
import matplotlib.pyplot as plt
from sklearn.datasets import load_iris

iris = load_iris()
X = torch.tensor(iris.data[:, 2:], dtype=torch.float32)       # petal length and width
X = (X - X.mean(dim=0)) / X.std(dim=0)
y = torch.tensor(iris.target)

torch.manual_seed(0)
model = torch.nn.Linear(2, 3)
loss_fn = torch.nn.CrossEntropyLoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.5)
for step in range(300):
    optimizer.zero_grad()
    loss = loss_fn(model(X), y)
    loss.backward()
    optimizer.step()
with torch.no_grad():
    acc = (model(X).argmax(dim=1) == y).float().mean().item()
print(f"cross-entropy {loss.item():.3f}, accuracy {acc:.3f}")

xx, yy = np.meshgrid(np.linspace(-2.2, 2.2, 300), np.linspace(-2.2, 2.2, 300))
with torch.no_grad():
    grid = torch.tensor(np.c_[xx.ravel(), yy.ravel()], dtype=torch.float32)
    region = model(grid).argmax(dim=1).reshape(xx.shape).numpy()
colors = ["#ff8a50", "#5577f5", "#1fb394"]
plt.figure(figsize=(5.6, 4.4))
plt.contourf(xx, yy, region, levels=[-0.5, 0.5, 1.5, 2.5], colors=["#ffdcc9", "#d6defe", "#ccf2e7"])
for k in range(3):
    plt.scatter(X[y == k, 0], X[y == k, 1], s=18, color=colors[k], label=iris.target_names[k])
plt.xlabel("petal length (standardized)")
plt.ylabel("petal width (standardized)")
plt.legend()
plt.title("Softmax regression: three straight borders")
plt.show()

Need a hint?

e1000e^{1000}e1000 is far beyond the largest number a float can hold. But ezk−c∑jezj−c\frac{e^{z_k - c}}{\sum_j e^{z_j - c}}∑j​ezj​−cezk​−c​ is the same for every ccc, as the mixer showed. Pick c=max⁡jzjc = \max_j z_jc=maxj​zj​.

Show a solution
one solution
def naive_softmax(z):
    e = torch.exp(z)
    return e / e.sum()

def softmax(z):
    e = torch.exp(z - z.max())          # subtracting the max changes nothing mathematically...
    return e / e.sum()

z = torch.tensor([2.0, 1.0, 0.1])
print("mine:   ", softmax(z))
print("PyTorch:", torch.softmax(z, dim=0))
big = torch.tensor([1000.0, 1001.0, 1002.0])
print("naive on big scores:", naive_softmax(big), " <- exp(1000) overflows to inf, and inf/inf = nan")
print("safe on big scores: ", softmax(big), " <- ...but keeps every exponent small")

Today in one sentence

1 min
Cross-entropy is the surprise −log⁡p-\log p−logp at the true class, and its gradient p−yp - yp−y keeps pushing on confident mistakes; softmax turns KKK scores into KKK probabilities, so the same loss trains classifiers with any number of classes.
Quantum link

A quantum classifier gets its probabilities for free: measuring a few qubits gives the probability of each bitstring, and those already add up to 1, like a built-in softmax. The Quantum ML tutorial trains such circuits with exactly this cross-entropy loss.
