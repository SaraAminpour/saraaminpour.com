What do you remember?

A convolution in one line?tap to flip
Slide a small filter over the image; at each position multiply and add: one number per position, a feature map. Size: (n−k+2p)/s+1(n - k + 2p)/s + 1(n−k+2p)/s+1.
The CNN block?tap to flip
Convolution (several filters, so several channels), ReLU, max pooling. Repeat, then flatten into a linear layer. Filters are learned by backpropagation.
Why does a CNN cope with shifted digits?tap to flip
Its filters slide, so features move with the digit, and global pooling forgets where they are. Data augmentation helps any model, but only with the changes it shows.
Why do plain RNNs forget, and how does an LSTM remember?tap to flip
The gradient back to early steps is a long product of small factors: it vanishes. The LSTM's memory cell is updated by addition, guarded by forget, input and output gates.
Attention in one formula?tap to flip
softmax(QK⊤/d) V\text{softmax}(QK^\top / \sqrt{d})\,Vsoftmax(QK⊤/d​)V: each position takes a weighted average of all values, weighted by how well its query matches each key.
