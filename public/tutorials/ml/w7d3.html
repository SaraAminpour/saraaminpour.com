Values and the Bellman equation

How good is it to be here? Values answer that, the Bellman equation links every value to its neighbors', and value iteration solves it sweep by sweep.

Warm-up

A map of how good each square is

1 min

On Monday you judged a whole policy by running it many times. Imagine instead a map that writes, on every square, how much return the cat can still expect from there. With such a map the cat never needs to plan: it just steps to the best-looking neighbor. Today you'll compute that map.

Big idea

Values, and one look ahead

4 min

The value Vπ(s)V^\pi(s)Vπ(s) of a state is the expected return when starting there and following policy π\piπ. The action value Qπ(s,a)Q^\pi(s, a)Qπ(s,a) is the expected return when taking action aaa first and following π\piπ afterwards.

The key observation: the return from here is the first reward plus the discounted return from wherever we land. Averaging gives the Bellman equation. For the best possible behavior it reads:

V∗(s)=max⁡a∑s′P(s′∣s,a) [ r+γ V∗(s′) ]⏟Q∗(s, a)V^*(s) = \max_a \underbrace{\sum_{s'} P(s' \mid s, a)\,\big[\, r + \gamma\, V^*(s') \,\big]}_{Q^*(s,\, a)}V∗(s)=amax​Q∗(s,a)s′∑​P(s′∣s,a)[r+γV∗(s′)]​​

In words: the best value of a square is the best of its actions, and an action's value is "reward now plus discounted value next", averaged over where you might slip.

Value iteration turns the equation into an algorithm: start with V=0V = 0V=0 everywhere and keep applying the right-hand side to every state, a sweep at a time. The fish's reward reaches its neighbors in the first sweep, their neighbors in the second, and so on, until nothing changes. (With γ<1\gamma < 1γ<1 this always settles, on the one true V∗V^*V∗.)

Then the best policy is simply greedy: in every square, take the action with the largest Q∗(s,a)Q^*(s, a)Q∗(s,a).

One catch: value iteration needs the rules of the world, PPP and rrr. That's planning. Tomorrow's Q-learning learns the same values from experience, without the rulebook.

Value now = reward + discounted value next. Apply that rule everywhere until it stops changing, and act greedily.

cell 1 · the rules, and one look ahead
import numpy as np

maze = ["S...#.", ".##.#.", "...P..", ".#.##.", ".#....", "...#.F"]
rows, cols = len(maze), len(maze[0])
moves = [(-1, 0), (0, 1), (1, 0), (0, -1)]          # up, right, down, left
arrows = "↑→↓←"

def outcomes(state, action, slip=0.0):
    """Every possible (probability, next state, reward, episode over?): the same rules as on Monday."""
    results = []
    for direction, p in [(action, 1 - slip), ((action + 1) % 4, slip / 2), ((action + 3) % 4, slip / 2)]:
        if p == 0:
            continue
        r, c = state
        nr, nc = r + moves[direction][0], c + moves[direction][1]
        if not (0 <= nr < rows and 0 <= nc < cols) or maze[nr][nc] == "#":
            nr, nc = r, c
        cell = maze[nr][nc]
        reward = 1.0 if cell == "F" else -1.0 if cell == "P" else -0.04
        results.append((p, (nr, nc), reward, cell == "F"))
    return results

states = [(r, c) for r in range(rows) for c in range(cols) if maze[r][c] not in "#F"]

def q_value(V, s, a, gamma, slip):
    """One look ahead: the expected reward plus the discounted value of where we land."""
    return sum(p * (reward + (0.0 if done else gamma * V[s2])) for p, s2, reward, done in outcomes(s, a, slip))
cell 2 · value iteration
def value_iteration(gamma=0.9, slip=0.0, tol=1e-8):
    V = np.zeros((rows, cols))
    for sweep in range(1, 1000):
        new = V.copy()
        for s in states:
            new[s] = max(q_value(V, s, a, gamma, slip) for a in range(4))
        change = np.abs(new - V).max()
        V = new
        if change < tol:
            return V, sweep
    return V, sweep

def greedy_policy(V, gamma, slip):
    return {s: int(np.argmax([q_value(V, s, a, gamma, slip) for a in range(4)])) for s in states}

def show(policy):
    for r in range(rows):
        print(" ".join(arrows[policy[(r, c)]] if (r, c) in policy else ("F" if maze[r][c] == "F" else "#") for c in range(cols)))

V, sweeps = value_iteration()
print(f"settled after {sweeps} sweeps; value of the start square: {V[0, 0]:.3f}")
print(np.round(V, 2) + 0.0)                       # walls and the fish show 0
show(greedy_policy(V, 0.9, 0.0))

Wrap-up

Today in one sentence

1 min
A state's value is its expected return; the Bellman equation says value now = reward + discounted value next, maximized over actions; value iteration applies it in sweeps until it settles, and the greedy policy on V∗V^*V∗ is optimal.
Quantum link

Value iteration needs a full model of the world. For quantum systems the model itself is often the expensive part: simulating nnn qubits takes 2n2^n2n amplitudes (Quantum Computing, week 4). That's one reason quantum-control researchers turn to model-free RL, which learns from experiments directly.
