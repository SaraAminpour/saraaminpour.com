Warm-up

A problem from Flatland

1 min

This week is about one idea that quantum machine learning builds on: similarity. It starts with a trick. Imagine you live in a flat, 2D world. A ring of orange points surrounds a cluster of blue ones, and your only tool is a straight ruler. Hopeless! But if you could pull the blue points upwards into a third dimension, a flat sheet of paper could slide in between. That trick is called a feature map, and it's the doorway to kernels and quantum kernels.

Big idea

Change the space, not the model

3 min

A feature map φ\varphiφ turns each input into a longer list of features. For the ring:

φ(x1,x2)=(x1,  x2,  x12+x22)\varphi(x_1, x_2) = \big(x_1,\; x_2,\; x_1^2 + x_2^2\big)φ(x1​,x2​)=(x1​,x2​,x12​+x22​)

The new third feature is the squared distance from the center: small for the inner blue points, large for the outer ring. In this 3D feature space a flat plane z=cz = cz=c separates the classes perfectly.

Now the key idea. The model is still linear in the features, but looked at back in the original 2D picture, the plane x12+x22=cx_1^2 + x_2^2 = cx12​+x22​=c is a circle. A linear model on lifted features draws a curved boundary.

You can lift with any features you like: squares, products such as x1x2x_1x_2x1​x2​, sines... PolynomialFeatures generates all products up to some degree. The catch is cost. With 10 inputs, degree 2 makes 66 features, degree 5 makes 3,003, degree 10 makes 184,756. On Wednesday the kernel trick will get around this.

import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_circles
from sklearn.linear_model import LogisticRegression

X, y = make_circles(n_samples=300, noise=0.08, factor=0.45, random_state=0)
flat = LogisticRegression().fit(X, y)
print("straight line in 2D, accuracy:", round(flat.score(X, y), 3))
What it printed in the notebook

cell 2 · add one feature
def lift(X):
    return np.c_[X, (X ** 2).sum(axis=1)]      # add a third column: the squared distance from the center

Z = lift(X)
lifted = LogisticRegression().fit(Z, y)
print("shape before:", X.shape, "  after:", Z.shape)
print("flat plane in 3D, accuracy:", round(lifted.score(Z, y), 3))
What it printed in the notebook

from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import PolynomialFeatures

Need a hint?

Class 1 sits where x1x_1x1​ and x2x_2x2​ have the same sign. Which simple combination of them is positive exactly there?

Show a solution
one solution
def lift_xor(X):
    return np.c_[X, X[:, 0] * X[:, 1]]                # the product x1*x2 is positive exactly for class 1

print("2D line:     ", LogisticRegression().fit(Xx, yx).score(Xx, yx))
print("after lifting:", round(LogisticRegression(C=100).fit(lift_xor(Xx), yx).score(lift_xor(Xx), yx), 3))
print("One product feature turns a hopeless problem into an easy one: the right feature map is everything.")

Wrap-up

Today in one sentence

1 min
A feature map lifts data into a space where a linear model is enough; seen back in the original space, the straight boundary becomes curved.
Quantum link

This is the central idea of quantum kernel methods. A quantum circuit takes a data point xxx and prepares a state ∣φ(x)⟩|\varphi(x)\rangle∣φ(x)⟩ of nnn qubits: a feature map into a space of dimension 2n2^n2n. Tomorrow's entanglement lets that map mix features in ways that are hard to compute classically.
