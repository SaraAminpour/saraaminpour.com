The kernel trick

An SVM only ever compares points two at a time. Replace that comparison with a kernel, and the street can curve through a feature space you never compute.

Warm-up

Curving the street

1 min

On Monday you lifted data into extra features so a flat cut could separate it, and saw the cost explode with many features. Yesterday's SVM built a straight street. Today's trick gives it curves, with features that are never written down, sometimes infinitely many of them. It's the single most important idea for quantum kernels.

Big idea

Similarities instead of features

4 min

When the SVM's optimization is solved, something remarkable shows up: the data only ever appears through inner products xi⋅xjx_i \cdot x_jxi​⋅xj​, a measure of how similar two points are. If we lift the data with a feature map φ\varphiφ, those become φ(xi)⋅φ(xj)\varphi(x_i)\cdot\varphi(x_j)φ(xi​)⋅φ(xj​). The kernel trick: don't compute φ\varphiφ at all, use a function that returns the inner product directly,

k(x,x′)=φ(x)⋅φ(x′)k(x, x') = \varphi(x)\cdot\varphi(x')k(x,x′)=φ(x)⋅φ(x′)

Example. For φ(x1,x2)=(x12, 2 x1x2, x22)\varphi(x_1, x_2) = (x_1^2,\ \sqrt2\,x_1x_2,\ x_2^2)φ(x1​,x2​)=(x12​, 2​x1​x2​, x22​), a little algebra shows φ(x)⋅φ(z)=(x⋅z)2\varphi(x)\cdot\varphi(z) = (x\cdot z)^2φ(x)⋅φ(z)=(x⋅z)2. Two roads, same number; the second never builds the features.

The favorite kernel is the RBF (Gaussian) kernel:

k(x,x′)=e−γ ∥x−x′∥2k(x, x') = e^{-\gamma\,\lVert x - x'\rVert^2}k(x,x′)=e−γ∥x−x′∥2

It's 1 for identical points and fades toward 0 with distance. Its hidden feature space has infinitely many dimensions, yet each similarity costs one exponential. γ\gammaγ sets how far each point's influence reaches: small γ\gammaγ gives broad, smooth boundaries; huge γ\gammaγ makes every training point its own little island (overfitting).

And a prediction becomes a weighted vote of similarities to the support vectors:

f(x)=∑i∈SVαi yi k(xi,x)+bf(x) = \sum_{i \in \text{SV}} \alpha_i\, y_i\, k(x_i, x) + bf(x)=i∈SV∑​αi​yi​k(xi​,x)+b

Choosing a kernel is choosing what "similar" means. The SVM does the rest.

cell 1 · two roads to the same number
import numpy as np
import matplotlib.pyplot as plt
from sklearn.svm import SVC

def phi(v):
    """The feature map hidden inside the degree-2 polynomial kernel."""
    x1, x2 = v
    return np.array([x1 ** 2, np.sqrt(2) * x1 * x2, x2 ** 2])

x, z = np.array([1.0, 2.0]), np.array([3.0, -0.5])
print("phi(x) . phi(z) =", round(phi(x) @ phi(z), 6), "  <- 3 features each, then a dot product")
print("(x . z)^2       =", round((x @ z) ** 2, 6), "  <- one dot product in 2D, then a square")

cell 2 · three values of γ
from sklearn.datasets import make_circles
from matplotlib.colors import LinearSegmentedColormap

apricot_blue = LinearSegmentedColormap.from_list("apricot_blue", ["#ff8a50", "#ffffff", "#5577f5"])
Xc, yc = make_circles(n_samples=200, noise=0.08, factor=0.45, random_state=1)
gx, gy = np.meshgrid(np.linspace(-1.5, 1.5, 200), np.linspace(-1.5, 1.5, 200))

fig, axes = plt.subplots(1, 3, figsize=(11, 3.7), sharey=True, layout="constrained")
for ax, gamma in zip(axes, [0.1, 2, 100]):
    m = SVC(kernel="rbf", gamma=gamma, C=1.0).fit(Xc, yc)
    f = m.decision_function(np.c_[gx.ravel(), gy.ravel()]).reshape(gx.shape)
    ax.contourf(gx, gy, f, levels=20, cmap=apricot_blue, alpha=0.5)
    ax.contour(gx, gy, f, levels=[0], colors="#2c2842", linewidths=1.8)
    ax.scatter(Xc[:, 0], Xc[:, 1], c=np.where(yc == 0, "#ff8a50", "#5577f5"), s=10)
    ax.set_title(f"gamma = {gamma}\naccuracy {m.score(Xc, yc):.2f}, {len(m.support_)} support vectors")
    ax.set_aspect("equal")
plt.show()

cell 3 · a prediction, rebuilt by hand
m = SVC(kernel="rbf", gamma=2, C=1.0).fit(Xc, yc)
new = np.array([0.2, 0.3])
k = np.exp(-2 * np.sum((m.support_vectors_ - new) ** 2, axis=1))     # similarity to every support vector
by_hand = m.dual_coef_[0] @ k + m.intercept_[0]
print("by hand:     ", round(by_hand, 6))
print("scikit-learn:", round(m.decision_function([new])[0], 6))
print("prediction:  ", "blue (class 1)" if by_hand > 0 else "orange (class 0)")

one solution
poly = SVC(kernel="poly", degree=2, coef0=1).fit(Xc, yc)

Wrap-up

Today in one sentence

1 min
An SVM only needs similarities k(x,x′)=φ(x)⋅φ(x′)k(x, x') = \varphi(x)\cdot\varphi(x')k(x,x′)=φ(x)⋅φ(x′), so a kernel can replace a feature map we never compute; the RBF kernel uses infinitely many hidden features, with γ\gammaγ setting how local "similar" is.
Quantum link

A quantum kernel is one more similarity function: encode xxx and x′x'x′ into quantum states ∣φ(x)⟩|\varphi(x)\rangle∣φ(x)⟩, ∣φ(x′)⟩|\varphi(x')\rangle∣φ(x′)⟩ and measure their overlap, k(x,x′)=∣⟨φ(x)∣φ(x′)⟩∣2k(x, x') = |\langle\varphi(x)|\varphi(x')\rangle|^2k(x,x′)=∣⟨φ(x)∣φ(x′)⟩∣2. The feature space is the space of quantum states, huge for many qubits, and just like here, nobody ever writes its features down.
