Warm-up

70% chance of rain

1 min

This week the answers become categories: spam or not, malignant or benign. A weather app that only says "rain" or "no rain" is less useful than one that says "70% chance of rain", and the same is true for classifiers: a probability tells you how sure the model is. Logistic regression, despite its name, is the classic classifier that gives probabilities. It is also the simplest neural network: one neuron.

Big idea

Score, squash, score again

4 min

1. Score. A linear function gives each point a score: z=w1x1+w2x2+bz = w_1 x_1 + w_2 x_2 + bz=w1​x1​+w2​x2​+b. Points far on one side get big positive scores, far on the other side big negative ones.

2. Squash. The sigmoid turns any score into a number between 0 and 1:

p=σ(z)=11+e−z,σ(0)=0.5p = \sigma(z) = \frac{1}{1 + e^{-z}}, \qquad \sigma(0) = 0.5p=σ(z)=1+e−z1​,σ(0)=0.5

We read ppp as the probability of class 1. We predict class 1 when p>0.5p > 0.5p>0.5, that is when z>0z > 0z>0. The set where z=0z = 0z=0 is a straight line, so the decision boundary is straight. The size of www sets how sharp it is: a big www means the probability jumps from 0 to 1 over a short distance (a confident model).

3. Score the probabilities. MSE is a poor fit for probabilities. Instead we use cross-entropy (log loss):

L=−[ ylog⁡p+(1−y)log⁡(1−p) ]L = -\big[\,y \log p + (1 - y)\log(1 - p)\,\big]L=−[ylogp+(1−y)log(1−p)]

If the true class is y=1y = 1y=1 and the model says p=0.9p = 0.9p=0.9, the loss is small (−log⁡0.9≈0.1-\log 0.9 \approx 0.1−log0.9≈0.1). If it confidently says p=0.01p = 0.01p=0.01, the loss is huge (−log⁡0.01≈4.6-\log 0.01 \approx 4.6−log0.01≈4.6). Confident mistakes hurt most. We minimize the average loss with gradient descent, exactly like last week. (Tomorrow's lesson is all about this loss.)

cell 1 · the sigmoid
import numpy as np
import matplotlib.pyplot as plt

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

z = np.linspace(-8, 8, 200)
plt.plot(z, sigmoid(z), color="#7b5cfa", lw=3)
plt.axhline(0.5, color="#8a85a3", ls="--", lw=1)
plt.axvline(0, color="#8a85a3", ls="--", lw=1)
plt.xlabel("score z = w·x + b")
plt.ylabel("probability of class 1")
plt.title("The sigmoid squashes any number into (0, 1)")
plt.show()
print("sigmoid(-4), sigmoid(0), sigmoid(4) =", sigmoid(np.array([-4, 0, 4])).round(3))

cell 2 · train with cross-entropy
import torch
from sklearn.datasets import make_blobs

torch.set_num_threads(1)
X, y = make_blobs(n_samples=200, centers=[(-1.2, -0.6), (1.0, 0.9)], cluster_std=0.9, random_state=4)
Xt = torch.tensor(X, dtype=torch.float32)
yt = torch.tensor(y, dtype=torch.float32).reshape(-1, 1)

torch.manual_seed(0)
model = torch.nn.Linear(2, 1)
loss_fn = torch.nn.BCEWithLogitsLoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.5)

for step in range(201):
    optimizer.zero_grad()
    loss = loss_fn(model(Xt), yt)
    loss.backward()
    optimizer.step()
    if step % 50 == 0:
        print(f"step {step:3d}: cross-entropy = {loss.item():.3f}")

with torch.no_grad():
    accuracy = ((model(Xt) > 0).float() == yt).float().mean().item()
print(f"training accuracy = {accuracy:.3f}")

torch.manual_seed(0)
model = torch.nn.Linear(30, 1)
loss_fn = torch.nn.BCEWithLogitsLoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)
for step in range(300):
    optimizer.zero_grad()
    loss = loss_fn(model(Xtr_t), ytr_t)
    loss.backward()
    optimizer.step()

with torch.no_grad():
    test_acc = ((model(Xte_t) > 0).float() == yte_t).float().mean().item()
print(f"PyTorch test accuracy      = {test_acc:.3f}")
print(f"scikit-learn test accuracy = {LogisticRegression(max_iter=1000).fit((Xtr - mu) / sd, ytr).score((Xte - mu) / sd, yte):.3f}")
w = model.weight.detach().numpy().ravel()

print("most influential measurements:", ", ".join(f"{data.feature_names[i]} ({w[i]:+.2f})" for i in top))

Today in one sentence

Quantum link

A measured qubit naturally gives a probability between 0 and 1, so it can play the role of the sigmoid. The simplest quantum classifier rotates a qubit by an angle that depends on the input and reads off P(1)P(1)P(1).
