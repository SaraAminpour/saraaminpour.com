Warm-up

The brain's building block, simplified

1 min

This week is about neural networks, the models behind image recognition and language models. They are built from one tiny part, copied thousands or billions of times: the artificial neuron. Today you meet a single one, and the moment in 1969 when it looked like the whole idea was doomed.

Big idea

Weigh, add, decide

3 min

An artificial neuron takes inputs x1,…,xdx_1, \dots, x_dx1​,…,xd​, multiplies each by a weight, adds a bias, and passes the sum through an activation:

output=f(w1x1+w2x2+⋯+b)\text{output} = f(w_1x_1 + w_2x_2 + \dots + b)output=f(w1​x1​+w2​x2​+⋯+b)

With a step activation (1 if the sum is positive, else 0) it's Rosenblatt's perceptron (1958). With a sigmoid it's exactly the logistic regression of week 3. Either way, the neuron draws a straight line, w⋅x+b=0w\cdot x + b = 0w⋅x+b=0, and answers 1 on one side.

The perceptron learns with a beautifully simple rule. Go through the examples; whenever the output y^\hat yy^​ is wrong, nudge the weights toward the right answer:

w←w+η (y−y^) x,b←b+η (y−y^)w \leftarrow w + \eta\,(y - \hat y)\,x, \qquad b \leftarrow b + \eta\,(y - \hat y)w←w+η(y−y^​)x,b←b+η(y−y^​)

If some straight line separates the classes, this is guaranteed to find one (the perceptron convergence theorem). Logic gates make a perfect test: AND, OR and NAND each split their four input points with a line.

XOR doesn't: its two 1s sit on opposite corners. No line can separate them, so one neuron can never learn it. Minsky and Papert pointed this out in 1969, and interest in neural networks faded for years.

One neuron draws one straight line. Anything that needs a bend needs more neurons, arranged in layers.

A perceptron in Python

cell 1 · a neuron computes AND and OR
import numpy as np

def neuron(x, w, b):
    """A perceptron: 1 if the weighted sum is positive, else 0."""
    return int(np.dot(w, x) + b > 0)

inputs = [(0, 0), (0, 1), (1, 0), (1, 1)]
for name, w, b in [("AND", (1, 1), -1.5), ("OR", (1, 1), -0.5)]:
    print(name, [neuron(x, w, b) for x in inputs])

cell 2 · the learning rule, and XOR's failure
def train_perceptron(X, y, lr=0.5, max_passes=25):
    w, b = np.zeros(X.shape[1]), 0.0
    for p in range(1, max_passes + 1):
        mistakes = 0
        for xi, yi in zip(X, y):
            error = yi - neuron(xi, w, b)
            if error:
                w, b = w + lr * error * xi, b + lr * error
                mistakes += 1
        if mistakes == 0:
            return w, b, p
    return w, b, None

X = np.array(inputs, dtype=float)
for name, y in [("AND", [0, 0, 0, 1]), ("OR", [0, 1, 1, 1]), ("XOR", [0, 1, 1, 0])]:
    w, b, passes = train_perceptron(X, np.array(y))
    if passes:
        print(f"{name}: learned in {passes} passes, w = {w}, b = {b}")
    else:
        print(f"{name}: still making mistakes after 25 passes. No straight line separates it.")

cell 3 · the same neuron in PyTorch
import torch

torch.manual_seed(0)
Xt = torch.tensor(X, dtype=torch.float32)
yt = torch.tensor([[0.0], [0.0], [0.0], [1.0]])           # AND
neuron_t = torch.nn.Linear(2, 1)
optimizer = torch.optim.SGD(neuron_t.parameters(), lr=1.0)
for step in range(2000):
    optimizer.zero_grad()
    torch.nn.functional.binary_cross_entropy_with_logits(neuron_t(Xt), yt).backward()
    optimizer.step()
with torch.no_grad():
    print("P(1) for 00, 01, 10, 11:", torch.sigmoid(neuron_t(Xt)).ravel().numpy().round(3))

one solution
w, b, passes = train_perceptron(Xi, yi, lr=0.1, max_passes=100)
acc = np.mean([neuron(x, w, b) == t for x, t in zip(Xi, yi)])
print(f"mine: {passes} passes, w = {np.round(w, 2)}, b = {b:.2f}, accuracy {acc:.2f}")

Today in one sentence

1 min
A neuron weighs its inputs, adds a bias and applies an activation, drawing one straight boundary; the perceptron rule learns any problem a line can separate, but XOR needs more than one neuron.
Quantum link

A qubit that rotates by an angle depending on the inputs, then gets measured, behaves a lot like a neuron. Surprisingly, a single qubit can learn XOR if the data is fed in more than once: that trick, data re-uploading, is a lesson in the Quantum ML tutorial.
