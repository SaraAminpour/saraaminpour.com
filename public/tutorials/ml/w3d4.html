Warm-up

Twenty questions

1 min

Remember the game Twenty Questions? "Is it bigger than a cat? Does it live in water?" A decision tree classifies the same way, and unlike most models you can read it like a flowchart. Your course covered trees in September, so today is about seeing how a tree picks its questions.

Big idea

Questions, boxes, purity

3 min

A decision tree asks one question about one feature at each step, like "is x2≤0.36x_2 \le 0.36x2​≤0.36?", and follows the yes or no branch until it reaches a leaf, which holds a prediction (the majority class there). Each question cuts the plane with a vertical or horizontal line, so a tree carves the data into boxes.

Which question? The one that makes the two groups purest. For a group in which a fraction ppp is class 1, the Gini impurity is

G=1−p2−(1−p)2(0 when pure, 0.5 for a 50/50 mix)G = 1 - p^2 - (1-p)^2 \qquad (0 \text{ when pure},\ 0.5 \text{ for a 50/50 mix})G=1−p2−(1−p)2(0 when pure, 0.5 for a 50/50 mix)

A split into a left group LLL and a right group RRR is scored by the weighted impurity ∣L∣nGL+∣R∣nGR\frac{|L|}{n}G_L + \frac{|R|}{n}G_Rn∣L∣​GL​+n∣R∣​GR​. The tree tries every feature and every threshold and keeps the lowest score. Then it does the same inside each box, and so on. (Another popular purity score is the entropy, used by the ID3 algorithm in Mitchell's book; the trees come out very similar.)

Grow a tree deep enough and every leaf becomes pure: it memorizes the training set, noise and all. Limits like max_depth keep it honest.

cell 1 · a depth-3 tree
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_moons
from sklearn.tree import DecisionTreeClassifier, plot_tree

X, y = make_moons(n_samples=300, noise=0.25, random_state=3)
tree = DecisionTreeClassifier(max_depth=3, random_state=0).fit(X, y)
print("training accuracy of a depth-3 tree:", round(tree.score(X, y), 3))

plt.figure(figsize=(9, 4))
plot_tree(tree, feature_names=["x1", "x2"], class_names=["orange", "blue"], filled=True, rounded=True, fontsize=8)
plt.show()

cell 2 · the first question, by hand
def gini(labels):
    if len(labels) == 0:
        return 0.0
    p = np.mean(labels)
    return 1 - p ** 2 - (1 - p) ** 2

root = tree.tree_
t, f = root.threshold[0], root.feature[0]
left, right = y[X[:, f] <= t], y[X[:, f] > t]
print(f"first question: x{f + 1} <= {t:.3f}")
print(f"before: Gini {gini(y):.3f} (all {len(y)} examples)")
print(f"after:  left {len(left)} examples, Gini {gini(left):.3f}; right {len(right)}, Gini {gini(right):.3f}")
print(f"weighted Gini = {(len(left) * gini(left) + len(right) * gini(right)) / len(y):.3f}  (scikit-learn: {root.impurity[0]:.3f} before the split)")

cell 3 · training and test accuracy by depth
from sklearn.model_selection import train_test_split

X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=0)
depths = range(1, 16)
train_acc, test_acc = [], []
for d in depths:
    m = DecisionTreeClassifier(max_depth=d, random_state=0).fit(X_tr, y_tr)
    train_acc.append(m.score(X_tr, y_tr))
    test_acc.append(m.score(X_te, y_te))
plt.figure(figsize=(6, 3.2))
plt.plot(depths, train_acc, "o-", color="#17a98c", label="training")
plt.plot(depths, test_acc, "o-", color="#7b5cfa", label="test")
plt.xlabel("max_depth")
plt.ylabel("accuracy")
plt.legend()
plt.title("Deep trees memorize their training data")
plt.show()

def best_split(x, labels):
    values = np.unique(x)
    best_t, best_score = None, np.inf
    for a, b in zip(values[:-1], values[1:]):
        t = (a + b) / 2
        L, R = labels[x <= t], labels[x > t]
        score = (len(L) * gini(L) + len(R) * gini(R)) / len(labels)
        if score < best_score:
            best_t, best_score = t, score
    return best_t, best_score

t, s = best_split(X[:, 0], y)
print(f"mine:    threshold {t:.4f}, weighted Gini {s:.4f}")
print(f"sklearn: threshold {stump.tree_.threshold[0]:.4f}")
print("A whole tree repeats this search for every feature, in every box, level after level.")
