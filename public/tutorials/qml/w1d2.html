Basis and angle encoding

Warm-up

A quantum computer can't read a spreadsheet

1 min

A classical model reads numbers straight from memory. A quantum computer starts every run in ∣00…0⟩|00\ldots0\rangle∣00…0⟩, and the only way in for your data is through the gates you apply. So the very first design decision of a quantum model is the encoding: which circuit turns a data point into a state. It shapes everything after it.

Big idea

Bits, angles and scales

4 min

Basis encoding. A bit string becomes the matching basis state: 1011 becomes ∣1011⟩|1011\rangle∣1011⟩, with an X gate on every qubit whose bit is 1. Simple and exact, but each bit needs its own qubit, and real numbers would need many bits each.

Angle encoding. Each real feature becomes the angle of a rotation on its own qubit:

∣φ(x)⟩=⨂jRY(xj)∣0⟩=⨂j(cos⁡xj2 ∣0⟩+sin⁡xj2 ∣1⟩)|\varphi(x)\rangle = \bigotimes_{j} R_Y(x_j)|0\rangle = \bigotimes_{j} \Big(\cos\tfrac{x_j}{2}\,|0\rangle + \sin\tfrac{x_j}{2}\,|1\rangle\Big)∣φ(x)⟩=j⨂​RY​(xj​)∣0⟩=j⨂​(cos2xj​​∣0⟩+sin2xj​​∣1⟩)

One qubit per feature, one gate per feature: cheap and hardware friendly. Measuring ZZZ on qubit jjj gives ⟨Zj⟩=cos⁡xj\langle Z_j\rangle = \cos x_j⟨Zj​⟩=cosxj​. The state is a product state: no entanglement yet (Thursday adds it).

Scale first. Angles repeat: xxx and x+2πx + 2\pix+2π give the same state, so large raw features collide. Tiny ranges make every state almost ∣0⟩|0\rangle∣0⟩, so all data looks alike. The standard fix is week 1's habit: rescale every feature, here to [0,π][0, \pi][0,π], so each qubit sweeps from ∣0⟩|0\rangle∣0⟩ to ∣1⟩|1\rangle∣1⟩ exactly once. (Fit the scaler on the training data only!)

Dense angle encoding. A qubit has two Bloch angles, so it can carry two features: RY(x1)R_Y(x_1)RY​(x1​) sets the latitude, then RZ(x2)R_Z(x_2)RZ​(x2​) the longitude. Half the qubits, at the price of mixing two features on one sphere.

Encoding is a design choice: bits as basis states, real features as rotation angles, always scaled to a sensible range first.

cell 1 · basis encoding
import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector, SparsePauliOp, state_fidelity

def basis_encoding(bits):
    """Bit string -> computational basis state. The last character goes to qubit 0, as Qiskit prints."""
    qc = QuantumCircuit(len(bits))
    for q, b in enumerate(reversed(bits)):
        if b == "1":
            qc.x(q)
    return qc

state = Statevector(basis_encoding("1011"))
print("1011 encodes as:", state.probabilities_dict(), " (one basis state, with certainty)")
print("n bits need n qubits; the state holds exactly one bit string.")

cell 2 · angle encoding
def angle_encoding(x):
    qc = QuantumCircuit(len(x))
    for q, value in enumerate(x):
        qc.ry(value, q)
    return qc

x = np.array([0.3, 1.2, 2.5])
sv = Statevector(angle_encoding(x))
for j in range(len(x)):
    Z_j = SparsePauliOp.from_sparse_list([("Z", [j], 1.0)], num_qubits=len(x))
    print(f"qubit {j}: <Z> = {sv.expectation_value(Z_j).real:+.4f}, cos(x_{j}) = {np.cos(x[j]):+.4f}")

cell 3 · why scaling matters
from sklearn.preprocessing import MinMaxScaler

collide = state_fidelity(Statevector(angle_encoding([0.5])), Statevector(angle_encoding([0.5 + 2 * np.pi])))
print(f"fidelity of x = 0.5 and x = 0.5 + 2*pi: {collide:.4f}  (the same state!)")

raw = np.array([[12.0, 0.003], [55.0, 0.009], [97.0, 0.006]])     # features on very different scales
scaled = MinMaxScaler((0, np.pi)).fit_transform(raw)
print("scaled to [0, pi]:\n", scaled.round(3))
for i in range(3):
    for k in range(i + 1, 3):
        F = state_fidelity(Statevector(angle_encoding(scaled[i])), Statevector(angle_encoding(scaled[k])))
        print(f"   points {i} and {k}: fidelity {F:.3f}")

Show a solution
one solution
def dense_encoding(x):
    qc = QuantumCircuit(len(x) // 2)
    for q in range(len(x) // 2):
        qc.ry(x[2 * q], q)                    # latitude on the Bloch sphere
        qc.rz(x[2 * q + 1], q)                # longitude
    return qc

states = [Statevector(dense_encoding(p)) for p in points]
F = np.array([[state_fidelity(a, b) for b in states] for a in states])
print(np.round(F, 3))
print("Only the diagonal is 1: four features, two qubits, four different states.")
print("Careful: a feature in RZ only matters if the RY angle isn't 0 or pi (at the poles, longitude means nothing).")

Wrap-up

Today in one sentence

1 min
Basis encoding turns bits into basis states, angle encoding turns each scaled feature into a rotation of its own qubit (or two features per qubit with dense encoding), and the scale decides whether data points stay distinguishable.
Research link

The encoding largely decides what a quantum model can learn: with angle encoding, a model's output is a sum of sines and cosines of the features (week 3's data re-uploading lesson explores this). Choosing and scaling encodings is still mostly done by hand, an open research question.
