Big idea

The map, the pipeline, the honest truth

4 min

The map. Ask two questions: is the data classical or quantum, and is the algorithm classical or quantum? That gives four corners:

  • CC: classical data, classical algorithm. Everything in the Machine Learning tutorial.
  • CQ: classical data, quantum algorithm. Quantum kernels and trainable quantum classifiers on ordinary datasets: weeks 1 to 3 here.
  • QC: quantum data, classical algorithm. Ordinary ML on measurement results: reading qubits out, reconstructing states, calibrating devices.
  • QQ: quantum data, quantum algorithm. Learning straight from quantum states, with no measurement in between. Many researchers think this is where quantum learners will help first (week 4).

The pipeline. Every CQ model in this tutorial follows four steps:

  1. Encode the data point xxx into a state with a circuit U(x)U(x)U(x) (this week).
  2. Process it with a circuit W(θ)W(\boldsymbol\theta)W(θ) that has trainable knobs (week 3), or compare two encoded states (week 2).
  3. Measure: expectation values, estimated from shots.
  4. Learn: a classical computer turns the knobs, or trains an SVM on the measured similarities.

The honest truth. For ordinary classical data, nobody has shown that today's quantum models learn better than good classical ones; careful benchmarks keep finding strong classical baselines hard to beat. Some celebrated quantum speedups were later matched by classical "quantum-inspired" algorithms. On the other hand, advantages have been proven for specially constructed problems and, most convincingly, for learning from quantum data. And practical hurdles are real: loading data, shot noise, barren plateaus, hardware noise. That's not a reason to stop; it's the research map.

Encode, process, measure, learn, and always compare with a strong classical baseline.

The smallest quantum model

cell 1 · encode, process, measure
import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector, SparsePauliOp

Z0 = SparsePauliOp("IZ")                      # Z on qubit 0 (Qiskit reads Pauli strings right to left)

def model(x, knobs):
    qc = QuantumCircuit(2)
    qc.ry(x[0], 0)
    qc.ry(x[1], 1)                            # 1. encode: two features become two rotation angles
    qc.cx(0, 1)                               # 2. process: entangle the qubits...
    qc.ry(knobs[0], 0)
    qc.ry(knobs[1], 1)                        #    ...and turn two trainable knobs
    return Statevector(qc).expectation_value(Z0).real      # 3. measure: <Z> of qubit 0, between -1 and +1

x = np.array([0.4, 2.0])
knobs = np.array([0.3, -0.8])
output = model(x, knobs)
print(f"model output {output:+.3f}  ->  predicted class {int(output < 0)}  (class 1 when <Z> < 0)")

cell 2 · the crudest learner: random search
from sklearn.datasets import make_moons
from sklearn.preprocessing import MinMaxScaler

X, y = make_moons(n_samples=200, noise=0.15, random_state=0)
X = MinMaxScaler((0, np.pi)).fit_transform(X)            # features become angles between 0 and pi

def accuracy(knobs):
    predictions = np.array([int(model(x, knobs) < 0) for x in X])
    return (predictions == y).mean()

rng = np.random.default_rng(0)
tries = rng.uniform(-np.pi, np.pi, size=(300, 2))
scores = [accuracy(k) for k in tries]
best = int(np.argmax(scores))
print(f"random knobs: accuracy between {min(scores):.2f} and {max(scores):.2f}")
print(f"best of 300: {scores[best]:.2f} with knobs {tries[best].round(2)}")

one solution
from sklearn.linear_model import LogisticRegression

baseline = LogisticRegression().fit(X, y).score(X, y)
print(f"quantum model, best of 300 random knobs: {max(scores):.3f}")
print(f"logistic regression:                    {baseline:.3f}")
print("A quantum model is not automatically better. Every claim in QML needs a strong classical baseline,")
print("and this tutorial will keep asking for one.")
