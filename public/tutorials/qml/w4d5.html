Warm-up

From student to researcher

1 min

Three tutorials ago, a classifier was a word on a syllabus and a qubit was a symbol. Today you do what researchers do: ask a question, design a fair test, run it, and say honestly what you found. It doesn't need to be big. It needs to be honest.

Big idea

Anatomy of a mini-study

4 min
  1. Question. One sentence, answerable with the tools you have. "Is QML better?" is too big; "Does a quantum kernel find a rare class better than an RBF kernel on these digits?" is the right size.
  2. Hypothesis. Written down before you run anything, so the results can surprise you.
  3. Design. The data; the models, with at least one quantum model and a strong classical baseline; week 2's protocol; a metric that fits the question; and the readout: exact, shots or noise.
  4. Run. Once, by the protocol, without peeking.
  5. Report. A study card: the numbers with their spread, a verdict (supported, partly supported or not), the limitations, and a next step.

And the attitude: a study that finds no difference, or proves your hypothesis wrong, is a good study if its protocol was sound. Negative results are results. They tell the next person where not to dig.

A mini-study is a question, a hypothesis written first, a fair protocol, numbers with their spread, and an honest verdict that includes what the study can't tell you.

cell 2 · data and models
import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector
from sklearn.datasets import load_digits
from sklearn.decomposition import PCA
from sklearn.preprocessing import MinMaxScaler
from sklearn.model_selection import StratifiedShuffleSplit, StratifiedKFold
from sklearn.metrics import balanced_accuracy_score, recall_score, accuracy_score
from sklearn.svm import SVC

digits = load_digits()
rng = np.random.default_rng(0)
threes = np.flatnonzero(digits.target == 3)
eights = rng.choice(np.flatnonzero(digits.target == 8), size=45, replace=False)   # the rare class
idx = np.r_[threes, eights]
X, y = digits.data[idx], (digits.target[idx] == 8).astype(int)
print(f"{len(y)} images: {np.sum(y == 0)} threes and {np.sum(y == 1)} eights ({100 * y.mean():.0f}% rare)")

def zz_map(x, reps=2):
    n = len(x)
    qc = QuantumCircuit(n)
    for _ in range(reps):
        qc.h(range(n))
        for q in range(n):
            qc.p(2 * x[q], q)
        for q in range(n - 1):
            qc.cx(q, q + 1)
            qc.p(2 * (np.pi - x[q]) * (np.pi - x[q + 1]), q + 1)
            qc.cx(q, q + 1)
    return qc

def quantum_kernels(U_tr, U_te, s):
    S_tr = np.array([Statevector(zz_map(s * u)).data for u in U_tr])
    S_te = np.array([Statevector(zz_map(s * u)).data for u in U_te])
    return np.abs(S_tr.conj() @ S_tr.T) ** 2, np.abs(S_te.conj() @ S_tr.T) ** 2

def rbf_kernels(U_tr, U_te, gamma):
    sq = lambda A, B: ((A[:, None, :] - B[None, :, :]) ** 2).sum(-1)
    return np.exp(-gamma * sq(U_tr, U_tr)), np.exp(-gamma * sq(U_te, U_tr))

cell 3 · the study
def tune_and_test(kernels, knobs, y_tr, y_te, weight):
    """Pick the knob and C with the best cross-validated balanced accuracy, then test once."""
    best = (-1, None, None)
    folds = list(StratifiedKFold(5, shuffle=True, random_state=0).split(np.zeros(len(y_tr)), y_tr))
    for knob in knobs:
        K_tr, K_te = kernels(knob)
        for C in (0.1, 1, 10, 100):
            cv = np.mean([balanced_accuracy_score(y_tr[va], SVC(kernel="precomputed", C=C, class_weight=weight)
                          .fit(K_tr[np.ix_(tr, tr)], y_tr[tr]).predict(K_tr[np.ix_(va, tr)])) for tr, va in folds])
            if cv > best[0]:
                best = (cv, C, (K_tr, K_te))
    _, C, (K_tr, K_te) = best
    pred = SVC(kernel="precomputed", C=C, class_weight=weight).fit(K_tr, y_tr).predict(K_te)
    return balanced_accuracy_score(y_te, pred), recall_score(y_te, pred), accuracy_score(y_te, pred)

results = {}
splits = StratifiedShuffleSplit(n_splits=5, test_size=0.3, random_state=0).split(X, y)
for split, (tr, te) in enumerate(splits):
    pca = PCA(n_components=4).fit(X[tr])
    scaler = MinMaxScaler((0, 1)).fit(pca.transform(X[tr]))
    U_tr, U_te = scaler.transform(pca.transform(X[tr])), scaler.transform(pca.transform(X[te]))
    for weight in (None, "balanced"):
        for name, kernels, knobs in (("quantum kernel", lambda s: quantum_kernels(U_tr, U_te, s), (0.25, 0.5, 1.0)),
                                     ("RBF kernel", lambda g: rbf_kernels(U_tr, U_te, g), (0.3, 1, 3, 10))):
            key = f"{name}, {'weighted' if weight else 'unweighted'}"
            results.setdefault(key, []).append(tune_and_test(kernels, knobs, y[tr], y[te], weight))

print(f"{'model':30s}{'balanced acc.':>17s}{'rare recall':>17s}{'accuracy':>17s}")
for key, rows in results.items():
    r = np.array(rows)
    print(f"{key:30s}" + "".join(f"{m:>11.3f} ± {s:.3f}" for m, s in zip(r.mean(0), r.std(0))))
What it printed in the notebook
model                             balanced acc.      rare recall         accuracy
quantum kernel, unweighted          0.894 ± 0.029      0.814 ± 0.073      0.942 ± 0.009
RBF kernel, unweighted              0.948 ± 0.016      0.914 ± 0.053      0.968 ± 0.014
quantum kernel, weighted            0.944 ± 0.028      0.929 ± 0.078      0.954 ± 0.023
RBF kernel, weighted                0.969 ± 0.023      0.971 ± 0.035      0.968 ± 0.028

The hypothesis was only partly right. With class weighting, the two kernels are within each other's spread. Without it, the RBF kernel is ahead by about 5 points of balanced accuracy, more than the spread, and weighting lifts the quantum kernel by 5 points but the RBF by only 2. Notice how plain accuracy hides all of this: 94% and 97% look fine for every model. The surprise isn't a failure. It's the most interesting finding, and it points to the next question: why does the quantum kernel need the weighting more?
