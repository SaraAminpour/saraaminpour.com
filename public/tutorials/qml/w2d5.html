Big idea

The rules of a fair fight

4 min

A benchmark is an experiment, and these five rules are its controls. Every line of today's notebook follows them.

  1. Several splits. One train/test split is one roll of the dice. We use five random splits, the same five for every model, and report the average and the spread.
  2. Train-only preprocessing. PCA (down to 4 features, one per qubit) and the scaling to [0,1][0, 1][0,1] are fitted on the training part only, so nothing about the test points leaks in.
  3. Equal tuning. Every model gets its knobs tuned the same way, by 5-fold cross-validation on the training part: CCC for all of them, γ\gammaγ for RBF, the bandwidth sss for the quantum kernels.
  4. One look at the test set. After tuning, each model is scored on the test part once. No second tries.
  5. A strong baseline. Beating a linear model proves little. The classical opponent is a tuned RBF kernel, the standard choice for small datasets.

The contestants: a linear kernel, the RBF kernel e−γ∥x−x′∥2e^{-\gamma\|x - x'\|^2}e−γ∥x−x′∥2, and this week's two quantum kernels, angle and ZZ (2 layers), on at most four qubits. The data: moons, circles, iris (versicolor versus virginica, the hard pair) and digits 3 versus 8.

One honest remark before the race. The angle kernel has no entanglement, and its value is simply

kangle(x,x′)=∏icos⁡2 ⁣(s (xi−xi′)2),k_{\text{angle}}(x, x') = \prod_i \cos^2\!\Big(\frac{s\,(x_i - x'_i)}{2}\Big),kangle​(x,x′)=i∏​cos2(2s(xi​−xi′​)​),

which a laptop computes directly, no qubits needed. Anything it wins, a classical kernel wins.

Same splits, train-only preprocessing, equal tuning, one look at the test set, a strong baseline, and the spread: only then does a comparison mean something.

cell 1 · four datasets, two feature maps
import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector
from sklearn.datasets import make_moons, make_circles, load_iris, load_digits
from sklearn.decomposition import PCA
from sklearn.preprocessing import MinMaxScaler
from sklearn.model_selection import train_test_split, StratifiedKFold
from sklearn.svm import SVC

def angle_map(x):
    qc = QuantumCircuit(len(x))
    for q, value in enumerate(x):
        qc.ry(value, q)
    return qc

def zz_map(x, reps=2):
    n = len(x)
    qc = QuantumCircuit(n)
    for _ in range(reps):
        qc.h(range(n))
        for q in range(n):
            qc.p(2 * x[q], q)
        for q in range(n - 1):
            qc.cx(q, q + 1)
            qc.p(2 * (np.pi - x[q]) * (np.pi - x[q + 1]), q + 1)
            qc.cx(q, q + 1)
    return qc

def datasets():
    X1, y1 = make_moons(n_samples=200, noise=0.2, random_state=0)
    X2, y2 = make_circles(n_samples=200, noise=0.1, factor=0.5, random_state=0)
    iris = load_iris()
    keep = iris.target > 0                                   # versicolor versus virginica: the hard pair
    digits = load_digits()
    mask = np.isin(digits.target, [3, 8])
    return {"moons": (X1, y1), "circles": (X2, y2),
            "iris": (iris.data[keep], (iris.target[keep] == 2).astype(int)),
            "digits 3 vs 8": (digits.data[mask], (digits.target[mask] == 8).astype(int))}

print({name: X.shape for name, (X, y) in datasets().items()})

cell 2 · the protocol: tune by cross-validation, test once
C_GRID = [0.1, 1, 10, 100]

def cv_best(K, y):
    """Best C and its CV accuracy for a precomputed kernel matrix."""
    best = (-1, None)
    folds = list(StratifiedKFold(5, shuffle=True, random_state=0).split(K, y))
    for C in C_GRID:
        score = np.mean([SVC(kernel="precomputed", C=C).fit(K[np.ix_(tr, tr)], y[tr]).score(K[np.ix_(va, tr)], y[va]) for tr, va in folds])
        best = max(best, (score, C))
    return best

def quantum_kernels(fmap, U_tr, U_te, s):
    S_tr = np.array([Statevector(fmap(s * u)).data for u in U_tr])
    S_te = np.array([Statevector(fmap(s * u)).data for u in U_te])
    return np.abs(S_tr.conj() @ S_tr.T) ** 2, np.abs(S_te.conj() @ S_tr.T) ** 2

def classical_kernels(kind, U_tr, U_te, gamma):
    if kind == "linear":
        return U_tr @ U_tr.T, U_te @ U_tr.T
    sq = lambda A, B: ((A[:, None, :] - B[None, :, :]) ** 2).sum(-1)
    return np.exp(-gamma * sq(U_tr, U_tr)), np.exp(-gamma * sq(U_te, U_tr))

KNOBS = {"linear": [None], "RBF": [0.1, 1, 10, 100], "angle (quantum)": [0.25, 0.5, 1, 2, np.pi], "ZZ (quantum)": [0.25, 0.5, 1, 2, np.pi]}

def run_split(X, y, seed):
    X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=seed, stratify=y)
    if X.shape[1] > 4:
        pca = PCA(n_components=4).fit(X_tr)
        X_tr, X_te = pca.transform(X_tr), pca.transform(X_te)
    scaler = MinMaxScaler((0, 1)).fit(X_tr)
    U_tr, U_te = scaler.transform(X_tr), scaler.transform(X_te)
    scores = {}
    for model, knobs in KNOBS.items():
        best = (-1, None, None)
        for knob in knobs:
            if model == "linear" or model == "RBF":
                K_tr, K_te = classical_kernels("linear" if model == "linear" else "rbf", U_tr, U_te, knob)
            else:
                K_tr, K_te = quantum_kernels(angle_map if model.startswith("angle") else zz_map, U_tr, U_te, knob)
            cv, C = cv_best(K_tr, y_tr)
            if cv > best[0]:
                best = (cv, C, (K_tr, K_te))
        cv, C, (K_tr, K_te) = best
        scores[model] = SVC(kernel="precomputed", C=C).fit(K_tr, y_tr).score(K_te, y_te)   # the one test
    return scores
cell 3 · 4 datasets × 5 splits × 4 kernels
def benchmark(data, seeds=range(5)):
    table = {}
    for name, (X, y) in data.items():
        runs = [run_split(X, y, seed) for seed in seeds]
        table[name] = {model: (np.mean([r[model] for r in runs]), np.std([r[model] for r in runs])) for model in KNOBS}
    return table

table = benchmark(datasets())
print(f"{'dataset':15s}" + "".join(f"{m:>18s}" for m in KNOBS))
for name, row in table.items():
    print(f"{name:15s}" + "".join(f"{row[m][0]:>12.3f} ± {row[m][1]:.3f}" for m in KNOBS))

Reading the table. Linear is hopeless on circles (0.50: no straight line separates two rings) but fine on iris and digits. The angle kernel matches RBF on circles yet only ties linear on moons: its few, gentle features can draw a ring but not the moons' S-shaped boundary. ZZ stays within the spread of RBF everywhere. And the spreads, up to 5 points, are as large as most of the differences: that's how much five splits disagree.

from sklearn.datasets import load_breast_cancer

cancer = load_breast_cancer()
extra = benchmark({"breast cancer": (cancer.data, cancer.target)})
for name, row in extra.items():
    print(f"{name:15s}" + "".join(f"{row[m][0]:>12.3f} ± {row[m][1]:.3f}" for m in KNOBS))

# the biggest lead: ZZ on breast cancer. Retest it on 20 splits it has never seen.
runs = [run_split(cancer.data, cancer.target, seed) for seed in range(100, 120)]
gaps = np.array([r["ZZ (quantum)"] - r["RBF"] for r in runs])
print(f"\nZZ minus RBF on 20 fresh splits: {100 * gaps.mean():+.1f} ± {100 * gaps.std():.1f} points")
print(f"ZZ wins {np.sum(gaps > 1e-9)}, ties {np.sum(np.abs(gaps) < 1e-9)}, loses {np.sum(gaps < -1e-9)}")
print()
print("1. On five small datasets, both quantum kernels match a tuned RBF kernel within the spread,")
print("   except the angle kernel on moons, which loses by about 12 points.")
print("2. The one lead, ZZ on breast cancer, halved on fresh splits and its spread now covers zero:")
print("   the first estimate was partly luck, picked because it looked best.")
print("3. This is no evidence of a quantum advantage on classical data like these; it says nothing")
print("   about data with quantum structure, which week 4 visits.")

Why the lead shrank. You picked it because it looked best out of ten comparisons, and looking best is partly luck. Fresh splits don't share that luck, so the gap falls back toward its true size. This is called the winner's curse, and it's why a paper's best result out of many tries should be retested on new data before anyone believes it.

Wrap-up

This week in one sentence

1 min
A quantum kernel is a similarity measured by a circuit and handed to an ordinary SVM: tune its bandwidth, watch for concentration, compare it with a tuned classical kernel over many splits, and on small classical datasets expect a tie.
Research link

Bowles, Ahmed and Schuld ran this kind of fair fight at scale in 2024: a dozen popular quantum models against classical ones on six kinds of classification task, all carefully tuned. The classical baselines usually won, and removing the entanglement from the quantum models often didn't hurt them. That doesn't end the search; it moves it towards problems with quantum structure, such as learning from quantum data (week 4).

Go deeper (optional)

Bowles, Ahmed and Schuld, "Better than classical? The subtle art of benchmarking quantum machine learning models" (2024, arXiv:2403.07059). Shaydulin and Wild, "Importance of kernel bandwidth in quantum machine learning" (Physical Review A, 2022), on why tuning sss matters. On comparing two models with statistics: Dietterich, "Approximate statistical tests for comparing supervised classification learning algorithms" (Neural Computation, 1998), and Nadeau and Bengio, "Inference for the generalization error" (Machine Learning, 2003), on why repeated splits make the spread look smaller than it really is.
