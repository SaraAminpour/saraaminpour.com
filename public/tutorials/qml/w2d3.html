Warm-up

Same rules as always

1 min

A quantum kernel is just a kernel, so a quantum SVM must follow every rule from the Machine Learning tutorial: scale on the training data, tune on validation folds, test once. Quantum papers have been caught breaking these rules. Today you'll do it right, on handwritten digits with four qubits.

Big idea

The workflow, and its knobs

4 min
  1. Split into training and test sets. Shrink the features with PCA to as many as you have qubits, and scale them, fitting both on the training set only.
  2. Encode with a feature map and build KtrainK_{\text{train}}Ktrain​ and KtestK_{\text{test}}Ktest​ (yesterday's lesson).
  3. Tune by cross-validation on the training set: split its rows into folds, train on KKK's training rows and columns, validate on the validation rows against the training columns.
  4. Fit the best setting on the whole training set and test once.

The knobs. CCC is the SVM's softness (ML week 4). The quantum kernel's own knob is the bandwidth sss: multiply every feature by sss before encoding. Small sss: every state looks alike and the boundary is too simple. Large sss: every state looks different, nearly every point becomes a support vector, and the SVM memorizes. It's the quantum cousin of the RBF kernel's γ\gammaγ.

Reading the model. The decision is a weighted vote of the support vectors:

f(x)=∑i∈SVαi yi k(xi,x)+bf(x) = \sum_{i \in \text{SV}} \alpha_i\, y_i\, k(x_i, x) + bf(x)=i∈SV∑​αi​yi​k(xi​,x)+b

Only the support vectors' kernel values with xxx matter, so prediction needs one circuit per support vector, not per training point.

Treat a quantum kernel like any kernel: scale and shrink on the training set, cross-validate the bandwidth and CCC, and open the test set once.

cell 1 · 3s versus 8s on four qubits
import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector
from sklearn.datasets import load_digits
from sklearn.decomposition import PCA
from sklearn.preprocessing import MinMaxScaler
from sklearn.model_selection import train_test_split, StratifiedKFold, GridSearchCV
from sklearn.svm import SVC

# handwritten 3s versus 8s, squeezed to 4 features with PCA: one qubit per feature
digits = load_digits()
mask = np.isin(digits.target, [3, 8])
X, y = digits.data[mask], (digits.target[mask] == 8).astype(int)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=0, stratify=y)
pca = PCA(n_components=4).fit(X_train)                    # fitted on the training set only
scaler = MinMaxScaler((0, 1)).fit(pca.transform(X_train))
U_train = scaler.transform(pca.transform(X_train))
U_test = scaler.transform(pca.transform(X_test))
print("training points:", len(U_train), "  test points:", len(U_test), "  qubits:", U_train.shape[1])

def angle_map(x):
    qc = QuantumCircuit(len(x))
    for q, value in enumerate(x):
        qc.ry(value, q)
    return qc

def zz_map(x, reps=2):
    n = len(x)
    qc = QuantumCircuit(n)
    for _ in range(reps):
        qc.h(range(n))
        for q in range(n):
            qc.p(2 * x[q], q)
        for q in range(n - 1):                             # neighbors only ("linear" entanglement)
            qc.cx(q, q + 1)
            qc.p(2 * (np.pi - x[q]) * (np.pi - x[q + 1]), q + 1)
            qc.cx(q, q + 1)
    return qc

def kernels(fmap, s):
    """Training and test kernel matrices for the bandwidth s (features are multiplied by s first)."""
    S_train = np.array([Statevector(fmap(s * u)).data for u in U_train])
    S_test = np.array([Statevector(fmap(s * u)).data for u in U_test])
    return np.abs(S_train.conj() @ S_train.T) ** 2, np.abs(S_test.conj() @ S_train.T) ** 2

cell 2 · cross-validated tuning
def cv_accuracy(K, y, C, folds=5):
    scores = []
    for tr, va in StratifiedKFold(folds, shuffle=True, random_state=0).split(K, y):
        model = SVC(kernel="precomputed", C=C).fit(K[np.ix_(tr, tr)], y[tr])
        scores.append(model.score(K[np.ix_(va, tr)], y[va]))
    return np.mean(scores)

results = {}
for name, fmap in [("angle", angle_map), ("ZZ", zz_map)]:
    best = None
    for s in [0.25, 0.5, 1.0, 2.0, np.pi]:
        K_train, K_test = kernels(fmap, s)
        for C in [0.1, 1, 10, 100]:
            score = cv_accuracy(K_train, y_train, C)
            if best is None or score > best[0]:
                best = (score, s, C, K_train, K_test)
    score, s, C, K_train, K_test = best
    model = SVC(kernel="precomputed", C=C).fit(K_train, y_train)
    results[name] = (model, K_train, K_test)
    print(f"{name:5s}: best CV accuracy {score:.3f} with s = {s:.2f}, C = {C}  ->  test accuracy {model.score(K_test, y_test):.3f}")

cell 3 · the weighted vote of support vectors
model, K_train, K_test = results["ZZ"]
print(f"support vectors: {len(model.support_)} of {len(U_train)} training points")
by_hand = K_test[:, model.support_] @ model.dual_coef_.ravel() + model.intercept_[0]
print("decision function rebuilt by hand matches:", np.allclose(by_hand, model.decision_function(K_test)))

Today in one sentence

1 min
A quantum SVM is an SVM with a quantum kernel: shrink and scale on the training set, cross-validate the bandwidth and CCC with precomputed kernels, test once, and compare with an equally tuned classical kernel.
Research link

Sara's group asks how such models behave when one class is rare (ML week 3): accuracy can look great while the rare class is missed. The same workflow then needs class weights and better metrics. A natural first research project.

Go deeper (optional)
