Warm-up

An uncomfortable question

1 min

QC week 7 ended with barren plateaus: big, expressive circuits whose gradients vanish. Yesterday, noise did the same to deep circuits. The cures all shrink the circuit's world: few qubits, shallow layers, local measurements. Today's question is uncomfortable. If a circuit's world is small enough to train, is it also small enough for a classical computer to imitate?

Big idea

Trainable, therefore imitable?

4 min

What the cures share. Barren plateaus appear when a circuit spreads its state over an exponentially large space, where any one measurement sees almost nothing. Every known cure keeps the action in a small part of that space: local measurements, shallow depth, symmetries, careful starting points.

The catch. A small part of the space can often be tracked classically. Cerezo and coauthors (2023) went through the families of models that provably have no barren plateaus and argued that, for all of them, the parts of the computation that matter can be simulated classically, sometimes after collecting some data from the quantum computer first. It isn't a theorem about every possible circuit, but no clear exception is known.

A surrogate you can build today. Week 3 showed that a re-uploading classifier is a Fourier series. With 3 uploads of each of 2 features, its score is a weighted sum of

cos⁡(ω1x1+ω2x2),sin⁡(ω1x1+ω2x2),ω1,ω2∈{−3,…,3},\cos(\omega_1 x_1 + \omega_2 x_2), \quad \sin(\omega_1 x_1 + \omega_2 x_2), \qquad \omega_1, \omega_2 \in \{-3, \dots, 3\},cos(ω1​x1​+ω2​x2​),sin(ω1​x1​+ω2​x2​),ω1​,ω2​∈{−3,…,3},

which makes 49 classical features in all (counting the constant). So the trained circuit is exactly a linear model on those features, and logistic regression on them, a classical surrogate, can draw everything the circuit can, and more.

When it gets expensive. The menu holds (2L+1)d(2L + 1)^d(2L+1)d frequency vectors for ddd features: 49 for 2 features, but 5.8 million for 8. Then you sample some of them at random (random Fourier features), which often works surprisingly well.

So, baselines. A QML claim needs a strong, equally tuned classical model on the same data; a surrogate check, asking whether a classical model with the same structure does as well; and a look at how both scale.

The circuits we know how to train tend to be the circuits we can imitate, so test every quantum model against a strong classical baseline and against a surrogate built from its own structure.

cell 1 · week 3's classifier, trained
import time
import numpy as np
from qiskit import QuantumCircuit
from qiskit.circuit import ParameterVector
from qiskit.quantum_info import SparsePauliOp
from qiskit_aer.primitives import EstimatorV2 as AerEstimator
from sklearn.datasets import make_moons
from sklearn.preprocessing import MinMaxScaler
from sklearn.model_selection import train_test_split

estimator = AerEstimator(options={"backend_options": {"max_parallel_threads": 1}})
L = 3
x, w = ParameterVector("x", 2), ParameterVector("w", 4 * L)
circuit = QuantumCircuit(2)
for l in range(L):                                   # week 3's re-uploading classifier
    circuit.ry(x[0], 0)
    circuit.ry(x[1], 1)
    circuit.ry(w[4 * l], 0)
    circuit.rz(w[4 * l + 1], 0)
    circuit.ry(w[4 * l + 2], 1)
    circuit.rz(w[4 * l + 3], 1)
    circuit.cx(0, 1)

def scores(X, weight_sets):
    rows = np.array([np.concatenate([W, p]) for W in weight_sets for p in X])
    return estimator.run([(circuit, SparsePauliOp("ZI"), rows)]).result()[0].data.evs.reshape(len(weight_sets), len(X))

X, y = make_moons(n_samples=200, noise=0.15, random_state=0)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.4, random_state=0, stratify=y)
scaler = MinMaxScaler((-np.pi / 2, np.pi / 2)).fit(X_train)
X_train, X_test = scaler.transform(X_train), scaler.transform(X_test)

sigmoid = lambda z: 1 / (1 + np.exp(-z))
t0 = time.time()
theta = np.r_[0.6 * np.random.default_rng(0).normal(size=4 * L), 2.0, 0.0]
m, v = np.zeros_like(theta), np.zeros_like(theta)
shifts = [s * np.eye(4 * L)[j] for j in range(4 * L) for s in (np.pi / 2, -np.pi / 2)]
for k in range(1, 61):                               # week 3's training: cross-entropy, scale a and b, Adam
    W, a, b = theta[:-2], theta[-2], theta[-1]
    S = scores(X_train, [W] + [W + d for d in shifts])
    f, df = S[0], (S[1::2] - S[2::2]) / 2
    dz = (sigmoid(-a * f + b) - y_train) / len(y_train)
    g = np.r_[df @ (-a * dz), np.sum(-f * dz), np.sum(dz)]
    m, v = 0.9 * m + 0.1 * g, 0.999 * v + 0.001 * g ** 2
    theta = theta - 0.1 * (m / (1 - 0.9 ** k)) / (np.sqrt(v / (1 - 0.999 ** k)) + 1e-8)
W_q = theta[:-2]
predict_q = lambda X_: (sigmoid(-theta[-2] * scores(X_, [W_q])[0] + theta[-1]) > 0.5).astype(int)
print(f"quantum classifier: test accuracy {np.mean(predict_q(X_test) == y_test):.3f}, "
      f"{time.time() - t0:.1f} s to train, {60 * len(X_train) * (1 + 2 * 4 * L):,} circuit runs")
What it printed in the notebook
quantum classifier: test accuracy 0.963, 23.0 s to train, 180,000 circuit runs
cell 2 · the circuit is a linear model in disguise
def fourier_features(X, L):
    pairs = [(a, b) for a in range(-L, L + 1) for b in range(-L, L + 1) if (a, b) > (0, 0)]   # one of each ± pair
    cols = [np.ones(len(X))]
    for a, b in pairs:
        phase = a * X[:, 0] + b * X[:, 1]
        cols += [np.cos(phase), np.sin(phase)]
    return np.stack(cols, axis=1)

probe = np.random.default_rng(1).uniform(-np.pi, np.pi, size=(300, 2))
F = fourier_features(probe, L)
z = scores(probe, [W_q])[0]
coef, *_ = np.linalg.lstsq(F, z, rcond=None)
print(f"{F.shape[1]} features; largest error of the least-squares fit: {np.abs(F @ coef - z).max():.1e}")
print("the five biggest coefficients:", np.round(np.sort(np.abs(coef))[::-1][:5], 3))
What it printed in the notebook
49 features; largest error of the least-squares fit: 3.7e-15
the five biggest coefficients: [0.404 0.28  0.198 0.189 0.173]

from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import GridSearchCV

t0 = time.time()

search.fit(fourier_features(X_train, L), y_train)
acc_s = search.score(fourier_features(X_test, L), y_test)
print(f"classical surrogate: test accuracy {acc_s:.3f}, {time.time() - t0:.2f} s to tune and train, C = {search.best_params_['C']}")

one solution
pairs = [(a, b) for a in range(-L, L + 1) for b in range(-L, L + 1) if (a, b) > (0, 0)]
rng = np.random.default_rng(0)

def some_features(X, chosen):
    cols = [np.ones(len(X))]
    for a, b in chosen:
        phase = a * X[:, 0] + b * X[:, 1]
        cols += [np.cos(phase), np.sin(phase)]
    return np.stack(cols, axis=1)

for K in (2, 4, 8, 16, 24):
    accs = []
    for repeat in range(5):
        chosen = [pairs[i] for i in rng.choice(len(pairs), size=K, replace=False)]
        model = GridSearchCV(LogisticRegression(max_iter=5000), {"C": [0.1, 1, 10, 100]}, cv=5)
        model.fit(some_features(X_train, chosen), y_train)
        accs.append(model.score(some_features(X_test, chosen), y_test))
    print(f"K = {K:2d} random pairs ({2 * K + 1:2d} features): test accuracy {np.mean(accs):.3f} ± {np.std(accs):.3f}")
What it printed in the notebook
K =  2 random pairs ( 5 features): test accuracy 0.758 ± 0.169
K =  4 random pairs ( 9 features): test accuracy 0.873 ± 0.083
K =  8 random pairs (17 features): test accuracy 0.957 ± 0.015
K = 16 random pairs (33 features): test accuracy 0.978 ± 0.005
K = 24 random pairs (49 features): test accuracy 0.975 ± 0.000

With 8 random pairs, a third of the menu, the surrogate already matches the circuit's 0.963 within the spread, and 16 pairs match the full surrogate. Sampling the menu is how classical surrogates stay affordable when the full menu is astronomically large, and Landman and coauthors used exactly this idea to imitate variational quantum models.

Wrap-up

Today in one sentence

1 min
The circuits we can train tend to be the circuits classical computers can imitate: a re-uploading classifier is exactly a linear model on its Fourier features, so every quantum claim needs a strong classical baseline, a surrogate check, and evidence of where classical imitation stops scaling.
Research link

Schreiber, Eisert and Meyer (2023) built classical surrogates for quantum learning models from their frequency menus, much like today's. Earlier, Tang (2019) "dequantized" a celebrated quantum recommendation algorithm with a classical one that is only polynomially slower. Where could a quantum edge in learning survive? In problems whose data are genuinely quantum, which is tomorrow's topic.
