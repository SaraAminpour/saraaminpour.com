Warm-up

Data you can't copy

1 min

Until now the data were numbers: pixels, coordinates, rows of a table. In the QQ corner of week 1's map, the data are quantum states themselves: qubits coming out of a quantum sensor, a quantum memory or another quantum computer. You get one copy of each, you can't copy it (QC week 1's no-cloning), and looking at it changes it. How do you learn from that?

Big idea

One copy, one question

4 min

Telling two states apart. A qubit arrives in state ρ0\rho_0ρ0​ or ρ1\rho_1ρ1​, with equal odds, and you get one measurement. Measure along an axis n⃗\vec nn of the Bloch sphere and call outcome 0 "class 0". With Bloch vectors r⃗0\vec r_0r0​ and r⃗1\vec r_1r1​, your chance of being right is

P(right)=12+n⃗⋅(r⃗0−r⃗1)4.P(\text{right}) = \frac{1}{2} + \frac{\vec n \cdot (\vec r_0 - \vec r_1)}{4}.P(right)=21​+4n⋅(r0​−r1​)​.

The ceiling. QC week 6's Helstrom bound says no measurement, by any learner, can do better than 12(1+D)\frac{1}{2}(1 + D)21​(1+D), where the trace distance DDD is half the tip-to-tip distance ∣r⃗0−r⃗1∣|\vec r_0 - \vec r_1|∣r0​−r1​∣. The formula above reaches it when n⃗\vec nn points along r⃗0−r⃗1\vec r_0 - \vec r_1r0​−r1​.

A trainable measurement. Rotate each incoming state with RZ(β)R_Z(\beta)RZ​(β) and RY(α)R_Y(\alpha)RY​(α), then measure Z. The chance of being right is an expectation value, so the parameter-shift rule can train α\alphaα and β\betaβ from labeled examples. It's a one-qubit quantum classifier whose data enter as states, not as angles.

Why measuring first can be fatal. Suppose a learner only receives Z-basis records of the states. If the classes differ only in their phase, as ∣+⟩|+\rangle∣+⟩ and ∣−⟩|-\rangle∣−⟩ do, every record is a fair coin, and even the best classical model on those records is stuck at 50%. Measuring X instead gives 100%. Once measured in the wrong basis, the information is gone for good.

Where quantum learners win. With many copies, measuring several at once (an entangled measurement) or holding states in a quantum memory can beat measuring them one by one, and for some tasks it needs exponentially fewer experiments. This is where QML's provable advantages live: in learning from quantum data, not from classical tables.

With quantum data, the measurement is part of the model: the Helstrom bound 12(1+D)\frac{1}{2}(1 + D)21​(1+D) caps every learner, a trainable measurement can reach it, and measuring in the wrong basis first can erase the answer.

cell 1 · the Helstrom bound for a few pairs
import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import DensityMatrix

def state(theta, phi=0.0, noise=0.0):
    """The qubit RZ(φ)·RY(θ)|0⟩, mixed with a fraction `noise` of white noise, as a 2×2 density matrix."""
    qc = QuantumCircuit(1)
    qc.ry(theta, 0)
    qc.rz(phi, 0)
    return (1 - noise) * DensityMatrix(qc).data + noise * np.eye(2) / 2

def helstrom(rho0, rho1):
    """The best possible chance of telling rho0 from rho1 from one copy, with equal odds."""
    return 0.5 + 0.25 * np.sum(np.abs(np.linalg.eigvalsh(rho0 - rho1)))

for name, r0, r1 in [("|0⟩ versus |1⟩", state(0), state(np.pi)),
                     ("30° apart", state(0), state(np.pi / 6)),
                     ("|+⟩ versus |−⟩", state(np.pi / 2), state(np.pi / 2, np.pi)),
                     ("|+⟩ versus |−⟩, 40% noise", state(np.pi / 2, 0, 0.4), state(np.pi / 2, np.pi, 0.4))]:
    print(f"{name:28s} best possible success: {helstrom(r0, r1):.3f}")

cell 2 · a quantum dataset
def sensor(n, seed):
    rng = np.random.default_rng(seed)
    labels = rng.integers(0, 2, n)
    phis = 0.6 + np.pi * labels + 0.25 * rng.normal(size=n)
    return [state(1.2, phi) for phi in phis], labels

train_states, y_train = sensor(200, 0)
test_states, y_test = sensor(400, 1)
avg0 = np.mean([s for s, c in zip(train_states, y_train) if c == 0], axis=0)
avg1 = np.mean([s for s, c in zip(train_states, y_train) if c == 1], axis=0)
Z = np.diag([1.0, -1.0])
print("chance of reading 0 in the Z basis, class 0 and class 1:",
      round(np.real(np.trace(avg0 @ (np.eye(2) + Z) / 2)), 3), round(np.real(np.trace(avg1 @ (np.eye(2) + Z) / 2)), 3))
print(f"best possible success on this data (Helstrom): {helstrom(avg0, avg1):.3f}")

cell 3 · a trainable measurement
def rz(t):
    return np.diag([np.exp(-1j * t / 2), np.exp(1j * t / 2)])

def ry(t):
    c, s = np.cos(t / 2), np.sin(t / 2)
    return np.array([[c, -s], [s, c]])

def p_zero(rho, alpha, beta):
    """Chance that the rotated state reads 0."""
    U = ry(alpha) @ rz(beta)
    return np.real((U @ rho @ U.conj().T)[0, 0])

def success(states, labels, alpha, beta):
    p0 = np.array([p_zero(s, alpha, beta) for s in states])
    return np.mean(np.where(labels == 0, p0, 1 - p0))

alpha, beta = 0.3, 0.2                                         # start somewhere arbitrary
for step in range(60):
    shift = np.pi / 2
    g_a = (success(train_states, y_train, alpha + shift, beta) - success(train_states, y_train, alpha - shift, beta)) / 2
    g_b = (success(train_states, y_train, alpha, beta + shift) - success(train_states, y_train, alpha, beta - shift)) / 2
    alpha, beta = alpha + 0.8 * g_a, beta + 0.8 * g_b          # gradient ascent: maximise the success
    if step % 20 == 0:
        print(f"step {step:2d}: training success {success(train_states, y_train, alpha, beta):.3f}")
print(f"learned measurement: α = {alpha:.2f}, β = {beta:.2f}")

rng = np.random.default_rng(2)
one_shot = np.array([rng.random() < p_zero(s, alpha, beta) for s in test_states])   # True means it read 0
print(f"expected test success (exact probabilities): {success(test_states, y_test, alpha, beta):.3f}")
print(f"one round of ONE measurement per test state: {np.mean((~one_shot).astype(int) == y_test):.3f}   (wobbles by about ±0.01)")
test0 = np.mean([s for s, c in zip(test_states, y_test) if c == 0], axis=0)
test1 = np.mean([s for s, c in zip(test_states, y_test) if c == 1], axis=0)
print(f"best possible on the test states (Helstrom): {helstrom(test0, test1):.3f}")

cell 4 · a learner that only gets Z records
bits_train = np.array([rng.random() < p_zero(s, 0.0, 0.0) for s in train_states])
bits_test = np.array([rng.random() < p_zero(s, 0.0, 0.0) for s in test_states])
for bit in (True, False):                                      # the best classical rule: majority class for each bit value
    sel = bits_train == bit
    print(f"read {'0' if bit else '1'}: {sel.sum()} training states, {np.mean(y_train[sel]):.2f} of them class 1")
rule = {bit: int(np.mean(y_train[bits_train == bit]) > 0.5) for bit in (True, False)}
print(f"test success of the best rule on Z records: {np.mean(np.array([rule[b] for b in bits_test]) == y_test):.3f}")

Cell 2: in the Z basis, both classes read 0 with exactly the same chance, 0.681. Cell 3: the trained measurement's expected success on the test states, 0.953, is exactly the Helstrom bound. With one measurement per state, any single round wobbles around it by about ±0.01, and may even land above it by luck. Cell 4: the best classical rule on Z records scores 0.512, a coin flip.

def noisy(states, p):
    return [(1 - p) * s + p * np.eye(2) / 2 for s in states]

def train_measurement(states, labels, steps=60):
    a, b = 0.3, 0.2
    for _ in range(steps):
        g_a = (success(states, labels, a + np.pi / 2, b) - success(states, labels, a - np.pi / 2, b)) / 2
        g_b = (success(states, labels, a, b + np.pi / 2) - success(states, labels, a, b - np.pi / 2)) / 2
        a, b = a + 0.8 * g_a, b + 0.8 * g_b
    return a, b

for p in (0, 0.2, 0.4, 0.6):
    tr, te = noisy(train_states, p), noisy(test_states, p)
    a, b = train_measurement(tr, y_train)
    t0 = np.mean([s for s, c in zip(te, y_test) if c == 0], axis=0)
    t1 = np.mean([s for s, c in zip(te, y_test) if c == 1], axis=0)
    print(f"p = {p:.1f}: best possible {helstrom(t0, t1):.3f}, learned measurement {success(te, y_test, a, b):.3f} (expected)")
print("White noise shrinks the gap between the two classes' states, and the bound falls with it: past the bound,")
print("no learner, quantum or classical, can do better from one copy.")

At every noise level, the learned measurement sits exactly on the bound: it can be reached, and nothing can beat it. White noise shrinks every Bloch vector by (1−p)(1 - p)(1−p), so the bound's height above ½ shrinks by the same factor.

Wrap-up

Today in one sentence

1 min
When the data are quantum states, the measurement is part of the model: the Helstrom bound caps every learner at 12(1+D)\frac{1}{2}(1 + D)21​(1+D), a trainable measurement can reach it, measuring in the wrong basis first can erase the answer, and the clearest quantum advantages in learning come from data like these.
Research link

Huang and coauthors (Science, 2022) showed on Google's quantum processor that a learner with a quantum memory, able to measure two copies of a state together, can learn some properties of physical systems from exponentially fewer experiments than any learner that measures copies one at a time. Huang, Kueng and Preskill's "classical shadows" (Nature Physics, 2020) show the other side: how much a clever classical record of quantum data can still predict.
