Warm-up

A twist of the globe

1 min

This week you've met four half-turns: X, Y, Z and H. Today the turns get a dial. Here is the secret that makes one-qubit quantum computing easy to picture: every gate is a rotation of the sphere. Learn about eight of them and you know them all.

Big idea

Matrices that rotate

4 min

A gate is a 2×22\times 22×2 matrix UUU that maps the amplitude vector to a new one, ∣ψ′⟩=U∣ψ⟩|\psi'\rangle = U|\psi\rangle∣ψ′⟩=U∣ψ⟩. It must keep probabilities adding up to 1, which makes it unitary. On the Bloch sphere, every unitary is a rotation about some axis by some angle:

gaterotationfor example
Xhalf turn (180°) about the x-axis∣0⟩↔∣1⟩|0\rangle \leftrightarrow |1\rangle∣0⟩↔∣1⟩
Yhalf turn about the y-axis∣0⟩→∣1⟩|0\rangle \to |1\rangle∣0⟩→∣1⟩ (with a phase)
Zhalf turn about the z-axis∣+⟩↔∣−⟩|+\rangle \leftrightarrow |-\rangle∣+⟩↔∣−⟩, poles stay put
Hhalf turn about the diagonal between x and z∣0⟩↔∣+⟩|0\rangle \leftrightarrow |+\rangle∣0⟩↔∣+⟩, ∣1⟩↔∣−⟩|1\rangle \leftrightarrow |-\rangle∣1⟩↔∣−⟩
S, Tquarter turn (90°) and eighth turn (45°) about zS∣+⟩=∣+i⟩S|+\rangle = |{+i}\rangleS∣+⟩=∣+i⟩
RX(θ\thetaθ), RY(θ\thetaθ), RZ(θ\thetaθ)any angle θ\thetaθ about x, y or zRY(θ)∣0⟩RY(\theta)|0\rangleRY(θ)∣0⟩ has P(1)=sin⁡2θ2P(1) = \sin^2\frac{\theta}{2}P(1)=sin22θ​

For example RY(θ)=(cos⁡θ2−sin⁡θ2sin⁡θ2cos⁡θ2)RY(\theta) = \begin{pmatrix}\cos\frac{\theta}{2} & -\sin\frac{\theta}{2}\\ \sin\frac{\theta}{2} & \cos\frac{\theta}{2}\end{pmatrix}RY(θ)=(cos2θ​sin2θ​​−sin2θ​cos2θ​​). The rotation gates are special because their angle is a continuous knob, exactly what gradient descent needs.

Order matters

A circuit is read left to right, but matrices are written right to left: the circuit "H then S" is the matrix product S HS\,HSH, because HHH acts on the state first. Rotations about different axes don't commute: H then S is not the same as S then H.

cell 1 · the matrices
import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Operator, Statevector, Pauli

def show(matrix):
    """Print a small complex matrix neatly."""
    for row in matrix:
        cells = []
        for z in row:
            z = complex(np.round(z, 3))
            cells.append(f"{z.real:+.3f}" if abs(z.imag) < 1e-9 else f"{z.real:+.3f}{z.imag:+.3f}i")
        print("   [ " + "   ".join(cells) + " ]")

for name in ["x", "z", "h", "s"]:
    qc = QuantumCircuit(1)
    getattr(qc, name)(0)                     # the same as qc.x(0), qc.z(0), ...
    print(f"{name.upper()} =")
    show(Operator(qc).data)

cell 2 · follow the Bloch vector
def bloch_vector(sv):
    return [round(float(np.real(sv.expectation_value(Pauli(p)))), 3) for p in "XYZ"]

state = Statevector.from_label("0")
print("start      :", bloch_vector(state))
for gate in ["h", "s", "s", "h"]:
    qc = QuantumCircuit(1)
    getattr(qc, gate)(0)
    state = state.evolve(qc)
    print(f"after {gate.upper():<5}:", bloch_vector(state))

cell 3 · gate identities
def same(a, b):
    return Operator(a).equiv(Operator(b))    # equal up to a global phase

hh = QuantumCircuit(1); hh.h(0); hh.h(0)
hzh = QuantumCircuit(1); hzh.h(0); hzh.z(0); hzh.h(0)
x_gate = QuantumCircuit(1); x_gate.x(0)
nothing = QuantumCircuit(1)

print("H then H  == do nothing ?", same(hh, nothing))
print("H, Z, H   == X ?         ", same(hzh, x_gate))

cell 4 · a rotation with a knob
import matplotlib.pyplot as plt
from qiskit.circuit import Parameter

theta = Parameter("θ")
qc = QuantumCircuit(1)
qc.ry(theta, 0)

angles = np.linspace(0, 2 * np.pi, 61)
p1 = [Statevector(qc.assign_parameters({theta: a})).probabilities()[1] for a in angles]

plt.plot(angles, p1, "o", ms=4, label="Qiskit")
plt.plot(angles, np.sin(angles / 2) ** 2, label="sin²(θ/2)")
plt.xlabel("θ (radians)")
plt.ylabel("P(1)")
plt.title(r"RY(θ) applied to $|0\rangle$")
plt.legend()
plt.show()

Show a solution
one solution
for name, amps in {"|0>": [1, 0], "|1>": [0, 1], "|+>": [s, s]}.items():
    a = Statevector(amps).evolve(ry)
    b = Statevector(amps).evolve(had)
    print(f"on {name}: same result? {a.equiv(b)}")
print("same gate?", Operator(ry).equiv(Operator(had)))
fix = QuantumCircuit(1)
fix.z(0)
fix.ry(np.pi / 2, 0)
print("Z then RY(pi/2) equals H?", Operator(fix).equiv(Operator(had)))
print("They agree on |0> and on |1> separately, but RY(pi/2)|1> = -|->: the minus sign is a global phase")
print("for that input alone, yet a *relative* phase once |0> and |1> are mixed. Compare gates as matrices.")

Wrap-up

Today in one sentence

1 min
Every one-qubit gate is a rotation of the Bloch sphere: X, Y, Z are half turns about the axes, H swaps the x and z axes, S and T are small turns about z, and RX, RY, RZ turn by any angle you choose.
Quantum link

A parameterised quantum circuit, the workhorse of quantum ML, is mostly a sequence of RX, RY and RZ dials (plus a few two-qubit gates). Training it means finding good angles, the same job gradient descent did for www and bbb yesterday.
