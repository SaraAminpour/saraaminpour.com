Warm-up

Two coins that always agree

1 min

Yesterday's CNOT made a pair of qubits that always agree when measured. "So what," a skeptic says, "I can glue two coins together so they always land the same way." Today you'll see what the glued coins can't do, and meet the whole family of these special states.

Big idea

The Bell family

4 min

The four Bell states are the maximally entangled states of two qubits:

∣Φ±⟩=12(∣00⟩±∣11⟩),∣Ψ±⟩=12(∣01⟩±∣10⟩)|\Phi^\pm\rangle = \tfrac{1}{\sqrt2}\big(|00\rangle \pm |11\rangle\big), \qquad |\Psi^\pm\rangle = \tfrac{1}{\sqrt2}\big(|01\rangle \pm |10\rangle\big)∣Φ±⟩=2​1​(∣00⟩±∣11⟩),∣Ψ±⟩=2​1​(∣01⟩±∣10⟩)

One recipe makes them all: H on qubit 0 and a CNOT give ∣Φ+⟩|\Phi^+\rangle∣Φ+⟩; an X first gives a Ψ\PsiΨ; a Z gives the minus sign. Their correlations (the average of "+1 if the two results agree, −1 if they disagree") are perfect in every basis:

ZZXXYY
∣Φ+⟩|\Phi^+\rangle∣Φ+⟩+1+1−1
∣Φ−⟩|\Phi^-\rangle∣Φ−⟩+1−1+1
∣Ψ+⟩|\Psi^+\rangle∣Ψ+⟩−1+1+1
∣Ψ−⟩|\Psi^-\rangle∣Ψ−⟩−1−1−1

The ZZ and XX signs alone tell the four apart. Meanwhile each qubit on its own is completely random in every basis: its Bloch arrow has length 0. All the information sits in the correlations, none in the parts.

Why glued coins fail. Coins can be prepared to agree in one "basis". But the CHSH test measures each side along two different angles and combines four correlations into a number SSS. If the outcomes were decided in advance, like glued coins, ∣S∣≤2|S| \le 2∣S∣≤2, always. A Bell state reaches 22≈2.832\sqrt2 \approx 2.8322​≈2.83. Experiments confirmed this so thoroughly that it earned the 2022 Nobel Prize in Physics.

Entanglement is correlation without pre-written answers: no list of outcomes, decided in advance, can reproduce it.

cell 1 · one recipe, four states
import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector, SparsePauliOp, partial_trace
from qiskit.primitives import StatevectorSampler

def bell(name):
    """H + CNOT makes |Phi+>; an X makes the Psi states, a Z puts in the minus sign."""
    qc = QuantumCircuit(2)
    if name in ("Psi+", "Psi-"):
        qc.x(1)
    qc.h(0)
    qc.cx(0, 1)
    if name in ("Phi-", "Psi-"):
        qc.z(0)
    return qc

for name in ["Phi+", "Phi-", "Psi+", "Psi-"]:
    print(f"{name}: amplitudes (00, 01, 10, 11) = {np.round(Statevector(bell(name)).data.real, 3) + 0}")

cell 4 · the CHSH test
sampler = StatevectorSampler(seed=4)

def E(theta_a, theta_b, shots=20000):
    qc = bell("Phi+")
    qc.ry(-theta_a, 0)          # turn so that "measure along theta" becomes "measure Z"
    qc.ry(-theta_b, 1)
    qc.measure_all()
    counts = sampler.run([qc], shots=shots).result()[0].data.meas.get_counts()
    agree = counts.get("00", 0) + counts.get("11", 0)
    return (2 * agree - shots) / shots

def E_exact(theta_a, theta_b):
    qc = bell("Phi+")
    qc.ry(-theta_a, 0)
    qc.ry(-theta_b, 1)
    p = Statevector(qc).probabilities()            # order 00, 01, 10, 11
    return p[0] - p[1] - p[2] + p[3]

a, a2, b, b2 = 0, np.pi / 2, np.pi / 4, -np.pi / 4
S_shots = E(a, b) + E(a, b2) + E(a2, b) - E(a2, b2)
S_exact = E_exact(a, b) + E_exact(a, b2) + E_exact(a2, b) - E_exact(a2, b2)
print(f"S from 4 x 20000 shots = {S_shots:.3f}  (shot noise is about ±0.01)")
print(f"S exact                = {S_exact:.3f}  = 2·sqrt(2)")
print("Any classical explanation gives |S| <= 2: the Bell state breaks that limit.")

one solution
def correlation(basis, shots=4000):
    qc = mystery()
    if basis == "X":
        qc.h([0, 1])
    qc.measure_all()
    counts = sampler.run([qc], shots=shots).result()[0].data.meas.get_counts()
    agree = counts.get("00", 0) + counts.get("11", 0)
    return (2 * agree - shots) / shots

zz, xx = correlation("Z"), correlation("X")
table = {(1, 1): "Phi+", (1, -1): "Phi-", (-1, 1): "Psi+", (-1, -1): "Psi-"}
guess = table[(int(np.sign(zz)), int(np.sign(xx)))]
print(f"ZZ = {zz:+.2f}, XX = {xx:+.2f}  ->  it's {guess}   (the secret was {_secret})")

Wrap-up

Today in one sentence

1 min
The four Bell states are perfectly correlated in every basis while each qubit alone is pure randomness; their correlation signs identify them, and the CHSH test shows no pre-arranged trick can mimic them.
Machine-learning link

Machine learning lives on correlations between features. A quantum feature map with CNOTs (Quantum ML tutorial, week 1) creates entangled correlations between the qubits that hold different features, a kind of interaction no product state can express.

Go deeper (optional)

Nielsen and Chuang, section 2.6 ("EPR and the Bell inequality") derives the classical limit of 2. The 2022 Nobel Prize in Physics (Aspect, Clauser and Zeilinger) was awarded for the experiments.
