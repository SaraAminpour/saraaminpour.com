Amplitudes and the Born rule

Amplitudes are arrows with a length and a direction. The length sets the odds; the direction, the phase, only shows when two states are compared.

Warm-up

Same odds, different states

1 min

Yesterday's exercise ended with a puzzle: 12(1,1)\frac{1}{\sqrt2}(1, 1)2​1​(1,1) and 12(1,i)\frac{1}{\sqrt2}(1, i)2​1​(1,i) both give 50/50 odds, yet they are different states. If the odds are the same, what is different? The answer is the phase, and it is the secret ingredient of every quantum algorithm.

Big idea

Amplitudes are arrows

4 min

A complex number z=a+biz = a + biz=a+bi is an arrow in a plane: aaa to the right, bbb up. Every arrow has a length ∣z∣=a2+b2|z| = \sqrt{a^2 + b^2}∣z∣=a2+b2​ and a direction, its phase φ\varphiφ. Euler's formula writes it as

z=∣z∣ eiφ=∣z∣(cos⁡φ+isin⁡φ)z = |z|\,e^{i\varphi} = |z|(\cos\varphi + i\sin\varphi)z=∣z∣eiφ=∣z∣(cosφ+isinφ)

The Born rule only uses the length: P(0)=∣α∣2P(0) = |\alpha|^2P(0)=∣α∣2 and P(1)=∣β∣2P(1) = |\beta|^2P(1)=∣β∣2. Turning an arrow changes nothing about those odds. So are phases useless? Not at all. There are two very different kinds:

Global phase: meaningless

Turn both arrows by the same angle: eiθ∣ψ⟩e^{i\theta}|\psi\rangleeiθ∣ψ⟩. No experiment can ever tell the difference, so physicists treat ∣ψ⟩|\psi\rangle∣ψ⟩ and eiθ∣ψ⟩e^{i\theta}|\psi\rangleeiθ∣ψ⟩ as the same state.

Relative phase: real

The angle between the arrows of α\alphaα and β\betaβ. ∣+⟩=12(∣0⟩+∣1⟩)|+\rangle = \frac{1}{\sqrt2}(|0\rangle + |1\rangle)∣+⟩=2​1​(∣0⟩+∣1⟩) and ∣−⟩=12(∣0⟩−∣1⟩)|-\rangle = \frac{1}{\sqrt2}(|0\rangle - |1\rangle)∣−⟩=2​1​(∣0⟩−∣1⟩) differ only in it, yet they are as different as two states can be.

To see a relative phase, compare states. The inner product of two states multiplies matching amplitudes, conjugating the first one (the "bra" ⟨ϕ∣\langle\phi|⟨ϕ∣ is the conjugate of the ket ∣ϕ⟩|\phi\rangle∣ϕ⟩):

⟨ϕ∣ψ⟩=ϕ0‾ ψ0+ϕ1‾ ψ1\langle\phi|\psi\rangle = \overline{\phi_0}\,\psi_0 + \overline{\phi_1}\,\psi_1⟨ϕ∣ψ⟩=ϕ0​​ψ0​+ϕ1​​ψ1​

The general Born rule: if you measure in a way that has ∣ϕ⟩|\phi\rangle∣ϕ⟩ as one of its outcomes, the chance of getting it is P=∣⟨ϕ∣ψ⟩∣2P = |\langle\phi|\psi\rangle|^2P=∣⟨ϕ∣ψ⟩∣2.

With ∣ϕ⟩=∣0⟩|\phi\rangle = |0\rangle∣ϕ⟩=∣0⟩ this is just ∣α∣2|\alpha|^2∣α∣2 again. With ∣ϕ⟩=∣+⟩|\phi\rangle = |+\rangle∣ϕ⟩=∣+⟩ it depends on the relative phase: ∣⟨+∣+⟩∣2=1|\langle +|+\rangle|^2 = 1∣⟨+∣+⟩∣2=1 but ∣⟨+∣−⟩∣2=0|\langle +|-\rangle|^2 = 0∣⟨+∣−⟩∣2=0. That number, between 0 (perfectly distinguishable) and 1 (identical), measures how similar two states are.

Python writes iii as 1j. abs gives the length and np.angle the phase:

cell 1 · arrows as numbers
import numpy as np

z = 0.6 * np.exp(1j * np.pi / 3)          # length 0.6, phase 60 degrees
print("z          =", np.round(z, 3))
print("length |z| =", round(abs(z), 3))
print("phase      =", round(np.degrees(np.angle(z)), 1), "degrees")
print("|z|^2      =", round(abs(z) ** 2, 3), " <- the only part the Born rule uses")

cell 2 · same odds, different states
from qiskit.quantum_info import Statevector

s = 1 / np.sqrt(2)
states = {
    "|0>": Statevector([1, 0]),
    "|1>": Statevector([0, 1]),
    "|+>": Statevector([s, s]),
    "|->": Statevector([s, -s]),
    "|+i>": Statevector([s, 1j * s]),
}
for name in ["|+>", "|->", "|+i>"]:
    print(f"{name:>4}: amplitudes {np.round(states[name].data, 3)}  P(0), P(1) = {states[name].probabilities().round(2)}")
What it printed in the notebook

|+i>: amplitudes [0.707+0.j    0.   +0.707j]  P(0), P(1) = [0.5 0.5]

Now every overlap at once. np.vdot conjugates its first argument, exactly like the bra:

names = list(states)
print("        " + "".join(f"{n:>7}" for n in names))

cell 4 · a global phase changes nothing
psi = Statevector([0.6, 0.8j])
turned = Statevector(np.exp(1j * 1.234) * psi.data)       # turn both arrows by 1.234 radians
print("same amplitudes?    ", np.allclose(psi.data, turned.data))
print("same probabilities? ", np.allclose(psi.probabilities(), turned.probabilities()))
print("same physical state?", psi.equiv(turned))
print("same overlap with |+>?", np.isclose(abs(np.vdot(states["|+>"].data, psi.data)) ** 2,

The state ∣ψ⟩=0.6 ∣0⟩+0.8i ∣1⟩|\psi\rangle = 0.6\,|0\rangle + 0.8i\,|1\rangle∣ψ⟩=0.6∣0⟩+0.8i∣1⟩ has odds 36/64. How much does it look like ∣+⟩|+\rangle∣+⟩, and how much like ∣+i⟩|+i\rangle∣+i⟩? Compute ∣⟨+∣ψ⟩∣2|\langle +|\psi\rangle|^2∣⟨+∣ψ⟩∣2 and ∣⟨+i∣ψ⟩∣2|\langle +i|\psi\rangle|^2∣⟨+i∣ψ⟩∣2.

Need a hint?

abs(np.vdot(plus, psi)) ** 2 is ∣⟨+∣ψ⟩∣2|\langle +|\psi\rangle|^2∣⟨+∣ψ⟩∣2. By hand: ⟨+i∣=12(1,−i)\langle +i| = \frac{1}{\sqrt2}(1, -i)⟨+i∣=2​1​(1,−i), and (−i)(0.8i)=0.8(-i)(0.8i) = 0.8(−i)(0.8i)=0.8.

Show a solution
one solution
overlap_plus = abs(np.vdot(plus, psi)) ** 2
overlap_plus_i = abs(np.vdot(plus_i, psi)) ** 2
print(f"|<+|psi>|^2  = {overlap_plus:.2f}")
print(f"|<+i|psi>|^2 = {overlap_plus_i:.2f}")
print("By hand: <+i|psi> = (0.6 + (-i)(0.8i)) / sqrt(2) = 1.4 / sqrt(2), and 1.4^2 / 2 = 0.98.")
print("So psi is almost |+i>, even though its 0/1 odds are 36/64.")

Today in one sentence

1 min
Amplitudes are complex arrows. Their lengths set the 0/1 odds, a global phase means nothing, and the relative phase is real: it shows up when states are compared, P=∣⟨ϕ∣ψ⟩∣2P = |\langle\phi|\psi\rangle|^2P=∣⟨ϕ∣ψ⟩∣2.
Machine-learning link

∣⟨ϕ∣ψ⟩∣2|\langle\phi|\psi\rangle|^2∣⟨ϕ∣ψ⟩∣2 is a similarity score between 0 and 1. In the Quantum ML tutorial you'll turn two data points into two states and use exactly this number as a kernel: a quantum cousin of the distances kNN uses in Machine Learning week 1.
