Warm-up

A sphere you can steer

1 min

This week you've learned to turn the Bloch sphere: half-turns, quarter-turns and turns by any angle. Today's project asks the natural question: from ∣0⟩|0\rangle∣0⟩ at the north pole, can you reach any point? And with how few gates?

Big idea

Latitude, then longitude

3 min

A point on a globe is fixed by its latitude and longitude. A qubit state is fixed by two angles too:

∣ψ⟩=cos⁡θ2 ∣0⟩+eiφsin⁡θ2 ∣1⟩|\psi\rangle = \cos\tfrac{\theta}{2}\,|0\rangle + e^{i\varphi}\sin\tfrac{\theta}{2}\,|1\rangle∣ψ⟩=cos2θ​∣0⟩+eiφsin2θ​∣1⟩

So two turns are enough:

  1. RY(θ)R_Y(\theta)RY​(θ) tilts the arrow down from the north pole to latitude θ\thetaθ (along the x–z plane).
  2. RZ(φ)R_Z(\varphi)RZ​(φ) then spins it around the vertical axis to longitude φ\varphiφ, without changing its height.

The result equals ∣ψ⟩|\psi\rangle∣ψ⟩ up to a global phase, which, as you know, doesn't matter. To score how close you are to a target, use the fidelity:

F=∣⟨target∣ψ⟩∣2=12(1+cos⁡γ)F = |\langle\text{target}|\psi\rangle|^2 = \tfrac12(1 + \cos\gamma)F=∣⟨target∣ψ⟩∣2=21​(1+cosγ)

where γ\gammaγ is the angle between the two arrows. Same point: F=1F = 1F=1. Opposite points: F=0F = 0F=0. Arrows at right angles: F=12F = \frac12F=21​.

Preparing a chosen state from ∣0⟩|0\rangle∣0⟩ is called state preparation. For one qubit it takes just two rotations.

Steering in Qiskit

cell 1 · two rotations, one state
import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector, state_fidelity

def prepare(theta, phi):
    """|0> -> RY(theta) -> RZ(phi): the point at latitude theta, longitude phi."""
    qc = QuantumCircuit(1)
    qc.ry(theta, 0)
    qc.rz(phi, 0)
    return qc

theta, phi = np.radians(120), np.radians(45)
made = Statevector(prepare(theta, phi))
target = Statevector([np.cos(theta / 2), np.exp(1j * phi) * np.sin(theta / 2)])
print(prepare(theta, phi).draw("text"))
print("prepared:", np.round(made.data, 3))
print("target:  ", np.round(target.data, 3))
print("the same state, up to a global phase?", made.equiv(target))

for err in [0, 5, 20, 45, 90]:
    near = Statevector(prepare(theta + np.radians(err), phi))
    print(f"tilt off by {err:2d} degrees: fidelity {state_fidelity(near, target):.3f}")

Project

Project: a state compiler

4 min

Write angles_for(state), which takes any one-qubit state and returns the (θ,φ)(\theta, \varphi)(θ,φ) that prepare needs. Then test it on five random states: every fidelity should be 1.

  1. ∣α∣=cos⁡θ2|\alpha| = \cos\frac\theta2∣α∣=cos2θ​, so θ=2arccos⁡∣α∣\theta = 2\arccos|\alpha|θ=2arccos∣α∣.
  2. The relative phase is the angle of β\betaβ minus the angle of α\alphaα: φ=arg⁡β−arg⁡α\varphi = \arg\beta - \arg\alphaφ=argβ−argα.

def angles_for(state):
    a, b = state.data
    theta = 0.0   # TODO: 2 * arccos(|a|)   (np.arccos, abs)
    phi = 0.0     # TODO: the phase of b minus the phase of a   (np.angle)
    return theta, phi

rng = np.random.default_rng(7)
for _ in range(5):
    v = rng.normal(size=2) + 1j * rng.normal(size=2)
    goal = Statevector(v / np.linalg.norm(v))          # a random state
    th, ph = angles_for(goal)
    print(f"theta = {np.degrees(th):6.1f}, phi = {np.degrees(ph):7.1f}  ->  fidelity {state_fidelity(Statevector(prepare(th, ph)), goal):.4f}")
Need a hint?

np.arccos(abs(a)) and np.angle(b) - np.angle(a). Rounding can push abs(a) a hair above 1, so np.clip(abs(a), 0, 1) is a safe habit.

Show a solution
one solution
def angles_for(state):
    a, b = state.data
    theta = 2 * np.arccos(np.clip(abs(a), 0, 1))
    phi = np.angle(b) - np.angle(a)
    return theta, phi

rng = np.random.default_rng(7)
for _ in range(5):
    v = rng.normal(size=2) + 1j * rng.normal(size=2)
    goal = Statevector(v / np.linalg.norm(v))
    th, ph = angles_for(goal)
    print(f"theta = {np.degrees(th):6.1f}, phi = {np.degrees(ph):7.1f}  ->  fidelity {state_fidelity(Statevector(prepare(th, ph)), goal):.4f}")
print("Every random state is reached with fidelity 1: two rotations are enough for any one-qubit state.")

Wrap-up

This week in one sentence

1 min
Every one-qubit state is a point on the Bloch sphere and every one-qubit gate is a turn of it: Paulis are half-turns, H swaps the z and x views, phase gates and rotations turn by any angle, and two rotations can reach any point.
Machine-learning link

State preparation is how data enters a quantum model. The simplest recipe, angle encoding, is exactly today's project: a feature xxx becomes the angle of an RY(x)R_Y(x)RY​(x), so every data point becomes a point on the sphere. That's day 2 of the Quantum ML tutorial.

Go deeper (optional)

Qiskit can prepare states for you: QuantumCircuit.initialize builds a circuit for any state vector, on any number of qubits. For many qubits this gets expensive quickly, which is one reason loading data is a real bottleneck in quantum ML.
