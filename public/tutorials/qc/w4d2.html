Warm-up

Two coins that always agree

1 min

Imagine two coins that you flip in different rooms. Each one is a perfectly fair coin, heads or tails 50/50. Yet whenever you compare notes, they landed the same way. Every time. No ordinary coins behave like that. Two qubits can, and it takes just two gates. This is entanglement.

Big idea

CNOT, Bell states and what 'entangled' means

4 min

The CNOT (controlled-NOT) gate acts on two qubits: if the control is 1 it flips the target, otherwise it does nothing. In circuit diagrams the control is a dot and the target a ⊕. Applied to a superposition, it acts on every branch at once.

Start in ∣00⟩|00\rangle∣00⟩, put qubit 0 into ∣+⟩|+\rangle∣+⟩ with H, then CNOT from qubit 0 to qubit 1:

∣00⟩→H12(∣00⟩+∣01⟩)→CNOT12(∣00⟩+∣11⟩)|00\rangle \xrightarrow{H} \tfrac{1}{\sqrt2}\big(|00\rangle + |01\rangle\big) \xrightarrow{\text{CNOT}} \tfrac{1}{\sqrt2}\big(|00\rangle + |11\rangle\big)∣00⟩H​2​1​(∣00⟩+∣01⟩)CNOT​2​1​(∣00⟩+∣11⟩)

(Qiskit labels: in ∣01⟩|01\rangle∣01⟩ qubit 0 is the 1. The CNOT sees that and flips qubit 1, giving ∣11⟩|11\rangle∣11⟩.) This is a Bell state. Measure it and you get 00 or 11, 50/50, never 01 or 10.

Why is that strange? Yesterday, separately prepared qubits gave product states, (β0∣0⟩+β1∣1⟩)⊗(α0∣0⟩+α1∣1⟩)(\beta_0|0\rangle + \beta_1|1\rangle)\otimes(\alpha_0|0\rangle + \alpha_1|1\rangle)(β0​∣0⟩+β1​∣1⟩)⊗(α0​∣0⟩+α1​∣1⟩), whose amplitudes always satisfy

a00 a11−a01 a10=0a_{00}\,a_{11} - a_{01}\,a_{10} = 0a00​a11​−a01​a10​=0

The Bell state has a00=a11=12a_{00} = a_{11} = \tfrac{1}{\sqrt2}a00​=a11​=2​1​ and a01=a10=0a_{01} = a_{10} = 0a01​=a10​=0, so this is 12≠0\tfrac12 \neq 021​=0. It is not a product: you cannot describe it as "qubit 0 is in this state and qubit 1 is in that state". That is the definition of entangled. The pair has a definite story; the individual qubits do not.

No faster-than-light messages

If the two qubits are far apart, measuring one instantly tells you the other's result. But you can't choose what you get (it's 50/50), so no message can be sent this way. The correlation only shows up when the two sides compare notes.

cell 1 · the CNOT truth table
import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector

def probs(sv):
    return {str(k): round(float(v), 3) for k, v in sv.probabilities_dict().items()}

cnot = QuantumCircuit(2)
cnot.cx(0, 1)                       # control = qubit 0, target = qubit 1

print("CNOT truth table (labels are q1 q0):")
for label in ["00", "01", "10", "11"]:
    out = Statevector.from_label(label).evolve(cnot)
    print(f"  |{label}>  ->  |{list(probs(out))[0]}>")

cell 4 · product or entangled?
def entanglement_test(sv):
    a00, a01, a10, a11 = sv.data
    return abs(a00 * a11 - a01 * a10)

separate = QuantumCircuit(2)
separate.h(0)                        # H on qubit 0 only, no CNOT
print("H only     :", round(entanglement_test(Statevector(separate)), 3), "-> product state")
print("Bell state :", round(entanglement_test(Statevector(bell)), 3), "-> entangled")

One line inside the loop: qc.cx(0, 1). A basis state goes to a basis state, so probabilities_dict() has a single key.

Show a solution
one solution
for control, target in [(0, 1), (1, 0)]:
    print(f"cx({control}, {target}): control q{control}, target q{target}")
    for label in ["00", "01", "10", "11"]:
        qc = QuantumCircuit(2)
        qc.cx(control, target)
        out = Statevector.from_label(label).evolve(qc)
        (result,) = out.probabilities_dict().keys()
        print(f"   |{label}> -> |{result}>")
print("The target flips exactly when the control is 1. With q0 as control, that's when the RIGHT character is 1.")

Wrap-up

Today in one sentence

1 min
CNOT flips a target when its control is 1; after an H it creates a Bell state whose outcomes always agree, a state that can't be split into two separate qubits: that is entanglement.
Quantum link

Entangling gates are what make quantum feature maps interesting. A map built only from one-qubit rotations treats each feature separately and is easy to simulate. Adding CNOTs mixes features together in the 2n2^n2n-dimensional space, and the popular "ZZ feature map" is built from exactly H, rotations and CNOTs.
