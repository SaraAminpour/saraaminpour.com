Warm-up

One question instead of five

1 min

A friend has a secret function of three bits. They promise it's either constant (the same answer for all 8 inputs) or balanced (0 for exactly half of them, 1 for the other half). Asking one input at a time, you might need 5 questions to be sure. A quantum computer needs one. Today's lesson shows the trick, which is the seed of every famous quantum algorithm.

Big idea

Oracles, kickback and interference

4 min

Oracles. A function f(x)∈{0,1}f(x) \in \{0, 1\}f(x)∈{0,1} of an nnn-bit input xxx can be hidden inside a gate, called an oracle:

Uf ∣x⟩∣y⟩=∣x⟩∣y⊕f(x)⟩U_f\,|x\rangle|y\rangle = |x\rangle|y \oplus f(x)\rangleUf​∣x⟩∣y⟩=∣x⟩∣y⊕f(x)⟩

It flips the output qubit yyy exactly when f(x)=1f(x) = 1f(x)=1 (⊕\oplus⊕ is XOR). It's reversible, so it's a valid quantum gate. One use of UfU_fUf​ is one query, and a query can act on a superposition of inputs.

Phase kickback. Put the output qubit in ∣−⟩=12(∣0⟩−∣1⟩)|-\rangle = \frac{1}{\sqrt2}(|0\rangle - |1\rangle)∣−⟩=2​1​(∣0⟩−∣1⟩). Flipping ∣−⟩|-\rangle∣−⟩ gives −∣−⟩-|-\rangle−∣−⟩, so:

Uf ∣x⟩∣−⟩=(−1)f(x) ∣x⟩∣−⟩U_f\,|x\rangle|-\rangle = (-1)^{f(x)}\,|x\rangle|-\rangleUf​∣x⟩∣−⟩=(−1)f(x)∣x⟩∣−⟩

The output qubit doesn't change; the answer is "kicked back" as a sign on ∣x⟩|x\rangle∣x⟩. (The smallest example: a CNOT with its target in ∣−⟩|-\rangle∣−⟩ acts as a Z on its control.)

Deutsch–Jozsa. Three steps on the inputs:

  1. H on every input qubit: all 2n2^n2n inputs, with equal amplitudes.
  2. One query: input xxx gets the sign (−1)f(x)(-1)^{f(x)}(−1)f(x).
  3. H on every input qubit again, then measure.

The amplitude of ∣00…0⟩|00\ldots0\rangle∣00…0⟩ at the end is the average of all the signs:

amp(00…0)=12n∑x(−1)f(x)={±1if f is constant0if f is balanced\text{amp}(00\ldots0) = \frac{1}{2^n}\sum_x (-1)^{f(x)} = \begin{cases} \pm 1 & \text{if } f \text{ is constant} \\ 0 & \text{if } f \text{ is balanced} \end{cases}amp(00…0)=2n1​x∑​(−1)f(x)={±10​if f is constantif f is balanced​

Constant: every path to 00…000\ldots000…0 has the same sign, and they add up. Balanced: half plus, half minus, and they cancel exactly. That's week 3's interference, now doing computation. So: measure 00…000\ldots000…0 means constant, anything else means balanced. Always, after one query.

Honest fine print: classically, to be certain you need 2n−1+12^{n-1} + 12n−1+1 queries in the worst case (513 for n=10n = 10n=10). But a classical guesser who asks a few random inputs is right with high probability. So the quantum advantage here is about certainty, on an artificial problem. Its real value is the pattern, H, oracle, H, which tomorrow's algorithm and later ones such as Simon's and Shor's build on.

Kickback writes the answers as signs; Hadamards make the signs interfere; one measurement reads a property of all the answers at once.

cell 1 · kickback, the smallest example
import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector, SparsePauliOp
from qiskit.primitives import StatevectorSampler

# a CNOT whose target is |->: watch what happens to the CONTROL
qc = QuantumCircuit(2)
qc.h(0)                 # control q0 in |+>
qc.x(1)
qc.h(1)                 # target q1 in |->
before = Statevector(qc)
qc.cx(0, 1)
after = Statevector(qc)

X0 = SparsePauliOp("IX")                 # X on qubit 0 (Qiskit reads Pauli strings right to left)
X1 = SparsePauliOp("XI")                 # X on qubit 1
print("<X> of the control: before", round(before.expectation_value(X0).real, 3), " after", round(after.expectation_value(X0).real, 3))
print("<X> of the target : before", round(before.expectation_value(X1).real, 3), " after", round(after.expectation_value(X1).real, 3))

cell 2 · oracles from a truth table
def oracle_from_table(table, n=3):
    """A gate on n input qubits plus an output qubit (number n): flips the output when table[x] = 1."""
    qc = QuantumCircuit(n + 1, name="U_f")
    for x, fx in enumerate(table):
        if fx:
            zeros = [q for q in range(n) if not (x >> q) & 1]   # bit q of x lives on qubit q
            if zeros:
                qc.x(zeros)                                    # so that this x looks like 11...1
            qc.mcx(list(range(n)), n)                          # flip the output if all inputs are 1
            if zeros:
                qc.x(zeros)                                    # undo
    return qc

def dj_circuit(oracle, n=3):
    qc = QuantumCircuit(n + 1, n)
    qc.x(n)
    qc.h(n)                                                    # output qubit in |->: ready for kickback
    qc.h(range(n))                                             # all 2^n inputs at once
    qc.barrier()
    qc.compose(oracle, inplace=True)                           # ONE query
    qc.barrier()
    qc.h(range(n))                                             # interference
    qc.measure(range(n), range(n))
    return qc

parity = [bin(x).count("1") % 2 for x in range(8)]
dj_circuit(oracle_from_table(parity)).draw("mpl", style="clifford", fold=-1)

cell 3 · one query per function
rng = np.random.default_rng(7)
functions = {
    "constant 0": [0] * 8,
    "constant 1": [1] * 8,
    "parity x0 ^ x1 ^ x2": parity,
    "majority of 3": [int(bin(x).count("1") >= 2) for x in range(8)],
    "random balanced": list(rng.permutation([0] * 4 + [1] * 4)),
}
sampler = StatevectorSampler(seed=1)
for name, table in functions.items():
    counts = sampler.run([dj_circuit(oracle_from_table(table))], shots=1000).result()[0].data.c.get_counts()
    verdict = "constant" if counts.get("000", 0) == 1000 else "balanced"
    print(f"{name:20s} table {''.join(map(str, table))}  ->  {counts}  ->  {verdict}")

one solution
def oracle_xor02():
    qc = QuantumCircuit(4)
    qc.cx(0, 3)
    qc.cx(2, 3)
    return qc

def oracle_and01():
    qc = QuantumCircuit(4)
    qc.ccx(0, 1, 3)
    return qc

for name, oracle in [("x0 xor x2", oracle_xor02()), ("x0 and x1", oracle_and01())]:
    counts = sampler.run([dj_circuit(oracle)], shots=1000).result()[0].data.c.get_counts()
    print(name, dict(sorted(counts.items())))
print("x0 xor x2 never gives 000: balanced. Notice it always gives 101, the bits that f looks at (tomorrow's lesson!).")
print("x0 and x1 gives 000 about a quarter of the time: (1/8 * sum of the signs)^2 = (4/8)^2. Without the promise, one shot proves nothing.")

Wrap-up

Today in one sentence

1 min
An oracle computes fff reversibly; with its output qubit in ∣−⟩|-\rangle∣−⟩ the answers kick back as signs (−1)f(x)(-1)^{f(x)}(−1)f(x), and Hadamards before and after make those signs interfere, so a single query tells constant from balanced.
Quantum link

Quantum feature maps for machine learning work the same way: data enters as phases on many basis states at once, and later gates make those phases interfere. The "data re-uploading" and kernel circuits in the Quantum ML tutorial are, at heart, H, phases, H, with the data playing the role of the function.
