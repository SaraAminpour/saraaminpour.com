Warm-up

Not knowing, made precise

1 min

A friend hands you a qubit: "It's either ∣0⟩|0\rangle∣0⟩ or ∣+⟩|+\rangle∣+⟩, I flipped a coin." That's not a superposition; it's ordinary uncertainty on top of quantum states. Yesterday's noise produces exactly this kind of state. The density matrix handles both kinds of uncertainty in one object, and it's the language of noisy quantum computing.

Big idea

A matrix instead of a vector

4 min

For a pure state, take the column ∣ψ⟩|\psi\rangle∣ψ⟩ times the row ⟨ψ∣\langle\psi|⟨ψ∣. For ∣ψ⟩=α∣0⟩+β∣1⟩|\psi\rangle = \alpha|0\rangle + \beta|1\rangle∣ψ⟩=α∣0⟩+β∣1⟩:

ρ=∣ψ⟩⟨ψ∣=(∣α∣2αβ∗α∗β∣β∣2)\rho = |\psi\rangle\langle\psi| = \begin{pmatrix} |\alpha|^2 & \alpha\beta^* \\ \alpha^*\beta & |\beta|^2 \end{pmatrix}ρ=∣ψ⟩⟨ψ∣=(∣α∣2α∗β​αβ∗∣β∣2​)

The diagonal holds the probabilities of 0 and 1 (the populations); the off-diagonal entries hold the relative phase (the coherences). For a mixture, average the matrices: ρ=∑kpk∣ψk⟩⟨ψk∣\rho = \sum_k p_k |\psi_k\rangle\langle\psi_k|ρ=∑k​pk​∣ψk​⟩⟨ψk​∣.

The rules. Every density matrix has trace 1, equals its own conjugate transpose, and has no negative eigenvalues. From ρ\rhoρ you get everything: probabilities (the diagonal), expectation values ⟨O⟩=Tr(Oρ)\langle O\rangle = \mathrm{Tr}(O\rho)⟨O⟩=Tr(Oρ), and a gate acts as ρ→UρU†\rho \to U\rho U^\daggerρ→UρU†. The purity Tr(ρ2)\mathrm{Tr}(\rho^2)Tr(ρ2) is 1 for pure states and 12\frac1221​ for the completely mixed qubit. For one qubit, ρ=12(I+xX+yY+zZ)\rho = \frac12(I + xX + yY + zZ)ρ=21​(I+xX+yY+zZ): the Bloch vector again, with length ≤1\le 1≤1.

Surprise 1: recipes don't matter. Half ∣0⟩|0\rangle∣0⟩ and half ∣1⟩|1\rangle∣1⟩ gives ρ=I/2\rho = I/2ρ=I/2. So does half ∣+⟩|+\rangle∣+⟩ and half ∣−⟩|-\rangle∣−⟩. Since every measurement result is computed from ρ\rhoρ, no experiment can ever tell which recipe was used: ρ\rhoρ is the state.

Surprise 2: parts of pure things can be mixed. The partial trace describes one qubit of a pair on its own. For a Bell pair, the whole is pure, but each half is I/2I/2I/2, a perfect coin. Entanglement makes the parts look like noise. In fact, a lot of real noise is entanglement with an environment we can't see.

The density matrix is the complete description: probabilities on the diagonal, phases off it, purity telling how much is still quantum.

Density matrices in Qiskit

cell 1 · a pure state's matrix
import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector, DensityMatrix, partial_trace, Pauli

theta, phi = 1.2, 0.8
psi = np.array([np.cos(theta / 2), np.exp(1j * phi) * np.sin(theta / 2)])
rho = np.outer(psi, psi.conj())                       # |psi><psi|: a column times a row
print("rho =\n", np.round(rho, 3))
print("same as Qiskit:", np.allclose(rho, DensityMatrix(Statevector(psi)).data))
print("trace:", np.round(np.trace(rho).real, 3), "  Hermitian:", np.allclose(rho, rho.conj().T),
      "  eigenvalues:", np.round(np.linalg.eigvalsh(rho), 3) + 0.0, "  purity Tr(rho^2):", np.round(np.trace(rho @ rho).real, 3))

cell 2 · two recipes, one matrix
def dm(label):
    return DensityMatrix.from_label(label).data

recipe_1 = 0.5 * dm("0") + 0.5 * dm("1")
recipe_2 = 0.5 * dm("+") + 0.5 * dm("-")
print("0/1 recipe:\n", np.round(recipe_1.real, 3))
print("+/- recipe:\n", np.round(recipe_2.real, 3) + 0.0)
print("identical:", np.allclose(recipe_1, recipe_2), "  purity:", np.trace(recipe_1 @ recipe_1).real)

cell 3 · everything comes from ρ
mixed = DensityMatrix(0.7 * dm("0") + 0.3 * dm("+"))
print("probabilities of 0 and 1:", mixed.probabilities().round(3))
bloch = [np.trace(Pauli(p).to_matrix() @ mixed.data).real for p in "XYZ"]
print("Bloch vector (Tr(X rho), Tr(Y rho), Tr(Z rho)):", np.round(bloch, 3) + 0.0, "  length:", round(float(np.linalg.norm(bloch)), 3))
h_gate = QuantumCircuit(1)
h_gate.h(0)
print("after an H gate:", np.round([np.trace(Pauli(p).to_matrix() @ mixed.evolve(h_gate).data).real for p in "XYZ"], 3) + 0.0)

cell 4 · half of a Bell pair
bell = QuantumCircuit(2)
bell.h(0)
bell.cx(0, 1)
whole = DensityMatrix(bell)
half = partial_trace(whole, [1])                      # keep qubit 0, trace out qubit 1
print("purity of the pair:", round(float(whole.purity().real), 3))
print("qubit 0 alone:\n", np.round(half.data.real, 3) + 0.0, "  purity:", round(float(half.purity().real), 3))

Show a solution
one solution
for degrees in [0, 30, 60, 90]:
    qc = QuantumCircuit(2)
    qc.ry(np.radians(degrees), 0)
    qc.cx(0, 1)
    purity = partial_trace(DensityMatrix(qc), [1]).purity().real
    print(f"theta = {degrees:2d} degrees: purity of qubit 0 alone = {purity:.3f}")
print("Purity 1: a product state, no entanglement. Purity 1/2: maximally entangled, each half a fair coin.")

Wrap-up

Today in one sentence

1 min
A density matrix ρ=∑kpk∣ψk⟩⟨ψk∣\rho = \sum_k p_k|\psi_k\rangle\langle\psi_k|ρ=∑k​pk​∣ψk​⟩⟨ψk​∣ is the complete description of a quantum state: probabilities on the diagonal, phases off it, purity between ½ and 1 for a qubit; different recipes can give the same ρ\rhoρ, and the parts of an entangled pair are mixed.
Quantum link

On noisy hardware, a quantum model's state for input xxx is a density matrix ρ(x)\rho(x)ρ(x), and the kernel becomes Tr(ρ(x) ρ(x′))\mathrm{Tr}\big(\rho(x)\,\rho(x')\big)Tr(ρ(x)ρ(x′)). Noise pushes every ρ(x)\rho(x)ρ(x) towards the same mixed state, so all inputs start to look alike. The Quantum ML tutorial's last week studies exactly this.
