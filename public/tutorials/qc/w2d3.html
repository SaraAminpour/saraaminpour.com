Hadamard: making superpositions

H turns a definite 0 into a perfect 50/50 superposition, and back again. It's also a change of viewpoint: it swaps the z axis and the x axis.

Warm-up

The gate behind every algorithm

1 min

Almost every quantum algorithm starts the same way: a row of H gates. You met H last week as "the fair coin". Today you'll see it from three sides: as a matrix, as a turn of the sphere, and as the gate that can undo its own randomness, which no coin can do.

Big idea

A superposition maker that undoes itself

4 min
H=12(111−1)H = \frac{1}{\sqrt2}\begin{pmatrix}1&1\\1&-1\end{pmatrix}H=2​1​(11​1−1​)

It maps the poles to the equator and back:

Into superposition

H∣0⟩=∣+⟩=12(∣0⟩+∣1⟩)H|0\rangle = |+\rangle = \frac{1}{\sqrt2}(|0\rangle + |1\rangle)H∣0⟩=∣+⟩=2​1​(∣0⟩+∣1⟩)
H∣1⟩=∣−⟩=12(∣0⟩−∣1⟩)H|1\rangle = |-\rangle = \frac{1}{\sqrt2}(|0\rangle - |1\rangle)H∣1⟩=∣−⟩=2​1​(∣0⟩−∣1⟩)

And back

H∣+⟩=∣0⟩H|+\rangle = |0\rangleH∣+⟩=∣0⟩
H∣−⟩=∣1⟩H|-\rangle = |1\rangleH∣−⟩=∣1⟩

On the Bloch sphere, H is a half-turn about the diagonal halfway between the x and z axes. That turn swaps the z axis and the x axis (and flips y). So H is a translator between two viewpoints: the 0/1 view (z) and the ± view (x). Next week you'll use exactly this to measure in the ± view: apply H, then measure 0/1.

Now the surprise: one H gives a coin, but two H's give ∣0⟩|0\rangle∣0⟩ back, every time. Follow the amplitudes of the second H, acting on 12(∣0⟩+∣1⟩)\frac{1}{\sqrt2}(|0\rangle + |1\rangle)2​1​(∣0⟩+∣1⟩):

H(12∣0⟩+12∣1⟩)=12(∣0⟩+∣1⟩)+12(∣0⟩−∣1⟩)=∣0⟩H\Big(\tfrac{1}{\sqrt2}|0\rangle + \tfrac{1}{\sqrt2}|1\rangle\Big) = \tfrac12\big(|0\rangle + |1\rangle\big) + \tfrac12\big(|0\rangle - |1\rangle\big) = |0\rangleH(2​1​∣0⟩+2​1​∣1⟩)=21​(∣0⟩+∣1⟩)+21​(∣0⟩−∣1⟩)=∣0⟩

Two routes lead to ∣1⟩|1\rangle∣1⟩, with amplitudes +12+\frac12+21​ and −12-\frac12−21​. They cancel. A classical coin can't do that: probabilities only add up, but amplitudes can be negative. This cancellation, interference, is next week's big topic.

H on every one of nnn qubits turns ∣00…0⟩|00\dots0\rangle∣00…0⟩ into an equal superposition of all 2n2^n2n bitstrings: the starting line of most quantum algorithms.

cell 1 · the matrix, and what it does
import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Operator, Statevector

H = Operator.from_label("H").data
print("H =\n", np.round(H, 3))
print("H·H = I ?", np.allclose(H @ H, np.eye(2)))

def ket(sv, labels=("|0>", "|1>")):
    """A state with real amplitudes, in Dirac notation."""
    out = ""
    for a, l in zip(sv.data, labels):
        if abs(a) < 1e-9:
            continue
        v = a.real
        out += f"{v:.3f}{l}" if not out else f" {'-' if v < 0 else '+'} {abs(v):.3f}{l}"
    return out

s = 1 / np.sqrt(2)
for name, amps in {"|0>": [1, 0], "|1>": [0, 1], "|+>": [s, s], "|->": [s, -s]}.items():
    print(f"H {name:>3} = {ket(Statevector(amps).evolve(Operator(H)))}")

cell 2 · the arrow: (x, y, z) becomes (z, −y, x)
def bloch(sv):
    a, b = sv.data
    c = np.conj(a) * b
    return np.round([2 * c.real, 2 * c.imag, abs(a) ** 2 - abs(b) ** 2], 3)

psi = Statevector([np.cos(0.5), np.exp(1.1j) * np.sin(0.5)])
print("before H:", bloch(psi))
print("after H: ", bloch(psi.evolve(Operator(H))))

cell 3 · one H is a coin, two are not
from qiskit.primitives import StatevectorSampler

sampler = StatevectorSampler(seed=1)
one, two = QuantumCircuit(1), QuantumCircuit(1)
one.h(0)
two.h(0)
two.h(0)
for qc in (one, two):
    qc.measure_all()
res = sampler.run([one, two], shots=1000).result()
print("H, measure:   ", res[0].data.meas.get_counts())
print("H, H, measure:", res[1].data.meas.get_counts())

cell 4 · three qubits, eight equal outcomes
import matplotlib.pyplot as plt

qc3 = QuantumCircuit(3)
qc3.h([0, 1, 2])                     # one H on each qubit
print(np.round(Statevector(qc3).probabilities(), 3), "<- 8 outcomes, 1/8 each")
qc3.measure_all()
counts = sampler.run([qc3], shots=4000).result()[0].data.meas.get_counts()
keys = sorted(counts)
plt.figure(figsize=(6, 3))
plt.bar(keys, [counts[k] for k in keys], color="#ff8fb8")
plt.axhline(500, color="#7b5cfa", ls="--", label="4000 / 8 = 500")
plt.xlabel("bitstring (q2 q1 q0)")
plt.ylabel("counts")
plt.legend()
plt.show()

Wrap-up

Today in one sentence

1 min
H turns ∣0⟩,∣1⟩|0\rangle, |1\rangle∣0⟩,∣1⟩ into ∣+⟩,∣−⟩|+\rangle, |-\rangle∣+⟩,∣−⟩ and back; it swaps the z and x views of the qubit; and two H's cancel, because amplitudes can interfere.
Machine-learning link

The most famous quantum feature map, which turns data into quantum states (Quantum ML tutorial, week 1), starts with exactly this: an H on every qubit, so that the data can then tilt a perfectly balanced superposition.
