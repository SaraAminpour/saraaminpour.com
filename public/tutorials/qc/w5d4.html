Big idea

Parity of a secret overlap

4 min

The hidden function compares your input xxx with a secret string sss (both nnn bits) and returns the parity of the bits they share:

f(x)=s⋅x mod 2=(s0x0+s1x1+⋯+sn−1xn−1) mod 2f(x) = s \cdot x \bmod 2 = (s_0x_0 + s_1x_1 + \dots + s_{n-1}x_{n-1}) \bmod 2f(x)=s⋅xmod2=(s0​x0​+s1​x1​+⋯+sn−1​xn−1​)mod2

Classically, each answer is one bit, and sss has nnn bits, so you need nnn questions. The input with a single 1 in position iii returns exactly sis_isi​.

Quantum: run Deutsch–Jozsa's circuit, H, one query, H, and measure. The result is sss, with certainty. Here is why, one qubit at a time:

  • The oracle is just a CNOT from each input qubit where si=1s_i = 1si​=1 to the output qubit (that computes the parity s⋅xs \cdot xs⋅x).
  • With the output qubit in ∣−⟩|-\rangle∣−⟩, each of those CNOTs kicks back a Z onto its control.
  • So each input qubit goes ∣0⟩→H∣+⟩→Z if si=1∣−⟩→H∣1⟩|0\rangle \xrightarrow{H} |+\rangle \xrightarrow{Z \text{ if } s_i = 1} |-\rangle \xrightarrow{H} |1\rangle∣0⟩H​∣+⟩Z if si​=1​∣−⟩H​∣1⟩, or stays ∣+⟩→∣0⟩|+\rangle \to |0\rangle∣+⟩→∣0⟩ if si=0s_i = 0si​=0.

The register ends in ∣s⟩|s\rangle∣s⟩, qubit by qubit, without any entanglement. In formulas: the oracle gives the amplitudes (−1)s⋅x(-1)^{s \cdot x}(−1)s⋅x, which is exactly the Hadamard pattern of ∣s⟩|s\rangle∣s⟩, and the last H turns it back into ∣s⟩|s\rangle∣s⟩.

Mind Qiskit's order when building the oracle: in the string "100110", the last character belongs to qubit 0.

nnn classical questions, or one quantum query: the answer comes back as the measured string itself.

Bernstein–Vazirani in Qiskit

cell 1 · the classical way: n questions
import numpy as np
from qiskit import QuantumCircuit
from qiskit.primitives import StatevectorSampler

secret = "100110"                                  # written like Qiskit prints: q5 ... q0

def f(x, s=secret):
    """s . x mod 2: the parity of the bits of x where s has a 1. Both are strings in Qiskit order."""
    return sum(int(a) * int(b) for a, b in zip(s, x)) % 2

# classical strategy: ask the inputs with a single 1; each answer is one bit of s
n = len(secret)
answers = []
for i in range(n):
    x = "".join("1" if k == i else "0" for k in range(n))
    answers.append(str(f(x)))
    print(f"ask x = {x} -> f(x) = {answers[-1]}")
print("recovered s =", "".join(answers), f"after {n} questions")

cell 2 · one quantum query
def bv_circuit(s):
    n = len(s)
    qc = QuantumCircuit(n + 1, n)
    qc.x(n)
    qc.h(n)                                        # output qubit in |->
    qc.h(range(n))
    qc.barrier()
    for qubit, bit in enumerate(reversed(s)):      # qubit 0 is the LAST character
        if bit == "1":
            qc.cx(qubit, n)
    qc.barrier()
    qc.h(range(n))
    qc.measure(range(n), range(n))
    return qc

sampler = StatevectorSampler(seed=1)
counts = sampler.run([bv_circuit(secret)], shots=1000).result()[0].data.c.get_counts()
print("measured:", counts, "  secret:", secret)
bv_circuit(secret).draw("mpl", style="clifford")
What it printed in the notebook

cell 3 · every qubit pure and certain
from qiskit.quantum_info import Statevector, partial_trace

qc = bv_circuit(secret).remove_final_measurements(inplace=False)
state = Statevector(qc)
for qubit in range(n):
    others = [q for q in range(n + 1) if q != qubit]
    rho = partial_trace(state, others)
    p1 = rho.probabilities()[1]
    print(f"qubit {qubit}: P(1) = {p1:.3f}   purity = {np.real(np.trace(rho.data @ rho.data)):.3f}")
print("Every qubit is pure (purity 1) and certain: the answer is stored qubit by qubit.")

Wrap-up

Today in one sentence

1 min
For f(x)=s⋅x mod 2f(x) = s \cdot x \bmod 2f(x)=s⋅xmod2, Deutsch–Jozsa's circuit returns the secret sss in one query, because kickback flips exactly the qubits where sss has a 1 and the final Hadamards turn those flips into 1s.
Quantum link

Learning a hidden parity function is a famous machine-learning problem. With noisy answers, "learning parity with noise" is believed to be hard for classical computers, and quantum versions of it are a classic testing ground for claims of quantum advantage in learning.
