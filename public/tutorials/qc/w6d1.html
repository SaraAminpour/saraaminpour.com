Warm-up

A photo fading in the sun

1 min

Leave a photo in the sun and it slowly fades towards a blank gray. Qubits do the same: their environment keeps "peeking" at them, and the delicate phases and amplitudes wash out. This is called noise or decoherence, and it is the main enemy of today's quantum computers. This week is about living with it: describing it, measuring it, and fighting back.

Big idea

Mixed states live inside the sphere

5 min

So far every state was pure: a definite ∣ψ⟩|\psi\rangle∣ψ⟩, an arrow of length 1. If we only know the qubit is in ∣ψ1⟩|\psi_1\rangle∣ψ1​⟩ with probability p1p_1p1​, or ∣ψ2⟩|\psi_2\rangle∣ψ2​⟩ with probability p2p_2p2​, we need a density matrix:

ρ=∑kpk ∣ψk⟩⟨ψk∣,ρ=12(I+rxX+ryY+rzZ)\rho = \sum_k p_k\, |\psi_k\rangle\langle\psi_k|, \qquad \rho = \tfrac12\left(I + r_x X + r_y Y + r_z Z\right)ρ=k∑​pk​∣ψk​⟩⟨ψk​∣,ρ=21​(I+rx​X+ry​Y+rz​Z)

The second form shows that every one-qubit state is still a Bloch vector r⃗=(⟨X⟩,⟨Y⟩,⟨Z⟩)\vec r = (\langle X\rangle, \langle Y\rangle, \langle Z\rangle)r=(⟨X⟩,⟨Y⟩,⟨Z⟩), but now ∣r⃗∣≤1|\vec r| \le 1∣r∣≤1. Pure states sit on the surface; mixed states sit inside the Bloch ball. The center ρ=I/2\rho = I/2ρ=I/2 is a totally random coin: you know nothing.

Noise moves the arrow inwards. Three classics:

  • Depolarizing: with probability ppp the state is replaced by I/2I/2I/2. The arrow shrinks evenly: r⃗→(1−p) r⃗\vec r \to (1-p)\,\vec rr→(1−p)r.
  • Dephasing: the phase is scrambled. The xxx and yyy parts shrink, zzz is untouched: the ball squashes towards the vertical axis.
  • Amplitude damping: energy leaks away and ∣1⟩|1\rangle∣1⟩ decays to ∣0⟩|0\rangle∣0⟩. Everything slides towards the north pole.

Noise takes time. On hardware these processes run continuously. Amplitude damping has a time constant T1T_1T1​: a qubit left in ∣1⟩|1\rangle∣1⟩ is still there after time ttt with probability e−t/T1e^{-t/T_1}e−t/T1​. Dephasing has a time constant T2T_2T2​: the arrow's sideways parts fade like e−t/T2e^{-t/T_2}e−t/T2​. For today's superconducting qubits both are typically around a hundred microseconds, while a two-qubit gate takes a fraction of a microsecond: room for hundreds of gates, not millions. Every extra gate lets in a little more noise.

How far did a state drift? Wednesday's lesson measures that properly, with fidelity and trace distance; today's widget already shows both numbers.

Noise shrinks the Bloch arrow: evenly (depolarizing), sideways only (dephasing), or towards ∣0⟩|0\rangle∣0⟩ (amplitude damping), a little more with every gate and every microsecond.

cell 1 · pure versus mixed
import numpy as np
import matplotlib.pyplot as plt
from qiskit.quantum_info import Statevector, DensityMatrix, Pauli, Kraus

plus = DensityMatrix(Statevector.from_label("+"))           # a pure state, written as a density matrix
mixed = DensityMatrix(np.eye(2) / 2)                        # a fair coin we know nothing more about

def bloch(rho):
    return [round(float(np.real(rho.expectation_value(Pauli(p)))), 3) + 0.0 for p in "XYZ"]

for name, rho in [("|+>  (pure)", plus), ("I/2 (mixed)", mixed)]:
    print(name, "  probabilities of 0 and 1:", rho.probabilities().round(3), "  Bloch vector:", bloch(rho))

cell 2 · three noise channels
def depolarizing(p):
    return Kraus([np.sqrt(1 - 3 * p / 4) * np.eye(2)] + [np.sqrt(p / 4) * Pauli(s).to_matrix() for s in "XYZ"])

def dephasing(p):                           # a Z error with probability p/2
    return Kraus([np.sqrt(1 - p / 2) * np.eye(2), np.sqrt(p / 2) * Pauli("Z").to_matrix()])

def amplitude_damping(g):                   # |1> decays to |0> with probability g
    return Kraus([np.array([[1, 0], [0, np.sqrt(1 - g)]]), np.array([[0, np.sqrt(g)], [0, 0]])])

start = DensityMatrix(Statevector([np.cos(1.0), np.exp(0.6j) * np.sin(1.0)]))
print(f"{'clean state:':28s}", bloch(start))
for name, channel in [("depolarizing", depolarizing), ("dephasing", dephasing), ("amplitude damping", amplitude_damping)]:
    print(f"{name + ', p = 0.5:':28s}", bloch(start.evolve(channel(0.5))))

cell 3 · T1 and T2
T1, T2 = 100e-6, 80e-6                      # seconds: typical orders of magnitude for superconducting qubits
times = np.linspace(0, 300e-6, 61)
p_one = [DensityMatrix.from_label("1").evolve(amplitude_damping(1 - np.exp(-t / T1))).probabilities()[1] for t in times]
coherence = [bloch(plus.evolve(dephasing(1 - np.exp(-t / T2))))[0] for t in times]

plt.plot(times * 1e6, p_one, color="#ff8a50", lw=2.5, label=r"$P(1)$ after preparing $|1\rangle$ (T1)")
plt.plot(times * 1e6, coherence, color="#7b5cfa", lw=2.5, label=r"$\langle X\rangle$ after preparing $|+\rangle$ (T2)")
plt.xlabel("waiting time (microseconds)")
plt.ylabel("what's left")
plt.legend()
plt.show()

cell 4 · a noisy Bell state in Aer
from qiskit import QuantumCircuit, transpile
from qiskit_aer import AerSimulator
from qiskit_aer.noise import NoiseModel, depolarizing_error

bell = QuantumCircuit(2)
bell.h(0)
bell.cx(0, 1)
bell.measure_all()

noise = NoiseModel()
noise.add_all_qubit_quantum_error(depolarizing_error(0.05, 1), ["h"])
noise.add_all_qubit_quantum_error(depolarizing_error(0.10, 2), ["cx"])

for name, sim in [("ideal", AerSimulator()), ("noisy", AerSimulator(noise_model=noise))]:
    counts = sim.run(transpile(bell, sim), shots=4000, seed_simulator=7).result().get_counts()
    print(f"{name:>5}: {dict(sorted(counts.items()))}")

one solution
noise2 = NoiseModel()
noise2.add_all_qubit_quantum_error(depolarizing_error(0.02, 2), ["cx"])
sim = AerSimulator(noise_model=noise2)
ns, good = range(2, 8), []
for n in ns:
    ghz = QuantumCircuit(n)
    ghz.h(0)
    for q in range(n - 1):
        ghz.cx(q, q + 1)
    ghz.measure_all()
    counts = sim.run(transpile(ghz, sim), shots=4000, seed_simulator=1).result().get_counts()
    good.append((counts.get("0" * n, 0) + counts.get("1" * n, 0)) / 4000)
    print(f"n = {n}: {n - 1} CNOTs, correct outcomes {good[-1]:.3f}")
plt.plot(list(ns), good, "o-", color="#7b5cfa")
plt.xlabel("number of qubits n")
plt.ylabel("share of correct outcomes")
plt.title("Every extra CNOT lets in a little more noise")
plt.show()

Wrap-up

Today in one sentence

1 min
Noise turns pure states into mixed ones, shrinking the Bloch arrow into the ball: depolarizing evenly, dephasing sideways, amplitude damping towards ∣0⟩|0\rangle∣0⟩; on hardware it grows with time (T1T_1T1​, T2T_2T2​) and with every gate.
Quantum link

Fidelity is not just a quality score: the most common quantum kernel is literally the fidelity between two data-encoded states, k(x,x′)=∣⟨φ(x)∣φ(x′)⟩∣2k(x, x') = |\langle\varphi(x)|\varphi(x')\rangle|^2k(x,x′)=∣⟨φ(x)∣φ(x′)⟩∣2. And noise matters for QML too: it shrinks states towards the center, so all kernel values drift towards the same number and the model gets blurrier.
