Warm-up

Two coins, four outcomes

1 min

Flip two coins and there are four outcomes: HH, HT, TH, TT. Two qubits likewise have four basis states, but instead of four probabilities they carry four amplitudes. That small difference grows explosively, and next week it produces entanglement.

Big idea

Four amplitudes, and the tensor product

4 min

A two-qubit state is a combination of four basis states:

∣ψ⟩=a00∣00⟩+a01∣01⟩+a10∣10⟩+a11∣11⟩,∑∣aij∣2=1|\psi\rangle = a_{00}|00\rangle + a_{01}|01\rangle + a_{10}|10\rangle + a_{11}|11\rangle, \qquad \sum |a_{ij}|^2 = 1∣ψ⟩=a00​∣00⟩+a01​∣01⟩+a10​∣10⟩+a11​∣11⟩,∑∣aij​∣2=1

When the two qubits are prepared separately, say qubit A in α0∣0⟩+α1∣1⟩\alpha_0|0\rangle + \alpha_1|1\rangleα0​∣0⟩+α1​∣1⟩ and qubit B in β0∣0⟩+β1∣1⟩\beta_0|0\rangle + \beta_1|1\rangleβ0​∣0⟩+β1​∣1⟩, the joint state is their tensor product: every amplitude of one times every amplitude of the other.

(β0∣0⟩+β1∣1⟩)⊗(α0∣0⟩+α1∣1⟩)=β0α0∣00⟩+β0α1∣01⟩+β1α0∣10⟩+β1α1∣11⟩(\beta_0|0\rangle + \beta_1|1\rangle) \otimes (\alpha_0|0\rangle + \alpha_1|1\rangle) = \beta_0\alpha_0|00\rangle + \beta_0\alpha_1|01\rangle + \beta_1\alpha_0|10\rangle + \beta_1\alpha_1|11\rangle(β0​∣0⟩+β1​∣1⟩)⊗(α0​∣0⟩+α1​∣1⟩)=β0​α0​∣00⟩+β0​α1​∣01⟩+β1​α0​∣10⟩+β1​α1​∣11⟩

For such product states the probabilities multiply, exactly like independent coins. Tomorrow you'll meet states that are not products. Those are entangled.

Qiskit's bit order

Qiskit numbers qubits from 0 and writes bitstrings with qubit 0 on the right: the label 01 means qubit 1 is 0 and qubit 0 is 1. (Many textbooks use the opposite order, so this trips everyone up at least once.)

The same rule sets the amplitude order: index iii in the state vector is the binary number q1q0q_1q_0q1​q0​, so ∣01⟩|01\rangle∣01⟩ is index 1 and ∣10⟩|10\rangle∣10⟩ is index 2.

With nnn qubits there are 2n2^n2n basis states. Ten qubits need 1,024 amplitudes; fifty need about 101510^{15}1015, around 16 petabytes of memory. This exponential growth is why quantum states are hard to simulate, and part of why quantum computers might do things classical ones can't.

cell 1 · the four basis states
import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector

def probs(sv):
    """Probabilities as a tidy dictionary, skipping zeros."""
    return {str(k): round(float(v), 3) for k, v in sv.probabilities_dict().items()}

for label in ["00", "01", "10", "11"]:
    sv = Statevector.from_label(label)
    print(f"|{label}>  ->  amplitude vector {sv.data.real.astype(int)}")

cell 5 · exponential growth
def human(nbytes):
    for unit in ["bytes", "KB", "MB", "GB", "TB", "PB"]:
        if nbytes < 1024:
            return f"{nbytes:,.0f} {unit}"
        nbytes /= 1024
    return f"{nbytes:,.0f} EB"

for n in [1, 2, 3, 10, 20, 30, 40, 50]:
    amplitudes = 2 ** n
    print(f"{n:2d} qubits -> {amplitudes:>25,d} amplitudes = {human(amplitudes * 16):>9}")   # 16 bytes each

one solution
def is_product(v):
    v = np.asarray(v, dtype=complex)
    return bool(abs(v[0] * v[3] - v[1] * v[2]) < 1e-9)

for name, v in tests.items():
    print(f"{name:>22}: product? {is_product(v)}")
print("The last one can't be written as (one qubit) x (other qubit): it is entangled. Tomorrow's lesson makes it.")
