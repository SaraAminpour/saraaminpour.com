Measuring in other bases

A meter only reads 0 or 1, along the z axis. Turn the state first and the same meter reads along x or y instead. That's how hidden phases become counts.

Warm-up

Asking a different question

1 min

∣+⟩|+\rangle∣+⟩ and ∣−⟩|-\rangle∣−⟩ give identical 0/1 counts, yet they're opposite points of the sphere. Yesterday, an H before the meter made a hidden phase show up as counts. Today that trick gets its proper name: measuring in a different basis. It's like asking the qubit a different question.

Big idea

Turn, then measure

4 min

Real hardware can only measure in the Z basis: "is it ∣0⟩|0\rangle∣0⟩ or ∣1⟩|1\rangle∣1⟩?" To ask "is it ∣+⟩|+\rangle∣+⟩ or ∣−⟩|-\rangle∣−⟩?", turn the x axis onto the z axis first, then use the ordinary meter:

basisthe questioncircuit before the meter
Z∣0⟩|0\rangle∣0⟩ or ∣1⟩|1\rangle∣1⟩?nothing
X∣+⟩|+\rangle∣+⟩ or ∣−⟩|-\rangle∣−⟩?H (because H∣+⟩=∣0⟩H|+\rangle = |0\rangleH∣+⟩=∣0⟩, H∣−⟩=∣1⟩H|-\rangle = |1\rangleH∣−⟩=∣1⟩)
Y∣+i⟩|{+i}\rangle∣+i⟩ or ∣−i⟩|{-i}\rangle∣−i⟩?S†, then H (S†S^\daggerS† turns ∣+i⟩|{+i}\rangle∣+i⟩ into ∣+⟩|+\rangle∣+⟩)

With the Bloch vector (x,y,z)(x, y, z)(x,y,z) of the state, the odds are beautifully simple:

P(0)=1+z2,P(+)=1+x2,P(+i)=1+y2P(0) = \frac{1 + z}{2}, \qquad P(+) = \frac{1 + x}{2}, \qquad P(+i) = \frac{1 + y}{2}P(0)=21+z​,P(+)=21+x​,P(+i)=21+y​

Each basis reads one coordinate of the arrow: Z its height, X its shadow on the x axis, Y its shadow on the y axis.

Notice what this implies: ∣0⟩|0\rangle∣0⟩ has z=1z = 1z=1 but x=y=0x = y = 0x=y=0, so it's certain in Z and a perfect coin in X and in Y. No state can be certain in all three bases at once, a small cousin of Heisenberg's uncertainty principle. And since three coordinates fix the arrow, measuring in all three bases tells you the whole state: that's Friday's project.

cell 1 · telling |+⟩ from |−⟩
import numpy as np
from qiskit import QuantumCircuit
from qiskit.primitives import StatevectorSampler
from qiskit.quantum_info import Statevector

sampler = StatevectorSampler(seed=3)

def prepare(label):
    qc = QuantumCircuit(1)
    if label == "+":
        qc.h(0)
    elif label == "-":
        qc.x(0)
        qc.h(0)
    return qc

for label in ["+", "-"]:
    z = prepare(label)
    z.measure_all()
    x = prepare(label)
    x.h(0)                      # turn the x axis onto the z axis...
    x.measure_all()             # ...then use the ordinary meter
    rz, rx = sampler.run([z, x], shots=1000).result()
    print(f"|{label}>:  Z basis {rz.data.meas.get_counts()}   X basis {rx.data.meas.get_counts()}  (0 means '+', 1 means '-')")

cell 2 · one state, three bases
def measure_in(state_circuit, basis, shots=4000):
    qc = state_circuit.copy()
    if basis == "X":
        qc.h(0)
    elif basis == "Y":
        qc.sdg(0)
        qc.h(0)
    qc.measure_all()
    counts = sampler.run([qc], shots=shots).result()[0].data.meas.get_counts()
    return counts.get("0", 0) / shots           # probability of the first outcome (0, + or +i)

plus_i = QuantumCircuit(1)
plus_i.h(0)
plus_i.s(0)                                     # |+i>
for basis in "ZXY":
    print(f"|+i> in the {basis} basis: P(first outcome) = {measure_in(plus_i, basis):.3f}")

cell 3 · three meters, one arrow
state = QuantumCircuit(1)
state.ry(1.1, 0)
state.rz(0.7, 0)
measured = [2 * measure_in(state, b) - 1 for b in "XYZ"]
a, b = Statevector(state).data
c = np.conj(a) * b
exact = [2 * c.real, 2 * c.imag, abs(a) ** 2 - abs(b) ** 2]
print("from three measurements:", np.round(measured, 3))
print("exact Bloch vector:     ", np.round(exact, 3))

Wrap-up

Today in one sentence

1 min
To measure in another basis, turn the state first: H for X, S† then H for Y. Each basis reads one coordinate of the Bloch arrow, P=(1+coordinate)/2P = (1 + \text{coordinate})/2P=(1+coordinate)/2.
Machine-learning link

Choosing what to measure is part of designing a quantum model. A quantum classifier's output is usually the average of one such measurement (next week: expectation values), so the measurement basis plays the role of the output layer in a neural network.
