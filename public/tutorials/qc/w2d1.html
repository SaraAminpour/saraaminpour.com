Warm-up

A globe for one qubit

1 min

Last week a qubit was a dot on a circle, with real amplitudes. But amplitudes can be complex, and then the circle isn't enough. The good news: one qubit always fits on a sphere, and once you can picture it, every one-qubit gate becomes a simple turn of the sphere. That's this whole week.

Big idea

Two angles describe every qubit

4 min

Any single-qubit state can be written, up to an unimportant overall factor, as

∣ψ⟩=cos⁡θ2 ∣0⟩+eiφsin⁡θ2 ∣1⟩,0≤θ≤π,  0≤φ<2π|\psi\rangle = \cos\frac{\theta}{2}\,|0\rangle + e^{i\varphi}\sin\frac{\theta}{2}\,|1\rangle, \qquad 0 \le \theta \le \pi,\; 0 \le \varphi < 2\pi∣ψ⟩=cos2θ​∣0⟩+eiφsin2θ​∣1⟩,0≤θ≤π,0≤φ<2π

Read θ\thetaθ (theta) as latitude measured down from the north pole, and φ\varphiφ (phi) as longitude around the equator. Then:

  • North pole θ=0\theta = 0θ=0: the state ∣0⟩|0\rangle∣0⟩. South pole θ=π\theta = \piθ=π: the state ∣1⟩|1\rangle∣1⟩.
  • Equator θ=π/2\theta = \pi/2θ=π/2: equal 50/50 mixtures. They differ only in phase: ∣+⟩|+\rangle∣+⟩ at φ=0\varphi = 0φ=0, ∣+i⟩|{+i}\rangle∣+i⟩ at π/2\pi/2π/2, ∣−⟩|-\rangle∣−⟩ at π\piπ, ∣−i⟩|{-i}\rangle∣−i⟩ at 3π/23\pi/23π/2.

The probabilities only care about latitude:

P(0)=cos⁡2θ2,P(1)=sin⁡2θ2P(0) = \cos^2\frac{\theta}{2}, \qquad P(1) = \sin^2\frac{\theta}{2}P(0)=cos22θ​,P(1)=sin22θ​

So the phase φ\varphiφ is invisible to a measurement in the 0/1 basis. Yet ∣+⟩|+\rangle∣+⟩ and ∣−⟩|-\rangle∣−⟩ are as different as two states can be (opposite points!). The phase shows up as soon as a gate mixes the amplitudes, which is exactly what interference is.

Why θ/2 and not θ?

On last week's circle, ∣0⟩|0\rangle∣0⟩ and ∣1⟩|1\rangle∣1⟩ were 90° apart. On the sphere they are 180° apart, at opposite poles. Every angle doubles: the circle's 45° state ∣+⟩|+\rangle∣+⟩ sits 90° from the pole, on the equator. Opposite points on the sphere are states that can be told apart perfectly.

One more fact: multiplying the whole state by eiαe^{i\alpha}eiα (a global phase) changes nothing you could ever measure. That's why two angles are enough.

As an arrow from the center, the state points to (x,y,z)=(sin⁡θcos⁡φ, sin⁡θsin⁡φ, cos⁡θ)(x, y, z) = (\sin\theta\cos\varphi,\ \sin\theta\sin\varphi,\ \cos\theta)(x,y,z)=(sinθcosφ, sinθsinφ, cosθ), the Bloch vector. Its height has a simple meaning: z=P(0)−P(1)z = P(0) - P(1)z=P(0)−P(1).

cell 1 · famous states from two angles
import numpy as np
from qiskit.quantum_info import Statevector

def bloch_state(theta, phi):
    """The qubit state at latitude theta and longitude phi on the Bloch sphere."""
    return Statevector([np.cos(theta / 2), np.exp(1j * phi) * np.sin(theta / 2)])

famous = {"|0>": (0, 0), "|1>": (np.pi, 0), "|+>": (np.pi / 2, 0),
          "|->": (np.pi / 2, np.pi), "|+i>": (np.pi / 2, np.pi / 2)}
for name, (theta, phi) in famous.items():
    sv = bloch_state(theta, phi)
    print(f"{name:>5}: amplitudes {np.round(sv.data, 3)}   P(0) = {sv.probabilities()[0]:.2f}")

one solution
def bloch_vector(state):
    alpha, beta = state.data
    c = np.conj(alpha) * beta
    x, y, z = 2 * c.real, 2 * c.imag, abs(alpha) ** 2 - abs(beta) ** 2
    return np.round([x, y, z], 3)

for name, (theta, phi) in {"|0>": (0, 0), "|+>": (np.pi / 2, 0), "|+i>": (np.pi / 2, np.pi / 2),
                           "halfway |0>-|+i>": (np.pi / 4, np.pi / 2)}.items():
    print(f"{name:>17}: {bloch_vector(bloch_state(theta, phi))}")
print("Check: the arrow is (sin θ cos φ, sin θ sin φ, cos θ). For θ = 45°, φ = 90° that's (0, 0.707, 0.707).")
print("And z = P(0) - P(1): the height of the arrow is the difference of the two probabilities.")

Today in one sentence

1 min
A qubit state is a point on the Bloch sphere: latitude θ\thetaθ sets the measurement odds, longitude φ\varphiφ is a phase that a 0/1 measurement can't see but gates can use.
