Big idea

Columns and tables

4 min

A state is a column vector, the two amplitudes stacked:

∣0⟩=(10),∣1⟩=(01),α∣0⟩+β∣1⟩=(αβ)|0\rangle = \begin{pmatrix}1\\0\end{pmatrix},\quad |1\rangle = \begin{pmatrix}0\\1\end{pmatrix},\quad \alpha|0\rangle + \beta|1\rangle = \begin{pmatrix}\alpha\\ \beta\end{pmatrix}∣0⟩=(10​),∣1⟩=(01​),α∣0⟩+β∣1⟩=(αβ​)

A gate is a 2×22\times22×2 matrix, and applying it is matrix–vector multiplication: each new amplitude is one row of the matrix times the column.

(abcd)(αβ)=(aα+bβcα+dβ)\begin{pmatrix}a & b\\ c & d\end{pmatrix}\begin{pmatrix}\alpha\\ \beta\end{pmatrix} = \begin{pmatrix}a\alpha + b\beta\\ c\alpha + d\beta\end{pmatrix}(ac​bd​)(αβ​)=(aα+bβcα+dβ​)

Two habits make matrices easy to read:

  • The columns are the answers. The first column is U∣0⟩U|0\rangleU∣0⟩ and the second is U∣1⟩U|1\rangleU∣1⟩. Read HHH's columns and you know H∣0⟩=∣+⟩H|0\rangle = |+\rangleH∣0⟩=∣+⟩, H∣1⟩=∣−⟩H|1\rangle = |-\rangleH∣1⟩=∣−⟩.
  • Gates act on each part of a superposition. U(α∣0⟩+β∣1⟩)=α U∣0⟩+β U∣1⟩U(\alpha|0\rangle + \beta|1\rangle) = \alpha\,U|0\rangle + \beta\,U|1\rangleU(α∣0⟩+β∣1⟩)=αU∣0⟩+βU∣1⟩. This linearity is what will let amplitudes add up and cancel on Wednesday.

A circuit of several gates is a product of matrices, written right to left: the circuit "AAA, then BBB, then CCC" is the matrix CBACBACBA, because AAA touches the state first. And the "bra" ⟨ϕ∣\langle\phi|⟨ϕ∣ from week 1 is just the row you get by transposing ∣ϕ⟩|\phi\rangle∣ϕ⟩ and conjugating it, so ⟨ϕ∣ψ⟩\langle\phi|\psi\rangle⟨ϕ∣ψ⟩ is a row times a column.

A quantum computer's state is a vector, its gates are matrices, and running it is multiplying them. Simulating qubits is linear algebra.

A tiny simulator in NumPy

cell 1 · kets as arrays
import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Operator, Statevector

ket0 = np.array([1, 0], dtype=complex)
ket1 = np.array([0, 1], dtype=complex)
psi = 0.6 * ket0 + 0.8j * ket1           # a superposition is just a weighted sum of columns
print("|psi> =", psi)
print("normalized?", np.isclose(np.vdot(psi, psi).real, 1.0))

cell 2 · gates as matrices, and linearity
s = 1 / np.sqrt(2)
X = np.array([[0, 1], [1, 0]], dtype=complex)
H = np.array([[s, s], [s, -s]], dtype=complex)
S = np.array([[1, 0], [0, 1j]], dtype=complex)

print("H|0> =", np.round(H @ ket0, 3), "  = first column of H:", np.round(H[:, 0], 3))
print("H|1> =", np.round(H @ ket1, 3), " = second column of H:", np.round(H[:, 1], 3))
print("H|psi> =", np.round(H @ psi, 3))
print("same as 0.6·H|0> + 0.8i·H|1>?", np.allclose(H @ psi, 0.6 * (H @ ket0) + 0.8j * (H @ ket1)))

Wrap-up

Today in one sentence

1 min
States are column vectors, gates are matrices whose columns say where ∣0⟩|0\rangle∣0⟩ and ∣1⟩|1\rangle∣1⟩ go, and a circuit is one product of matrices, read right to left.
Machine-learning link

A PyTorch nn.Linear layer is also a matrix times a vector. So a neural network layer and a quantum gate are close cousins. Two differences matter: a gate's matrix must be unitary (tomorrow's lesson), and it acts on amplitudes rather than on features. Quantum ML lives right at that border.
