Warm-up

A needle in a haystack

1 min

A million boxes, one prize, and no clue where. Classically you open boxes one by one: half a million on average. Grover's algorithm needs about 785 questions. It is this week's tools put together: an oracle with phase kickback, Hadamards and interference.

Big idea

Two reflections make a rotation

4 min

Number the N=2nN = 2^nN=2n items with bit strings. An oracle marks the prize www by flipping its sign (phase kickback, as this week): ∣w⟩→−∣w⟩|w\rangle \to -|w\rangle∣w⟩→−∣w⟩, every other item untouched. Start with all items equally likely (H on every qubit), then repeat a Grover step:

  1. Oracle: flip the sign of the prize's amplitude.
  2. Diffuser: reflect every amplitude about the mean, a→2aˉ−aa \to 2\bar{a} - aa→2aˉ−a.

The flipped prize sits far below the mean, so the reflection throws it far above; every other amplitude shrinks a little. Each step moves probability onto the prize.

The picture that explains everything: the state always lives in a plane spanned by ∣prize⟩|\text{prize}\rangle∣prize⟩ and ∣rest⟩|\text{rest}\rangle∣rest⟩ (all other items, equally mixed). It starts at a small angle θ\thetaθ from ∣rest⟩|\text{rest}\rangle∣rest⟩, with sin⁡θ=1/N\sin\theta = 1/\sqrt{N}sinθ=1/N​. Two reflections make a rotation, so each step turns the state by 2θ2\theta2θ towards the prize:

P(prize after k steps)=sin⁡2((2k+1) θ)P(\text{prize after } k \text{ steps}) = \sin^2\big((2k + 1)\,\theta\big)P(prize after k steps)=sin2((2k+1)θ)

It reaches the prize after about π4θ≈π4N\frac{\pi}{4\theta} \approx \frac{\pi}{4}\sqrt{N}4θπ​≈4π​N​ steps. That's a quadratic speedup: N\sqrt{N}N​ instead of NNN. Go further and the rotation overshoots, so the probability falls again. Grover's search must stop at the right moment.

In a circuit, the diffuser is H⊗nH^{\otimes n}H⊗n, a sign flip on ∣00…0⟩|00\ldots0\rangle∣00…0⟩, and H⊗nH^{\otimes n}H⊗n again: a reflection about the starting state, built from the same gates as the oracle.

Mark with a sign, reflect about the mean, repeat about π4N\frac{\pi}{4}\sqrt{N}4π​N​ times: the prize's amplitude grows like a rotating arrow.

cell 1 · oracle, diffuser, search
import numpy as np
import matplotlib.pyplot as plt
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector
from qiskit.primitives import StatevectorSampler

def phase_oracle(marked):
    """Flip the sign of one basis state. marked is a bit string in Qiskit order (last character = qubit 0)."""
    n = len(marked)
    qc = QuantumCircuit(n, name="oracle")
    zeros = [q for q, bit in enumerate(reversed(marked)) if bit == "0"]
    if zeros:
        qc.x(zeros)                          # now the marked state looks like 11...1
    qc.h(n - 1)
    qc.mcx(list(range(n - 1)), n - 1)        # H, multi-controlled X, H = multi-controlled Z
    qc.h(n - 1)
    if zeros:
        qc.x(zeros)
    return qc

def diffuser(n):
    """Reflect every amplitude about the mean (up to an overall sign, which can't be measured)."""
    qc = QuantumCircuit(n, name="diffuser")
    qc.h(range(n))
    qc.x(range(n))
    qc.h(n - 1)
    qc.mcx(list(range(n - 1)), n - 1)
    qc.h(n - 1)
    qc.x(range(n))
    qc.h(range(n))
    return qc

def grover(marked, steps, measure=True):
    n = len(marked)
    qc = QuantumCircuit(n)
    qc.h(range(n))                           # every item equally likely
    oracle_gate, diffuser_gate = phase_oracle(marked).to_gate(), diffuser(n).to_gate()
    for _ in range(steps):
        qc.append(oracle_gate, range(n))     # appended as boxes, so the drawing stays readable
        qc.append(diffuser_gate, range(n))
    if measure:
        qc.measure_all()
    return qc

display(grover("101", 2).draw("mpl", style="clifford"))
diffuser(3).draw("mpl", style="clifford")

N = 8

rows = []
for n in range(2, 9):
    N = 2 ** n
    marked = "1" * n
    probs = [Statevector(grover(marked, k, measure=False)).probabilities_dict().get(marked, 0.0)
             for k in range(int(np.pi / 4 * np.sqrt(N)) + 3)]
    best_k = int(np.argmax(probs))
    rows.append((n, N, best_k, probs[best_k]))
for n, N, best_k, best_p in rows:
    print(f"n = {n}, N = {N:3d}: best k = {best_k:2d} (P = {best_p:.3f}), pi/4 sqrt(N) = {np.pi / 4 * np.sqrt(N):5.2f}, classical N/2 = {N // 2}")

sqrtN = [np.sqrt(N) for _, N, _, _ in rows]
fig, ax = plt.subplots(figsize=(5.6, 3.2), layout="constrained")
ax.plot(sqrtN, [k for _, _, k, _ in rows], "o", color="#7b5cfa", ms=8, label="best k (simulated)")
ax.plot(sqrtN, np.pi / 4 * np.array(sqrtN), color="#b9a7ff", lw=2, label=r"$\frac{\pi}{4}\sqrt{N}$")
ax.set_xlabel(r"$\sqrt{N}$")
ax.set_ylabel("Grover steps")
ax.legend()
plt.show()
print("A straight line in sqrt(N): searching 100 times more items takes only 10 times more steps.")

Wrap-up

This week in one sentence

1 min
Entanglement carries qubits and bits (teleportation, superdense coding), phase kickback turns answers into signs, and interference turns signs into results: one query for Deutsch–Jozsa and Bernstein–Vazirani, and about π4N\frac{\pi}{4}\sqrt{N}4π​N​ for Grover's search.
Quantum link

Grover-style "amplitude amplification" appears inside many proposed quantum machine-learning speedups, for example in quantum versions of nearest-neighbor search. Read those claims carefully: the speedup is at most quadratic, needs fault-tolerant hardware, and assumes the data can be loaded into qubits quickly, which is often the hard part.
