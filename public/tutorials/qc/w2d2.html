Warm-up

Turning the globe

1 min

Yesterday every qubit state got its own spot on a globe. A gate moves the state, so a gate must move the spot. The simplest gates of all are three half-turns of that globe, named after the physicist Wolfgang Pauli: X, Y and Z.

Big idea

Bit flip, phase flip, and both

4 min

As 2×22\times 22×2 matrices acting on the amplitude vector (αβ)\binom{\alpha}{\beta}(βα​):

X=(0110)Y=(0−ii0)Z=(100−1)X = \begin{pmatrix}0&1\\1&0\end{pmatrix}\qquad Y = \begin{pmatrix}0&-i\\i&0\end{pmatrix}\qquad Z = \begin{pmatrix}1&0\\0&-1\end{pmatrix}X=(01​10​)Y=(0i​−i0​)Z=(10​0−1​)

X: the bit flip

Swaps the amplitudes: X∣0⟩=∣1⟩X|0\rangle = |1\rangleX∣0⟩=∣1⟩, X∣1⟩=∣0⟩X|1\rangle = |0\rangleX∣1⟩=∣0⟩. On the sphere, a half-turn about the x axis.

Z: the phase flip

Flips the sign of the ∣1⟩|1\rangle∣1⟩ amplitude: Z∣+⟩=∣−⟩Z|+\rangle = |-\rangleZ∣+⟩=∣−⟩. On the sphere, a half-turn about the z axis.

Y does both at once, with an extra factor iii: Y∣0⟩=i∣1⟩Y|0\rangle = i|1\rangleY∣0⟩=i∣1⟩. It's a half-turn about the y axis. (In fact Y=iXZY = iXZY=iXZ.)

Three facts follow from the picture of half-turns:

  • Doing a half-turn twice brings you back: X2=Y2=Z2=IX^2 = Y^2 = Z^2 = IX2=Y2=Z2=I. Each Pauli gate undoes itself.
  • A turn about an axis leaves the two points on that axis where they are. So X leaves ∣±⟩|\pm\rangle∣±⟩ alone, Y leaves ∣±i⟩|\pm i\rangle∣±i⟩ alone, Z leaves ∣0⟩|0\rangle∣0⟩ and ∣1⟩|1\rangle∣1⟩ alone (up to a global phase). These are the gates' eigenstates.
  • Z doesn't change the height of the arrow, so it doesn't change P(0)P(0)P(0) or P(1)P(1)P(1). A 0/1 measurement can't see it, yet Z∣+⟩=∣−⟩Z|+\rangle = |-\rangleZ∣+⟩=∣−⟩ is a completely different state.

A gate is a turn of the Bloch sphere. The Pauli gates are the three half-turns about its axes.

cell 1 · the matrices and their rules
import numpy as np
from qiskit.quantum_info import Operator, Statevector

X, Y, Z = (Operator.from_label(p).data for p in "XYZ")
I = np.eye(2)
for name, M in [("X", X), ("Y", Y), ("Z", Z)]:
    print(f"{name} =\n{np.round(M, 3)}\n")
print("X·X = I?", np.allclose(X @ X, I), "  Y·Y = I?", np.allclose(Y @ Y, I), "  Z·Z = I?", np.allclose(Z @ Z, I))
print("X·Z = -Z·X?", np.allclose(X @ Z, -Z @ X), "   Y = i·X·Z?", np.allclose(Y, 1j * X @ Z))

cell 2 · what they do to four famous states
def fmt(z):
    re, im = round(z.real, 3), round(z.imag, 3)
    if im == 0:
        return f"{re:g}"
    if re == 0:
        return f"{im:g}i"
    return f"({re:g}{im:+g}i)"

def ket(sv):
    out = ""
    for amp, label in zip(sv.data, ["|0>", "|1>"]):
        if abs(amp) < 1e-9:
            continue
        c = fmt(amp)
        if not out:
            out = c + label
        elif c.startswith("-"):
            out += " - " + c[1:] + label
        else:
            out += " + " + c + label
    return out

s = 1 / np.sqrt(2)
famous = {"|0>": [1, 0], "|1>": [0, 1], "|+>": [s, s], "|->": [s, -s]}
for gname, G in [("X", X), ("Z", Z), ("Y", Y)]:
    for sname, amps in famous.items():
        out = Statevector(amps).evolve(Operator(G))
        print(f"{gname} {sname:>3} = {ket(out)}")
    print()

cell 4 · signs flip, one axis stays
def bloch(sv):
    a, b = sv.data
    c = np.conj(a) * b
    return np.round([2 * c.real, 2 * c.imag, abs(a) ** 2 - abs(b) ** 2], 3)

psi = Statevector([np.cos(0.4), np.exp(0.9j) * np.sin(0.4)])
print("start        ", bloch(psi))
for gname, G in [("X", X), ("Y", Y), ("Z", Z)]:
    print(f"after {gname}      ", bloch(psi.evolve(Operator(G))))

one solution
for gname, G in [("X", X), ("Y", Y), ("Z", Z)]:
    stay = [sname for sname, amps in six.items() if Statevector(amps).evolve(Operator(G)).equiv(Statevector(amps))]
    print(f"{gname} leaves alone: {stay}")
print("Each gate leaves exactly the two states on its own axis: these are its eigenstates.")

Wrap-up

Today in one sentence

1 min
The Pauli gates are half-turns of the Bloch sphere: X flips the bit, Z flips the phase, Y does both. Each undoes itself, and each leaves the two states on its own axis alone.
Machine-learning link
