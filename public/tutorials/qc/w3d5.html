Warm-up

A detective story, part two

1 min

This project is a short one. In week 1 you recovered one hidden angle from 0/1 counts. A single meter can't see the phase, though. Now you have three meters, and three coordinates fix an arrow completely. Let's rebuild a whole mystery state.

Big idea

Three shadows make an arrow

2 min

From yesterday: measuring in a basis gives the probability of its first outcome, and the matching coordinate of the Bloch arrow is

x=2P(+)−1,y=2P(+i)−1,z=2P(0)−1x = 2P(+) - 1, \qquad y = 2P(+i) - 1, \qquad z = 2P(0) - 1x=2P(+)−1,y=2P(+i)−1,z=2P(0)−1

So: prepare many copies of the state, measure some in X, some in Y and some in Z, and compute the three coordinates. Shot noise can make the estimated arrow a little longer than 1, which no real state can be, so we shrink it back to length 1. Finally the angles θ=arccos⁡z\theta = \arccos zθ=arccosz and φ=atan2⁡(y,x)\varphi = \operatorname{atan2}(y, x)φ=atan2(y,x) give the state.

Reconstructing a state from measurements in several bases is called quantum state tomography, like a CT scan built from shadows taken at different angles.

cell 1 · a hidden state and its three meters
import numpy as np
from qiskit import QuantumCircuit
from qiskit.primitives import StatevectorSampler
from qiskit.quantum_info import Statevector, state_fidelity

sampler = StatevectorSampler(seed=12)
_rng = np.random.default_rng(31)
_t, _p = np.arccos(1 - 2 * _rng.random()), 2 * np.pi * _rng.random()

def mystery():
    """A circuit that prepares a hidden one-qubit state (don't peek!)."""
    qc = QuantumCircuit(1)
    qc.ry(_t, 0)
    qc.rz(_p, 0)
    return qc

def p_first(basis, shots):
    """Probability of the first outcome (0, + or +i) when measuring the mystery state in a basis."""
    qc = mystery()
    if basis == "X":
        qc.h(0)
    elif basis == "Y":
        qc.sdg(0)
        qc.h(0)
    qc.measure_all()
    counts = sampler.run([qc], shots=shots).result()[0].data.meas.get_counts()
    return counts.get("0", 0) / shots

print({b: p_first(b, 100) for b in "XYZ"})

one solution
def tomography(shots):
    v = np.array([2 * p_first(b, shots) - 1 for b in "XYZ"])
    length = np.linalg.norm(v)
    if length > 1:
        v = v / length
    theta = np.arccos(np.clip(v[2] / max(np.linalg.norm(v), 1e-12), -1, 1))
    phi = np.arctan2(v[1], v[0])
    return Statevector([np.cos(theta / 2), np.exp(1j * phi) * np.sin(theta / 2)])

for shots in [100, 1000, 10000]:
    print(f"{shots:6d} shots per basis: fidelity {state_fidelity(tomography(shots), truth):.4f}")
print(f"\nThe hidden angles were theta = {np.degrees(_t):.1f} and phi = {np.degrees(_p):.1f} degrees.")

Wrap-up

This week in one sentence

1 min
States are vectors and gates unitary matrices, so every gate can be undone; amplitudes add and cancel (interference); a basis change before the meter reads the arrow along any axis, and three bases reveal the whole state.
Machine-learning link

Tomography is a tiny learning problem: estimate parameters (the arrow) from noisy samples (the shots). For many qubits it gets exponentially expensive, and researchers now use machine learning, even neural networks, to do it with far fewer measurements.
