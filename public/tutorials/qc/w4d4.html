Warm-up

From pairs to crowds

1 min

Bell states tie two qubits together. Nothing stops you from tying three, ten or fifty. Today you'll build such crowds, and then do a little arithmetic that explains, in one line, why people build quantum computers at all.

Big idea

GHZ, and counting amplitudes

4 min

The GHZ state (after Greenberger, Horne and Zeilinger) generalizes ∣Φ+⟩|\Phi^+\rangle∣Φ+⟩ to nnn qubits:

∣GHZn⟩=12(∣00⋯0⟩+∣11⋯1⟩)|\text{GHZ}_n\rangle = \frac{1}{\sqrt2}\big(|00\cdots0\rangle + |11\cdots1\rangle\big)∣GHZn​⟩=2​1​(∣00⋯0⟩+∣11⋯1⟩)

The recipe: H on qubit 0, then a CNOT from each qubit to the next. Measure any single qubit, and you instantly know what all the others will show.

Now count. One qubit has 2 amplitudes, two have 4, and nnn qubits have 2n2^n2n. Stored as complex numbers of 16 bytes each:

qubitsamplitudesmemory
101,02416 KB
30about a billion16 GB, a laptop
45about 35 trillion0.5 PB, a big supercomputer
300more than atoms in the visible universeimpossible

Every extra qubit doubles the work of a classical simulation. A quantum computer just adds one more qubit.

Two honest footnotes. First, not every state is expensive: a product state of nnn qubits needs only 2n2n2n numbers, and states with little entanglement can be compressed cleverly. The expense comes from entanglement. Second, a big state is not automatically a fast algorithm: you only get to read out a few bits per shot. Turning the size into speed takes interference, which is next week's story.

cell 1 · GHZ on three qubits
import time
import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector
from qiskit.primitives import StatevectorSampler

def ghz(n):
    """H on qubit 0, then a chain of CNOTs: (|00...0> + |11...1>)/sqrt(2)."""
    qc = QuantumCircuit(n)
    qc.h(0)
    for q in range(n - 1):
        qc.cx(q, q + 1)
    return qc

print(ghz(3).draw("text"))
print({str(k): round(float(v), 3) for k, v in Statevector(ghz(3)).probabilities_dict().items()})

cell 3 · the memory bill
def human(nbytes):
    for unit in ["bytes", "KB", "MB", "GB", "TB", "PB", "EB", "ZB", "YB"]:
        if nbytes < 1024:
            return f"{nbytes:,.0f} {unit}"
        nbytes /= 1024
    return f"{nbytes:,.0f} more than YB"

for n in [10, 20, 30, 40, 50, 60]:
    print(f"{n:2d} qubits: {2 ** n:>22,d} amplitudes = {human(16 * 2 ** n):>12}")

cell 4 · simulation time doubles
import matplotlib.pyplot as plt

ns, secs = list(range(12, 23)), []
for n in ns:
    t0 = time.perf_counter()
    Statevector(ghz(n))
    secs.append(time.perf_counter() - t0)
plt.figure(figsize=(6, 3.2))
plt.semilogy(ns, secs, "o-", color="#7b5cfa")
plt.xlabel("number of qubits")
plt.ylabel("seconds (log scale)")
plt.title("Each qubit roughly doubles the work")
plt.show()

Your turn: a faster GHZ

3 min

The chain of CNOTs takes nnn steps, one after another. But once two qubits share the GHZ, both can pass it on at the same time. Build an 8-qubit GHZ with depth 4 (one H, then three layers of CNOTs) and check it equals the chain's state.

exercise · in your notebook
fast = QuantumCircuit(8)
fast.h(0)
# TODO: layer 1: 0->1;  layer 2: 0->2, 1->3;  layer 3: 0->4, 1->5, 2->6, 3->7
print("depth:", fast.depth(), "  same state as the chain?", Statevector(fast).equiv(Statevector(ghz(8))))
Need a hint?

Layer 1: 0→1. Layer 2: 0→2 and 1→3. Layer 3: 0→4, 1→5, 2→6, 3→7. Gates on different qubits run in parallel, so each layer adds depth 1.

Show a solution
one solution
fast = QuantumCircuit(8)
fast.h(0)
fast.cx(0, 1)
for c, t in [(0, 2), (1, 3)]:
    fast.cx(c, t)
for c, t in [(0, 4), (1, 5), (2, 6), (3, 7)]:
    fast.cx(c, t)
print(fast.draw("text"))
print("depth:", fast.depth(), "  same state as the chain?", Statevector(fast).equiv(Statevector(ghz(8))))
print("The number of qubits in the GHZ doubles every layer, so n qubits need only about log2(n) layers.")

Wrap-up

Today in one sentence

1 min
GHZ states tie many qubits into one decision; writing a general nnn-qubit state takes 2n2^n2n amplitudes, so every qubit doubles a simulation's cost, a wall that entanglement builds and quantum computers simply climb.
Machine-learning link

This exponential space is the big promise of quantum machine learning: a feature map can place data into a 2n2^n2n-dimensional space with just nnn qubits. Whether that space actually helps a model learn is one of the field's central questions, and you'll meet both the hope and the catch.
